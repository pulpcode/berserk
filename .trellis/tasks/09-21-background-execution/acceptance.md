# 验收：信息处理与席位投递

状态：**已完成开发验证并部署，待用户验收**。执行证据及覆盖方式见 [验证记录](validation.md)。本目录 BG 编号属于第二增量，不等同于父任务讨论快照中的编号。

先以确定性模型、真实 SQLite 和进程故障验证权限与可靠性；再在隔离目录使用真实 Pi、模型及 Linux Docker 验证。关闭网页不等于关闭服务器。

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| BG01 | 文本、文件及组合接入 | 回执前固定输入、规则／资源快照与接收／排队记录已保存；未匹配信息也可重启查回。上传不完整或保存失败不确认接收 |
| BG02 | 重送、并发重送与回执丢失 | 相同来源消息键／内容对应原事件和初始作业；同键异内容返回 409。附件重新上传但名称／内容不变仍去重；来源不同可用同一消息号；停止接收或容量满仍可查原回执 |
| BG03 | 同事项补充、无任务编号 | 新消息独立保留，可关联同一 subjectId；无任务编号不阻止预处理，不自动推断权限或覆盖旧分析 |
| BG04 | 无人在线 | 所有浏览器关闭时接收、预处理、站内投递照常完成；席位登录可查收，未确认前模型调用数不再增加，后台无等待人员的资源占用 |
| BG05 | 通用处理与脚本 | 同一机制处理材料检查及 CSV 计算；Agent 可编写 Python，多次工具调用使用同一目录，容器清理后脚本／中间文件／输出仍在；不绑定特情固定步骤 |
| BG06 | 强制退出边界 | 覆盖接收提交前后、领取后 Pi 启动前、脚本写入后、原生回复后终态提交前、成功后投递前。queued 可处理，running 明确中断／取消，已成功仅补投递，无模型／工具重放 |
| BG07 | Pi 机制复用 | 两类后台执行均复用原生会话／压缩／重试及只读 Agents；按各自范围加载 AGENTS.md 和 Skills。原文、摘要和子调用仍可核对，无第二套聊天历史 |
| BG08 | 服务与席位隔离 | 预处理不能读 A／B 私有工作区；A、B 分析使用各自任务目录。来源凭证不能进入信息中心或用户接口；明确撤销资料授权后旧收件和下载也拒绝 |
| BG09 | 结果与固定文件 | 最终答复和交付引用可核验，下载 hash 不随原文件改写而变化；坏文件明确报错。失败产物不作为成功结果投递，不默认创建 WorkItem／Submission |
| BG10 | 对话分析入口 | 选择任务、资料和目标，准备普通会话与可编辑草稿；发送前不启动模型，不自动带入服务指令或全文过程。未发送仅标已创建对话；发送后可关联原收件 |
| BG11 | 取消竞争 | 排队取消不启动 Pi；执行取消先保存、停止新工作并清理，已有文件保留。取消与成功只有一个确定终态，重启不丢取消请求；维护停服不伪装为人员取消 |
| BG12 | 明确重新处理 | 新 jobId／retryOf 和操作回执；预处理新目录，席位分析沿用本任务文件并提示核对效果。同 clientActionId 不重复，改参数冲突；不静默扩大权限或替换输入，旧结果可查 |
| BG13 | 人工操作边界 | 缺资料可返回问题结束；后台 ask 类命令没有执行、不会无限等待，原因明确。点击提交后台分析不批准任意命令；进入普通会话重新确认后才可执行受控操作 |
| BG14 | 容量与模型并发 | 两类后台共用可配置作业容量；前后台／摘要／父子模型调用共用许可，并发为 1 仍可完成委派。等待不误计调用或流空闲超时，取消释放名额，用量不重复；运行中改模型设置被拒绝 |
| BG15 | 来源、领取和存储异常 | 停止来源不确认新消息，暂停领取不取消在途；开关重启保留。积压上限含无规则消息，超限不假接收。来源／资源不可用、磁盘错误有明确状态，遗留容器清理失败暂停领取 |
| BG16 | 桌面页面 | 入口为信息处理中心，含信息记录／后台作业／处理与投递规则；普通席位只有自己的收件。详情 URL 可恢复，刷新不重跑；导航返回保留草稿，退出清空身份并拒绝迟到响应，键盘可操作 |
| BG17 | 迁移与原功能 | 数据副本升级后账号、任务、原生历史、文件、业务回执不变；旧版拒绝新版数据库。原登录、对话、引用、压缩、Agents、文件、HITL 和双席位交接回归通过 |
| BG18 | 一次预处理、多席位投递 | A、B 分别有投递记录及收件，预处理只执行一次；模拟 B 投递失败不撤销 A 的送达。重试／进程重启只补未送达项，无重复收件或模型调用；送达不表示查看或开始分析 |
| BG19 | 规则新建、编辑、启停 | 查看权限只读，管理权限可操作；越界方案／接收席位被拒绝，每来源最多一条启用规则。并发保存冲突保留草稿。变更只作用新消息，历史规则可追溯；无规则消息可接收，启用不自动补办，明确补办只产生一项初始作业 |
| BG20 | 人员提交后台分析 | 只有明确确认后入队；保存目标、资料、发起主体、任务及会话。关网页／退出登录不取消已接受作业。领取前账号失效／权限撤销拒绝执行；结束后可在原普通会话继续，结果不自动转发其他席位 |
| BG21 | 指定账号／席位权限 | 查看、管理及来源范围分别生效，服务端拒绝越权，不只隐藏菜单。来源内管理权限不能读取他人私有分析目标／文件／会话或擅自重跑其分析；全局暂停要求完整来源管理范围 |
| BG22 | 发起幂等与关联 | 文件准备、会话绑定和队列提交任意边界中断后可查回原发起回执，不重复会话／作业，不覆盖同名文件；排队会话禁止普通并发发送，归档检查 queued 和准备中导入。信息详情串起原文、规则、预处理、各席位投递及受权限限制的后续处理 |

真实验收至少覆盖一次双席位投递，A 选择对话分析，B 选择后台分析；后台包含脚本与文件产出。使用测试资料和独立数据，不执行正式上报，不将既有阶段或确定性测试结果冒充本期真实模型验收。
