# W01-10 聊天过程展示优化

用户已授权实施；改造前备份提交 `c2ae7b2`。参考 DSH Web 的过程折叠和工具展示，面向桌面浏览器。

## 目标与验收

- 每轮用户输入、处理过程、最终答复和成果层次清晰，减少重复品牌与大卡片边框。
- 处理时过程可见；确有成功终态及独立最终答复时，普通过程默认收起，允许展开完整内容。
- 提问、操作确认、错误、中断、未知执行结果及可下载成果保持独立可见，不因折叠丢失。无可靠完成依据或无最终答复时不自动隐藏。
- Agents 展示名称、任务、进展与结果，不暴露主从关系；不改变实际委派和权限。
- 保留原始历史、顺序、请求归属、草稿、流式更新、手动阅读位置与键盘焦点。刷新和切换会话后展示一致。
- 不修改 Pi 执行机制、提示词、上下文或新增持久状态。只在已有历史投影上补齐展示所需信息。
