# 验证设计

从规范聊天消息验证累积文本、页面投影和 Pi 原生历史。为旧版本展示块和固定引用保留可读恢复路径。依据当前授权处理历史可见性，缺失或失权时给出明确状态。记录取消、组件非法和引用缺失各自的可观察反馈。

分别保留确定性协议回归、真实工具及桌面浏览器联调、实际配置模型试跑的证据。复用既有 Playwright 和当前 Pi 入口。阶段验收覆盖配置开关以及数据和工具服务重启。

- 浏览器在收到 `response.started` 后遇到提前结束或连接异常时，使用已有会话查询机制恢复该请求。以现有终态快照结束恢复提示。由测试代理中断 SSE，在同一请求上核对图表和正文恢复、停止以及固定回执。
- 使用已知有数据的合成标注和 CSV。核对终态前出现的有效组件及其引用、真实工具数值、刷新重读后的回执和下载数量。真实模型使用部署机上的独立 Pi 数据目录，测试完成后清理临时账号和数据。
- [验收指南](acceptance.md) 提供资源概览与明细、文件汇总和五类图表的复现入口。
