# R1.4 历史、异常与阶段验收

## 目标

在 R1.1 至 R1.3 交付基础上验证流式展示、恢复、异常状态与真实模型生成。整理三条可复验入口和已知限制。

## 验收

| 场景 | 通过条件 |
| --- | --- |
| 流式与中断 | 终态前出现可用组件。任意分片、重复快照及终态替换不会重复渲染。取消、断流和无效描述给出状态，保留有效正文及可用部分 |
| 历史与授权 | 刷新、切换和重启后使用同一个固定结果。撤销授权、原数据缺失、旧格式及关闭生成后均有可理解的显示或降级 |
| 桌面布局 | 三栏和窄聊天栏可读。拖拽分隔线、长标签、图例、表格滚动及键盘访问符合预期 |
| 真实模型 | 在实际配置的模型上验证资源查询和一般计算。记录引用正确性、流式生成表现、失败状态和样例 |
| 阶段交付 | 提供资源查询展示、一般计算展示、五类图表样例及复现入口，记录证据和限制 |

R1.1 的确定性模型验收作为回归基线，实际模型和运行环境在验收前确认。
