## 2026-11-24 验收结果

### 桌面与协议回归

- 实际切断聊天 SSE 后，以同一会话重新读取正在运行的请求，消息只提交一次。停止后保留有效图表和正文，未关闭的展示块显示「资源展示未完成」。收到同一请求的终态才清除断流提示。
- 检查了无效的后续补丁、缺失或跨会话引用、旧结果、权限撤销、刷新、切换会话及应用重启。关闭新展示生成后，旧图表仍可回看。
- 桌面分栏覆盖拖拽和键盘调整、长标签、图例、表格横向滚动、键盘展开和分页。五类图表使用实际读取合成 CSV 的确定性测试。
- 5 项 Playwright 浏览器用例及 7 个文件中的 113 项相关 Vitest 通过。类型检查、Lint、构建和差异检查通过。Lint 有两条既有 `InteractionCard.tsx` 警告。

### 真实模型和执行

在 4316 部署机使用同一版 Pi 代码和已启用的平台配置。两个合成任务在隔离目录运行，分别记录工具完成投影、助手流事件、终态和重新打开后的固定回执。模型配置留在部署机，测试结束清理临时目录。

| 模型与案例 | 观察结果 |
| --- | --- |
| `kimi-for-coding` 资源查询 | 查询首次成功前有 4 次工具错误。最终获得 2 项车辆和 1 项设施的固定回执，指标、柱状图和资源明细的有效补丁均在终态前出现。重新打开后回执一致 |
| `kimi-for-coding` CSV 汇总 | 首轮等待 Bash 执行未完成。复验使用预先准备的只读 Python 脚本，在真实 Docker 中调用 Bash 获得甲班 12 件和乙班 8 件。柱状图和表格的有效补丁均在终态前出现。重新打开后回执一致，未发布下载文件 |
| `deepseek-v4.1-flash` 两条案例 | 方舟在工具调用前返回 HTTP 400 和 `InvalidSubscription`。当前默认模型的真实业务验收受方舟订阅状态阻塞 |

真实模型验证覆盖资源查询和 CSV 汇总。五类图表组合覆盖在桌面浏览器回归。测试数据和可复制提示见[验收指南](acceptance.md)。
