# R1.4 验收指南

在桌面浏览器打开 [4316 服务](http://127.0.0.1:4316/)。每条用例使用独立会话。资源测试需要在任务空间内进行，计算测试需要能执行 Bash 的会话。

资源示例已在 `kimi-for-coding` 上通过隔离试跑。默认 `deepseek-v4.1-flash` 当前返回方舟的 `InvalidSubscription`，资源查询和文件计算均在工具调用前结束。

## 1. 资源概览和明细

选用已有且含资源条目的标注版本，或在测试任务中准备两个车辆和一个设施的资源点，标明它们是实际资源且已分配给此任务。在地图的标注组菜单选择「引用此版本」，确认输入区出现标注引用，再发送。

```text
请只查询我引用的固定标注版本，用 task_resource_query 统计本任务的车辆和设施。在聊天中显示按类别统计的柱状图和可展开的资源明细。概览和明细使用同一份查询结果，用一句话说明范围。不需要下载文件。
```

样例应显示车辆 2 项、设施 1 项。明细默认收起，展开后可核对三个条目和逐项来源。刷新后应看到同一组结果。如果显示「暂无资源条目」，先核对输入区是否选中正确版本，以及标注对象是否有资源类别、实际资源属性和任务关系。只有名称的普通地图点不足以复现本例。

## 2. 文件计算和聊天内展示

将下列内容保存为 UTF-8 的 `工单.csv`，在新会话上传后发送。

```csv
班组,工单数
甲班,5
甲班,4
甲班,3
乙班,2
乙班,6
```

```text
请用 Bash 实际读取附件工单.csv，用 Python 标准库按班组汇总工单数。将计算结果作为工具的数据集输出，在聊天中用同一份结果画柱状图并显示表格。简短说明统计口径，不需要生成或下载文件。
```

如果页面要求确认执行命令，先核对它只读取样例 CSV 并输出数据。柱状图和表格应分别显示甲班 12 件、乙班 8 件。切换会话后再回来，结果应一致。可以在测试工作区中替换原文件再刷新，已发送的图表仍应显示 12 和 8。

## 3. 五类图表

将下列内容保存为 UTF-8 的 `班组表现.csv`，在新会话上传后发送。

```csv
班组,日期,工单数,耗时分钟,质量分,时效分,满意分
甲班,2026-11-20,12,35,86,72,90
乙班,2026-11-21,8,25,91,88,84
丙班,2026-11-22,10,30,78,95,89
```

```text
请用 Bash 实际读取附件班组表现.csv，把日期转成带时区的 ISO 时间，用工具返回的同一份数据集在聊天中画五张图。柱状图比较各班组工单数，饼图显示各班组占总工单的份额，折线图按日期显示工单数，雷达图按班组比较质量分、时效分和满意分，散点图用耗时分钟作横轴、工单数作纵轴。雷达图三个指标的量程都是 0 到 100 分，越高越好，量程来源填本次样例约定。保留一张表供核对，不需要下载文件。
```

应有五张图和一张表。饼图的比例为 40%、约 26.7%、约 33.3%。折线的点依次为 12、8、10 件，散点包含 `(35, 12)`、`(25, 8)`、`(30, 10)`。拉窄桌面聊天栏，检查图例、长标签和表格横向滚动。用 Tab 和 Enter 核对详情可用键盘打开。

## 怎样核对流式和历史

- 观察回复仍显示「停止」时是否已出现至少一张图。真实模型的生成速度会影响肉眼观察，可用浏览器回归中的受控暂停复测时序。
- 在浏览器回归中先等图表出现再停止回复，检查有效图表和正文仍可见。刷新及切换会话后核对已保存的结果。
- 以合成数据测试重启和权限变更。关闭新结果展示生成后，已保存结果仍可读取。撤销授权或缺少固定引用时，应显示不可用状态。
