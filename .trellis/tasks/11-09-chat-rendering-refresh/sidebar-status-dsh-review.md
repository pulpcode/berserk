# 侧栏状态提示：直接采用 DSH Web 交互

日期：2026-11-13。状态：2026-11-13 用户已批准，实施及本地验证完成，待用户验收。用户已选择直接采用 DSH Web，不采用此前自定义的折叠分组汇总方案。不新建 Trellis 任务；本记录沿用当前聊天 UI 分支。

## 目标与范围

替换任务空间标题旁含义模糊的数字和会话状态呈现，采用 DSH 的分组、会话状态位置、待交互文字及悬停详情。范围限于当前侧栏状态提示，不扩展为整个 DSH 侧栏功能迁移。

## 固定参考与事实

DSH 参考版本：`39163dd30f703a79079e2d2446545cff3c453738`。

来源：[Rows.tsx](https://github.com/deepseek-ai/deepseek-harness/blob/39163dd30f703a79079e2d2446545cff3c453738/packages/client/ui-workspace/src/client/rows/Rows.tsx)、[ui-workspace README](https://github.com/deepseek-ai/deepseek-harness/blob/39163dd30f703a79079e2d2446545cff3c453738/packages/client/ui-workspace/README.md)。仅参考交互，沿用本项目组件实现，不引入 DSH 插件运行时。

- `ProjectRow`：文件夹、标题及悬停操作，无运行/未读/需关注汇总数字；折叠时也不增加状态汇总。
- `SessionRowItem`：左侧固定 16px 状态位置，然后是标题；右侧通常显示简短更新时间。待交互时，右侧替换为对应短标签。
- `sessionStatuses`：待交互优先，随后是运行（含子任务），再是完成提醒。只显示主要状态标记；空闲行不画状态点，但保留对齐位置。
- `SessionHoverContent`：展示完整标题、时间及各项相关状态。HoverCard 首次延迟 800ms，键盘聚焦同样可触发。详细信息不挤在列表行里。
- [StateDot.module.css](https://github.com/deepseek-ai/deepseek-harness/blob/39163dd30f703a79079e2d2446545cff3c453738/packages/client/ui-primitives/src/StateDot.module.css)：静态状态采用约6px实心点，运行采用中性转圈；侧栏不沿用原来待交互的大点与光圈。颜色沿用本项目主题，不迁移整套主题。

## 本地采用规则

1. 去掉任务空间标题旁的处理中/需关注数字，展开和折叠均如此；不新增分组聚合点、数字或弹出统计。
2. 会话状态从标题右侧移到左侧固定位置；处理中转圈、未读完成点、待交互警示点、空闲留白。
3. 待回答与待确认显示明确的右侧短标签，并优先于转圈；普通会话右侧显示基于现有更新时间的简短时间，完整时间可查。
4. 会话悬停或键盘聚焦显示完整标题、所属任务空间、完整更新时间和状态。首次延迟 800ms，不因查看详情切换会话，不裁切在侧栏滚动容器中。
5. 继续使用现有请求状态、后台作业与未读判定。失败、中断和恢复异常沿用真实数据，以错误状态展示；本地没有 DSH 的计划审阅状态，不凭空增加。
6. 保留现有任务空间进入入口、分组折叠、新建对话和键盘操作，以及桌面窄面板适配。

## 实施边界

主要影响 `WorkspaceNavigation.tsx`、`styles.css` 和侧栏浏览器回归；悬停详情可按本项目组件组织方式拆成小组件。无需后端、公共事件、持久记录或数据迁移。

本轮不迁移排序、搜索、置顶、归档、拖拽、重命名、目录树、插件插槽和 DSH 整套主题；不修改聊天正文、输入区和 C 轮交互卡。既有 4316 修复版本保持，部署不属于本次设计确认。
