# C 轮修复方案 v0.3（已批准实施）

日期：2026-11-12。基于当前 C 轮测试版及本次反馈；用户已批准提交方案、实施、验证并更新既有 C 轮线上测试版。

## 核心方向

**本轮集中修复提问卡、确认卡，以及它们在聊天列表中的对应记录。** 这些部分参照 DeepSeek Harness Web，保持简洁；沿用 Axon 的配色、字体及已有业务规则。

A 轮已经调整的正文排版、普通消息和工具过程展示继续保留。先完成 ABC 三轮，再统一评估前端整体交互效果，本轮不扩展为聊天列表全面改版。

## 1. 提问卡怎么改

| 内容 | 调整后的行为 |
| --- | --- |
| 卡片结构 | 直接突出当前问题，移除重复的“需要你的回答”“待回答”和顶部题号；题号放在底部分页。 |
| 选项 | 使用紧凑选项行，缩减大边框和留白；长题目、选项说明可就地展开全文。 |
| 自定义回答 | 在选项末尾的“输入你的答案…”一行直接填写，随内容适度增高；不另弹出一块大输入框，不重复显示“填写自定义回答”。无选项的题目直接提供输入区。 |
| 问题切换 | 左下角显示 `‹ 1 / 4 ›`，可回看和修改，答案保留。翻页本身不算回答或跳过。 |
| 自动下一题 | 单选后自动进入下一题；多选点击“下一题”，文字回答按 Enter 或点击“下一题”。Shift+Enter 换行，中文输入法确认文字时不翻页。最后一题不自动提交。 |
| 跳过 | 改为“跳过本题”，只跳过当前题并继续；其他题已填内容保留。最后一题跳过后仍需明确提交。 |
| 提交 | 未处理完全部问题时不显示“提交回答”；全部回答或明确跳过后，主按钮切换为“提交回答”。跳过不视为选择默认答案，也不代表操作授权。 |

当前只有“跳过整组”的能力。需要小范围补齐逐题跳过的记录、提交校验和 Agent 返回结果，让系统分清“未填写”和“主动跳过”；已有历史记录继续可读，不用空字符串冒充跳过。

## 2. 确认卡与停止按钮

- 提问或确认卡占用输入区时，移除独立停止按钮，也不在标题栏或其他位置补一个停止入口。提问收起、多卡接续、提交中或等待查询结果时，同样不显示停止按钮。
- 提问通过回答或跳过处理；确认通过允许或拒绝处理。拒绝当前操作不等于停止整次请求，不修改其后台含义。
- 服务端接收交互结果、所有待处理卡退出后，如果 Agent 仍在生成或执行，恢复普通运行中的既有停止按钮。
- 确认卡突出具体操作、对象、影响和主要按钮。同一风险说明只出现一次，完整命令和实际附件仍可核对；长内容内部滚动，操作区保持可见。
- 提问可收起，确认卡不可收起；不增加关闭后重新打开、稍后处理或新的授权方式。

## 3. 只精简卡片对应的聊天记录

处理输入区卡片的同时，精简它在聊天原位置留下的状态和结果，避免同一交互重复占据大块空间。

| 内容 | 默认显示 | 展开后 |
| --- | --- | --- |
| 等待回答／确认 | 一行“提问 · 等待回答”或“确认 · 等待确认” | 不再复制操作表单，也不显示“请在下方输入区处理”等说明 |
| 已答问答，包括多题 | 参照 DSH，放在一个紧凑的用户问答气泡内，逐题显示问题和实际答案；跳过按实显示 | 不额外默认折叠整组；未选选项集中放在对应工具的只读详情，不逐题铺设“查看全部选项” |
| 已跳过、取消或失效的提问 | 紧凑状态记录，按实际结果显示 | 原题只读可查，不显示成已回答 |
| 确认结果 | 紧凑行，保留具体动作、用户决定及执行状态 | 核对操作内容、附件和实际结果；失败、取消、未执行、结果未知必须在摘要中可辨认 |

已答问答不再使用“回答记录”大标题、整幅状态栏或每题一个灰色大答案框。篇幅通过气泡宽度、字号、题间距和去除重复结构收敛，不擅自截断实际问题和答案。

确认后的记录缩减为一条紧凑行：具体命令摘要或操作对象、用户决定、执行结果同排显示，缩减上下留白；完整内容点击展开。每次真实操作独立保留，不因标题相同而合并。

## 4. 与 DSH 的对应关系

已核对固定版本源码：DSH 支持行内文字回答、左下角分页、单选自动翻页和逐题跳过；最后一页的主按钮为提交，并在提交时检查整组是否完成。

DSH 的已答历史是完整问答气泡，**并非默认整组折叠**，本版跟随这一呈现方向。“答完才出现提交”“最后一题跳过后不自动提交”是为本项目明确提出的行为；卡片期间不提供停止入口已按用户要求确定，不声称外部源码证明 DSH 所有位置都没有停止功能。来源见 [源码核对记录](research/c-repair-reference.md)。

## 5. 完成后怎么验收

1. 用同一组单选、多选、文字和长文案问题，对照 DSH 检查行内填写、自动翻页、分页、跳过及提交时机。
2. 对照待回答、回答后、待确认、确认后截图，检查卡片及对应记录的密度、展开层次和重复文字；核对相邻普通消息、正文和工具过程展示没有回退。
3. 验证逐题跳过、全部跳过、回改答案；刷新后草稿保留，Agent 能区分回答与跳过。
4. 验证卡片期间无停止入口、交互结束后普通运行恢复停止；同时验证拒绝、多卡顺序、服务端接收后退出、提交结果不确定时查询，不重复提交、不串会话、不抢阅读位置或键盘焦点。
5. 检查桌面宽窗口、窄聊天面板及地图分屏；长内容可查看，按钮不被挤出页面。

本次不调整 A 轮正文排版、普通消息、通用过程行与整体折叠规则，也不改造普通文件卡。B 轮的工具结果专门视图、实时输出、diff 和新增文件预览仍另行安排；ABC 完成后，由用户再评估整体前端效果。

本次不改变工具执行权限、业务流程、消息队列和模型配置，不新增聊天展示模式或第二套交互记录。获批后再同步原 C 轮设计和验收用例。
