# B 轮首批优化方案

版本：v0.1，2026-11-13。状态：用户于 2026-11-13 批准方案并要求开始首批优化。

**本批目标：让用户看得懂 Agent 正在做什么，并在完成后方便阅读结果、查阅过程。本批完成不代表 B 轮完成。**

## 1. 本批做什么

| 优化 | 预期效果 |
| --- | --- |
| 实时思考展示 | 模型实际返回可展示的思考文本时，出现「思考」行并实时更新简短预览；点击可查看完整的已返回文本。 |
| 工具展示细化 | 工具行显示具体动作、路径或命令和真实状态；展开后查看输入、输出或文件修改差异。 |
| 整轮耗时与折叠 | 进行中展示过程行，正常完成后收为「已完成，用时…」入口；点击可逐层查看过程。 |
| 历史与模型兼容 | 刷新后仍能查看已有证据；界面不绑定 DeepSeek，缺少思考、时间或详情时自然回退。 |

交互以 **DSH Web 的 Detailed + All replies + 完成时收起**为主要参考；命令、输出、diff 分开呈现的方式参考 Codex App。沿用当前产品字体、颜色和桌面分屏布局。

## 2. 进行中和完成后

**进行中：过程行直接可见，单条详情默认收起。**

```text
我先读取资料，再核对差异。          ← 普通进度说明

▸ 思考 · 正在核对任务与资料的关系…   ← 预览随真实返回更新
▸ 读取文件 · /workspace/brief.md    已完成
▸ 执行命令 · python analyze.py     执行中

已完成资料读取，正在整理结论。      ← 后续进度说明
```

点击思考行查看已返回的思考文本；点击命令行查看完整命令与实时输出。没有输出时显示「等待输出」，不生成模拟日志。新增内容更新原行，不重复堆卡片。

**正常完成：收起执行过程，保留全部普通回复。**

```text
我先读取资料，再核对差异。

▸ 已完成，用时 23 秒               ← 整轮过程入口

已完成资料读取，正在整理结论。

最终回答……
```

展开入口后，按原位置显示各过程段摘要；展开过程段可看到思考、工具行，再点击单条查看详情。**折叠只隐藏过程，不搬动消息，不隐藏进度说明、最终回答、交付文件、交互回执或异常。**

规则：

- 本批固定采用「完成时收起」，不增加多种显示模式和折叠时机设置。
- 成功终态且最终答复可见时才自动收起；失败、停止、结果未知或缺少终态证据时保持过程可见，并显示实际状态。
- 过程开始后有已消费的用户补充或引导消息时，保留分段结构，不使用整轮折叠跨越该输入。
- 用户手动展开、向上阅读或焦点在详情中时，不强制收起、不抢滚动位置。单条工具结束不触发整轮完成。
- 纯文本回答不生成空过程入口；可以显示无展开箭头的完成耗时。没有可靠起止时间时只显示状态，不猜时间。

## 3. 工具执行中、执行后分别显示什么

| 工具类别 | 执行中 | 执行后 |
| --- | --- | --- |
| 文件读取、目录与查找 | 路径、范围或查找条件、运行状态 | 保留摘要，展开查看实际返回内容；有真实行号时显示行号 |
| Shell 命令 | 完整命令可展开；输出随真实事件更新 | 保留命令和最终输出，失败有明确标记；有可信退出码时显示 |
| 文件编辑 `edit` | 目标路径和修改中状态 | 展示原生 diff；有明确增删证据时显示数量 |
| 文件写入 `write` | 目标路径和写入中状态 | 展示实际结果；没有原生 diff 时不伪造修改前后对比 |
| 业务工具、Agent 及其他工具 | 简洁动作和状态；详情按需展开 | 保留现有业务结果卡、Agent 摘要和结果文本；本批不逐个重做专门视图 |

命令、路径等长内容在详情内完整可查；长输出局部滚动，截断时明确提示。展示经过现有授权和校验的数据，不直接公开内部参数或原始元数据。

## 4. 思考展示与模型边界

- 展示供应商经 Pi 返回的可见思考文本或摘要；完整内容指「完整的已返回文本」，不代表模型全部内部推理。
- 思考行默认收起，正文通过点击查看；不把思考混入普通回答，不额外调用模型生成思考摘要。
- 前端按统一内容类型展示，不判断模型名称。无思考返回、思考关闭或仅返回不可展示数据时，不生成空思考行。
- 本批验证当前已配置模型和通用的有/无思考返回场景；Kimi、Qwen 的真实接入、配置和供应商差异适配另行安排，不承诺仅切换名称即可使用。

## 5. 本批验收

1. 思考、正文和工具交替到达时，顺序正确；展开能看到持续更新的真实内容。
2. 读取、命令、编辑、写入及未适配工具均有可理解的展示，缺数据有回退；命令输出不重复累加，diff 不伪造。
3. 正常完成显示真实耗时并按规则收起；失败、停止、未知结果和用户补充不会被隐藏或误报完成。
4. 刷新、断线重连、切换会话和读取旧历史时，归属、内容、状态一致；不丢普通回复、引用、Skill、文件或 C 轮交互。
5. 自动折叠不打断阅读和键盘操作；宽窗口、窄聊天面板及地图分屏均可读。展开、收起不触发工具或业务写入。
