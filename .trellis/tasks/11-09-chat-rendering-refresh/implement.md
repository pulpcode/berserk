## 8. 代表场景与证据

| 场景 | 应保留的证据 |
| --- | --- |
| 纯文本、Markdown、宽表格、长链接 | 正文对齐、局部滚动、无空过程 |
| 说明与多个工具交替、进行中及成功完成 | 原时序、说明常显、分类摘要及默认收起 |
| 工具失败/中断/未知结果、旧历史缺终态 | 独立可见、无成功误判 |
| 单/多文件、长中英文名、交接附件 | 固定链接、真实附件数量与紧凑布局 |
| 待确认、批准但结果未知、拒绝/失效 | 决定与执行分离、关键内容可审阅 |
| 多题、自由文本、已回答/已跳过 | 草稿、答案匹配及摘要可查 |
| 排队/引导/撤销/取回、会话切换与向上阅读 | 顺序、状态、焦点与阅读位置 |
| 桌面 1440px、960px 及实际聊天/地图分屏 | 由可用面板宽度决定布局，不增加手机端专项验收 |
