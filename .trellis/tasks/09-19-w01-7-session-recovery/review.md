# W01-7 审阅入口：中断后原会话续聊

日期：2026-09-19。状态：**已实现，自动验收通过，待用户验收**。

本期优先沿用 Pi 原生能力：加载已有会话，用户发新消息后继续。Axon 只调整当前一律阻止续聊的限制、旧交互解析与网页提示。

## 请重点审阅

| 事项 | 本期方案 |
| --- | --- |
| 怎样继续 | 原会话显示中断提示，用户自己发送下一条消息 |
| 历史与状态 | 根据已有请求记录判断中断；打开／重启不修改 JSONL，不追加中断记录 |
| 上下文 | 沿用 Pi 历史组装、缺失工具结果配对及默认压缩；不加恢复提示词或恢复摘要 |
| 旧问题和确认 | 待处理项失效；已保存决定保留，新操作需要时重新确认 |
| 网页范围 | 复用现有快照、最后请求状态、草稿和导航，不新增恢复中心或状态时间线 |
| 已有保护 | 历史／归属异常、持久化失败、未结束或不一致的子任务，以及相关沙盒初始化失败继续阻止处理 |

系统不会自动重放旧调用；模型在新请求中仍可能提出相同的新调用。本期保留现有工具能力与命令规则，不提供任意操作去重。
