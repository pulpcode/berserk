# W01-4 实施方案

日期：2026-09-17。状态：**已实现，D01～D13 组合验收通过**。开发依据为 [PRD](prd.md)、[设计](design.md) 和 [验收清单](acceptance.md)。

## 1. 开发顺序

| 步骤 | 工作 | 退出条件 |
| --- | --- | --- |
| P0 SDK 接入验证 | 用现有确定性模型替身验证父工具调用独立子 AgentSession、onUpdate、失败标记和 abort；核对独立原生保存 | 不修改 Pi 内部代码即可完成委派与取消，记录实测；失败先修正方案，不绕过公共 SDK |
| P1 角色配置与会话复用 | 加入受控 Markdown 加载／校验，预置 analyst、reviewer，将角色目录暴露给主 Agent；提取共享会话逻辑，按选定角色加载提示和工具 | 添加合法角色文件无需修改委派代码；角色及权限在请求内固定；子无写入／Shell／递归能力，不混入父历史 |
| P2 委派、历史及用量 | 加入 subagent 工具、父子生命周期、原生文件关联、严格记录校验、故障收敛及独立用量 | 子结果返回后主继续；父取消与截止时间覆盖子；重启不重做，旧历史可读 |
| P3 Web 接入 | 新 DTO／SSE、父快照投影和可展开子任务卡；复用停止、活动概览与未读逻辑 | 切换和刷新保持原请求状态，结果不串会话，无新增诊断入口 |
| P4 验收与记录 | 完成 D01～D13、受影响回归和真实模型验证；记录限制、更新已实现规范 | 分别报告确定性、浏览器及真实 API 证据，包括多角色选择与工具权限差异 |

P0 已通过真实 Pi SDK 与确定性模型流验证；P1～P3 已实现。P4 的检查和真实模型证据见 [验收记录](research/validation-results.md)。

## 2. 预计涉及位置

- `experiments/harness-lab/src/pi/`：会话创建共享逻辑、subagent 执行模块、只读工具、严格历史投影与 usage；Pi 依赖留在本层。
- `experiments/harness-lab/fixtures/agents/`：预置通用角色文件；复用 Pi 公开 frontmatter 解析，补充本项目的目录、字段和工具校验。
- `src/contracts/index.ts`、`src/server/app.ts`：公开子任务契约和既有快照／SSE 接口接入；不增加任意子任务启动 API。
- `src/web/`：子任务卡片、流和历史合并、状态与停止；沿用现有组件风格。
- `tests/pi/`、`tests/e2e/`：隔离／生命周期／保存故障测试与产品交互回归；`scripts/` 增加显式真实委派探针。
- 实现完成后再更新 `.trellis/spec/` 的已实现契约，规划阶段不将设计当作现状。

## 3. 检查与真实验证

开发时运行受影响测试；交付前运行 typecheck、lint、test、test:e2e、build。确定性测试使用临时数据目录和可控模型流，不产生真实费用。至少覆盖多角色加载与权限差异、配置更新／删除的生效边界、子压缩／重试期间取消、父子保存缺口和双工作区同时运行。

真实验收使用现有 DeepSeek 配置，在隔离数据目录分别以资料分析、内容检查目标验证角色选择、实际执行与主 Agent 综合，并验证执行中停止；若需触发长上下文，使用独立测试压缩参数，不改用户模型设置。保存实际调用与费用相关 usage，沿用用户未设置验收总请求数上限的约定，避免无关重复调用。

现有 API Key 可用时无需新增凭证；若缺失或失效再告知用户。本阶段无需服务器账号或密码。

## 4. 兼容与回退

不升级 Pi，不改写 `.env.local`，旧会话不要求新增子任务记录。测试与真实探针不得重置用户数据；首次运行新版本前，在服务停止状态下备份完整 LAB_DATA_DIR。

新增 berserk 记录会被旧版严格校验器拒绝，不能假设旧程序能继续打开新产生的会话。回退使用对应版本和独立备份目录，保留升级后数据供检查；不删子文件来伪造兼容。正式迁移和运行中切换后置。
