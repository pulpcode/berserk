# W01-4 验收清单

状态：**已完成 D01～D13 组合验收**；具体证据及复用测试边界见 [验证记录](research/validation-results.md)。本期验证 S2c 能力，不提前宣布完整 T、FG 或业务 AC 通过。

| 编号 | 场景 | 必须观察到的结果 | 证据 |
| --- | --- | --- | --- |
| D01 真实委派与综合 | 分别要求委派资料分析、检查含资料错误的草稿 | 主根据职责选择适当角色并实际调用 subagent；子结果有资料依据，主综合后回答；普通聊天可以不委派 | SDK 集成＋真实 API 记录 |
| D02 多次委派 | 同一请求先调用 analyst，再调用 reviewer，并再次复查 | 每次独立子会话，显式传新 task；single 支持先后选择不同角色；同父最多一个活动子任务，调用记录不会覆盖 | 确定性集成 |
| D03 上下文与项目隔离 | 两个工作区同时处理；父历史放置不传给子任务的识别文本；父请求期间修改 AGENTS.md | 子只见自己的 task 和父请求资源快照；不自动继承父历史或另一会话；新指令下个用户请求生效 | 输入捕获＋资源断言 |
| D04 权限与角色 | 要求子写指令、调用 Shell、递归或使用角色未声明的工具；构造未知 agent、cwd 或多余权限字段 | 实际工具集合受角色声明和宿主权限限制；非法委派参数不启动子模型；只读指令返回 editable=false | SDK 工具／参数测试 |
| D05 停止与迟到结果 | 创建子会话、读取工具、模型输出时分别停止；切会话后再返回 | 显示正在停止直到父子收敛；后续无新调用；迟到结果不改变其他请求；草稿保留 | 集成＋浏览器 |
| D06 压缩与失败 | 子触发自动压缩；另测摘要失败、截断、空最终正文、过长子结果导致父超限 | 默认压缩独立保存；失败／不完整结果不能当通过；父超限按 Pi 恢复或明确失败，不新增摘要补救循环 | 原生记录＋受控模型流 |
| D07 重试与时限 | 子瞬时失败后原生恢复；重试／压缩等待中取消；显式父截止时间即将到达后委派 | 原生重试有界，停止覆盖等待；子不重置父时间；关闭总时限时持续任务不被旧 8 次／120 秒等配置截断 | 时钟／故障集成 |
| D08 保存及重启 | 完成后重启；分别在父开始记录、子保存、父结束记录／工具结果附近注入保存失败或退出 | 已完成原文与关联可读；未完成／未完整提交明确提示，不自动重做；子不进入普通会话列表；旧会话仍可读 | 独立进程与文件证据 |
| D09 切换及刷新 | 子执行中切项目、刷新、网络断开重连；完成后再次加载 | 查询快照恢复同一卡片；不重复委派、不混入其他会话，不把子完成当父完成 | 浏览器＋请求计数 |
| D10 用量归属 | 主子都包含回复、工具、摘要及一次缺失 usage 的中断调用 | 父自身与子自身分开；总计不重复，未知项保留，非调用次数推算 token／费用 | 汇总与原始响应比对 |
| D11 产品交互 | 键盘操作、窄屏、阅读旧消息时完成、失败后查看不同角色卡片 | 实际角色／职责／任务／状态／结果清楚，不固定显示 reviewer；停止整次处理；不抢焦点或滚动；仅父完成产生未读；无内部推理及诊断按钮 | 浏览器验收 |
| D12 工程回归 | 运行类型、静态、单元／集成、浏览器和构建检查 | W01-1～3 既有行为保持；公共 DTO 无 Pi 类型、密钥和内部路径；用户数据和配置未被测试修改 | 检查记录 |
| D13 角色文件与生效 | 增加第三个合法角色文件；请求期间修改／删除角色；测试 tools=[]、重复名称、缺字段、越权工具和未支持字段 | 新角色无需改代码即可发现／调用；父只加载角色目录，子按选定正文及工具执行；变更下个请求生效，旧结果仍按保存版本可读；无工具角色确实无工具；非法配置明确报错，不回退或扩大权限 | 加载器＋真实 Pi 输入／工具集合及历史断言 |

D01 真实模型结果需要语义核对：所选角色是否适合目标、子结果是否有资料依据、主是否实际采纳或有理由解释，不能只检查调用次数或角色名称。D05 另保留一次真实执行中停止的证据。

父会话、子会话原始 JSONL、公开 DTO 和模型实际输入分别核对，避免“页面看似正确”掩盖上下文串用。记录中只保留必要的脱敏证据，不记录 API Key 或内部推理内容。
