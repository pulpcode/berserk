# 会话独立地图标注与任务发布需求

状态：实施中；设计基线形成于 2026-10-12，2026-10-13 获准实施。

## 目标

让人员在不同任务、不同会话中围绕地图独立讨论和编辑标注，按权限引用其他会话的明确版本，并将选定成果发布到任务。有现有任务管理权限的人可将已发布版本设为任务当前标注，不建设审批流程。

核心对象称为“标注集”，不要求讨论必须形成业务方案。标注集管理归属、版本与发布，内部图层管理内容组织，点线面与文字对象保留各自业务语义。

## 已确认的基础与决定

- 用户已确定：每会话独立草稿、跨会话可查看引用、发布后由具备现有任务管理权限的人设为当前标注；不做审批。
- 工作区当前按任务 × 席位隔离，同一工作区会话共享普通文件；用户身份与席位不同，当前每个席位最多一个启用账号。依据见 [研究记录 E1、E2](research/evidence.md)。
- 设计前的地图用 MapLibre GL 6.4.0 展示来源态势，尚无人工绘制或 Agent 标注写工具。独立模拟控制修改共同模拟源，不具备私人草稿语义。[E3、E4](research/evidence.md)
- 颜色、虚线、轮廓和纹理可能承载业务语义，不能统一用它们编码草稿／发布状态；通过图层组、文字状态、版本及当前编辑目标表达工作状态。
- 来源态势与人工标注分别呈现；发布或设为当前，不把假设变成事实，也不修改来源数据。

## 需求

| 编号 | 可观察要求 |
| --- | --- |
| MA01 | 草稿归属任务 × 席位工作区，并绑定唯一编辑会话。首期一个会话最多一份可写草稿，其他会话只能读取获准修订或派生自己的草稿 |
| MA02 | 会话可选空白或获准的固定版本为基线；只查看不创建草稿，第一次修改才建立草稿。任务当前标注更新不改变已有基线或草稿 |
| MA03 | 标注集包含具名图层及点、线、面、文字注记；支持创建、编辑、删除对象和基本业务样式，明确当前可写图层 |
| MA04 | 每次完成的保存产生不可变修订。跨会话引用、历史消息和已发布成果固定到明确修订，不读取最新内容来替换旧依据 |
| MA05 | 同席位、同任务的会话可以查看彼此草稿；跨席位只能读获准的已发布内容；不因公开任务或管理权限开放私人草稿及来源会话 |
| MA06 | 发布一个明确保存修订到任务；发布版本不可变，草稿仍可继续编辑。发布不设为任务当前，不自动通知或触发分析 |
| MA07 | 具备现有任务管理权限的人可将已发布版本设为当前标注，保留历次设定记录。不要求另一人批准，不建设审批状态或审批角色 |
| MA08 | 设为当前采用完整版本，不自动合并；展示与现有当前版本的差异及旧基线提示。并发设定冲突不能静默覆盖 |
| MA09 | 全局地图保留共同态势；任务地图提供当前标注、我的草稿、已发布版本与历史入口；会话地图突出自己的草稿和只读参考组 |
| MA10 | 图层组持续标识来源／草稿／已发布／任务当前及具体版本。支持开关、独显、定位和重叠对象选择；打开参考组不能改变编辑目标。状态不改写业务颜色、线型或符号 |
| MA11 | Agent 与人工通过同一业务服务读写。宿主自动提供当前会话草稿身份和起始修订，Agent 按需读取内容，无需用户每次显式引用；主 Agent 只能修改当前会话草稿。发布、设为当前须按明确用户指令和权限执行，无业务审批流程 |
| MA12 | 保存检查草稿修订并保证操作幂等；编辑期间发生冲突保留本地输入。已有消息排队和引导不改变会话绑定，不自动切换引用版本 |
| MA13 | 权威标注内容不作为普通共享工作区文件暴露给文件工具。任务、席位、会话绑定和资料范围由服务端检查，浏览器与模型不能自报权限 |
| MA14 | 刷新、重启、关闭会话页面后已保存成果仍可读取；旧原生聊天依据保持不变。任务归档后只读，首期不提供成果硬删除和自动历史清理 |
| MA15 | 外部态势继续显示实际来源、查询时间和模拟标记；标注快照不宣称冻结外部态势或底图。来源故障不妨碍独立读取已有获准标注 |
| MA16 | 自动草稿上下文仅含固定少量标识与状态，不随图层／对象数量增长；显式 annotationRefs 仅带经核实的固定引用和有界描述性元信息。几何及业务属性按需按范围读取。不以压缩上下文为由改变固定引用或重写原生历史，不新增专用摘要缓存或记忆系统 |

## 验收

| 编号 | 场景与通过标准 | 对应需求 |
| --- | --- | --- |
| AC01 | 两席位、两任务、同席位两个会话交叉验证：各自草稿写入互不影响，越权 API 和深链接均拒绝，任务管理员读不到别人的私人草稿 | MA01、MA05、MA13 |
| AC02 | A、B 从相同任务版本派生；A 编辑、发布并设当前后，B 的基线、地图草稿和历史讨论不变 | MA02、MA04、MA06、MA07 |
| AC03 | B 引用 A 的获准 r3，A 保存 r4；B 当前引用及重开旧消息仍显示 r3。普通来源对象入口仍按既有约定读取当前态势并标明旧依据 | MA04、MA15 |
| AC04 | 人工与 Agent 都能在自己的图层创建、改动和删除点线面／文字；只读参考组无法进入编辑，重复对象位置可选到正确版本／图层／对象 | MA03、MA10、MA11 |
| AC05 | 发布后其他获准席位可查看；继续修改草稿不改变发布内容，发布过程无审批记录，不自动切换任务当前 | MA05、MA06、MA07 |
| AC06 | 无任务管理权限者不能设当前；有权限的发布者本人可以直接设当前。私人空间按所属席位规则处理 | MA07、MA13 |
| AC07 | 两人从同一当前序号设定，只有第一次成功；第二次返回冲突。旧基线的发布版本可在明确比较当前版本后被完整设定，不进行暗中合并 | MA08、MA12 |
| AC08 | 人工先将 r5 保存为 r6，Agent 基于 r5 的写入拒绝；同一动作重试不产生重复版本；响应丢失可查询回执，不伪造原生工具成功记录 | MA11、MA12 |
| AC09 | 草稿、发布、当前之间切换不改变对象业务样式；来源态势、编辑草稿和参考组均有明确标签；视图开关不改变别人的地图或已发布数据 | MA09、MA10 |
| AC10 | 切任务、席位、会话及迟到请求不会串写；消息排队／引导保留本会话范围和既有文本排队边界；停止请求后不接受新工具操作 | MA11、MA12、MA13 |
| AC11 | 重启恢复版本和设定历史；任务归档拒绝新写入；旧聊天、交接、对象引用与来源权限回归通过 | MA04、MA14、MA15 |
| AC12 | 真实模型在未显式引用自身草稿时，仍能读取已绑定修订完成讨论和修改；下一条普通请求能识别手工保存后的新修订，未保存缓冲不被当作已读取内容。另覆盖自然语言创建、固定版本比较及显式发布／设当前；保留实际误选对象、额外询问、漏调用及失败，不把请求成功等同语义正确 | MA03、MA04、MA11 |
| AC13 | 小草稿与大草稿的普通问答默认输入均不含图层清单、业务属性和几何；多轮无关问答不触发宿主自动读取草稿全文。显式引用两个对象时，初始输入仅含引用及描述性元信息，比较位置只按需读取所需几何；明确要求全局分析时才扩大范围。记录元信息、工具定义、结果及多轮累计占用；原生压缩后仍能按固定修订重读 | MA04、MA11、MA16 |
