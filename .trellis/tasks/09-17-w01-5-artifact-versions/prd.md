# W01-5：Web 通用文件作业（S3a）

日期：2026-09-18。基线：670cb3c。状态：**已实现并通过 E01～E15 组合验收**。

## 1. 目标

基于现有 Pi 内核，让用户通过网页多轮对话完成文件处理：上传输入文件，Agent 按需读写文件、编写和执行脚本、使用中间产物，再交付可预览或下载的文件。处理方式由任务决定，不预设只能生成 Markdown 文稿。

典型流程：上传 CSV → 要求分析并形成方案 → Agent 编写 Python、运行分析、生成中间 JSON 和图表 → 生成方案及附件 → 用户提出修改 → Agent 修改并重新交付 → 用户下载。普通问答仍可直接回复。

## 2. 已确认的边界

- 继续使用锁定的 Pi 0.85.1；优先复用其循环、文件工具、命令工具、压缩、重试与会话，不自研第二套 Agent 循环。
- 已有项目／会话、多轮对话、AGENTS.md、Skill、默认压缩及 single 只读子 Agent 保持可用。
- 用户从浏览器提供文件，实际处理发生在服务端的受控执行环境；不要求用户填写服务器文件路径。
- 独立工作区跟随席位，并按任务分开：同一任务、同一席位的会话共用文件；不同席位或任务的工作目录隔离，人员交接不改变文件归属。
- 同一工作区的不同会话允许并行执行，聊天与运行控制各自独立；本期不建设跨会话的同文件冲突保护或自动合并。
- 上传成功的文件直接成为工作目录中的普通可写文件，可以原地修改；不强制保留一份只读原件。发送消息只关联文件引用。
- 本期落地最小执行沙盒，验证脚本执行、目录范围、停止清理和文件持久保存；不建设沙盒调度平台。
- 本期不建设成果上报、审批、定稿、发布或业务状态机；文件生成、下载和用户说“满意”均不触发业务提交。
- 仍为单一本地主体的实验工程，不把文件能力扩展解释为多租户或公网部署已就绪。

## 3. 需求与验收

| 编号 | 用户可观察的能力 | 验收 |
| --- | --- | --- |
| F01 文件作业 | 能读取、创建、修改和查找当前席位工作区文件；上传文件、脚本、数据、中间文件与最终文件均可持久保留，不限于文稿 | E01、E02 |
| F02 执行处理 | Agent 能编写并执行 Python／Shell，获得真实输出与错误，据此修正并继续 | E02、E03 |
| F03 上传 | 输入框附件按钮、拖放及项目文件面板上传；逐文件进度、失败重试、移除；同名文件不覆盖 | E04、E05 |
| F04 文件归属 | 文件归“任务 × 席位”工作区；上传完成后，同工作区会话可按需读取，聊天历史仍独立；切换任务／席位不串文件，文件不随人员交接丢失 | E01、E05、E06、E13 |
| F05 上下文 | 发送附件引用和必要元数据，Agent 按需读取或解析；上传成功不等于模型已读取，不自动拼入所有正文 | E06、E09 |
| F06 文件交付 | 当前席位工作区的统一文件列表可查看、引用和下载；对话中的交付卡对应实际存在的文件，下载内容不随后续修改偷偷变化 | E07 |
| F07 多轮续作 | 刷新、重启、压缩或换同工作区会话后，仍可查找文件并继续处理；不自动重放脚本 | E08、E09 |
| F08 并发与停止 | 同一工作区及不同工作区的会话均可并行；停止只影响本次请求及其子 Agent／执行进程，保留已写文件，不虚称回滚 | E10、E11 |
| F09 子 Agent | 现有角色可按权限读取文件并检查；继续禁止写入、执行 Shell 和递归委派 | E12 |
| F10 范围隔离 | 文件与命令不能触及其他任务／席位工作区、宿主密钥、原生会话或平台状态；上传内容不能改变授权或自动成为指令 | E13 |
| F11 网页体验 | 切换会话后保留各自尚未发送的文字和附件引用；上传与文件更新不打断输入；沿用未读蓝点和流式回复；窄屏可操作，上传失败可重试 | E14 |
| F12 真实闭环 | 通过真实 Pi、执行环境、浏览器与模型完成上传、脚本分析、文件交付和多轮修订 | E15 |

文件可按原始字节上传和下载；“可保存”不等于“模型能理解所有格式”。首期验证文本／代码、CSV／JSON、XLSX、DOCX、含文本 PDF 的基础读取或生成，以及 PNG 图表输出。格式能力和网页预览范围见设计；扫描件 OCR、复杂版式还原不作为本期承诺。

## 4. 本期运行边界

参照 Codex Local 的同目录工作方式：会话使用当前工作目录中的文件，不增加工作区级整轮排队。同一会话仍最多一个活动请求。多个会话同时修改同一文件可能相互覆盖，专门的冲突检测、独立工作副本和合并机制后续按实际问题再设计，不作为本期前置工作。

本期只用服务端固定测试席位和最小归属映射验证隔离，不建设真实登录、人员交接或业务任务状态管理。

## 5. 本期之外

成果状态与版本库、上报／审批工具、完整 Run 状态机与恢复队列、业务任务分派、外部调度、多人协同编辑、自动合并／Git worktree、跨会话聊天检索、浏览器控制及长期后台进程，均不纳入本阶段。

不提供浏览器内完整 IDE、Office 所见即所得编辑器、任意宿主目录挂载或运行时任意联网安装依赖。文件处理环境预装常用依赖，缺失能力明确报告并通过后续环境配置补充；不承诺与 Codex 等产品全部功能等价。
