# R1 聊天内流式结果展示与组件化

## 阶段目标

用户能在原桌面聊天中看到逐步形成的结果展示，核对图表数值和来源，并在重开会话后回看同一结果。

## 轮次与依赖

| 任务 | 交付与依赖 |
| --- | --- |
| [R1.1 流式展示闭环](../11-24-r1-1-streaming-result-ui/prd.md) | 在原聊天中用真实固定资源结果流式显示指标和柱状图，建立基础历史恢复 |
| [R1.2 通用计算结果与五类图表](../11-24-r1-2-result-datasets-and-charts/prd.md) | 基于 R1.1 的展示通道，接入固定计算数据、表格和五类图表 |
| [R1.3 资源结果组件化与展示规则](../11-24-r1-3-resource-result-components/prd.md) | 基于 R1.1 的资源结果及授权语义独立推进。组合使用的其他图型随 R1.2 接入 |
| [R1.4 历史、异常与阶段验收](../11-24-r1-4-result-ui-acceptance/prd.md) | 验证前三轮的历史恢复、异常和桌面交互，提供[验收指南](../11-24-r1-4-result-ui-acceptance/acceptance.md) |

## 阶段验收

- 提供资源查询展示、一般计算展示、五类图表样例三条体验入口。
- 两条真实工具链路均可在同一聊天回复内逐步渲染，数值可追溯，刷新、重入和重启后恢复。
- 完成桌面分栏、异常降级和真实模型验证。记录验证环境、证据和已知限制。

自由 HTML、SVG、JS 制图，以及结果编辑和持久化为后续方向。
