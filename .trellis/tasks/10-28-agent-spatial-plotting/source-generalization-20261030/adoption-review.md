## 可以直接借鉴什么，必须补什么

| 内容 | 采用方式 |
|---|---|
| 8 道主测题、各自几何与标准答案 | 原题保留。相同数量不同名单、零命中、标签不等于几何、同名不同对象均有针对性 |
| 资源来源与边界来源分别决定 | 采用。两者独立未知时允许澄清或四组合条件回答，不回溯重判旧题 |
| 原生标绘与来源数据接口 | 可以承载这些数据；需完整替换旧模拟系统场景和任务配置，不只是增加新点 |
| 资源点筛选 | 当前空间入口不自动过滤 Point 或 resource；必须让模型正常查询并选择对象，不让适配器泄露标准候选 |
| 两项独立追问 | 包内规则合理，但现有单次固定回复流程不够；需接入原生文本回答并逐项记录哪些要求已明确 |
| 冻结记录与预算 | 包内模板为空，不能直接作为执行配置；本轮方案补充具体模型、产品基线、请求/token 上限和停止条件 |
| 解释判分 | 将“模型自行选择却说成用户指定”明确列为严格失败；不能只检查最终数字 |
| 保留题隔离 | 本轮只保存原包不展开；这是流程上的隔离，不声称文件加密或后续开发者无法访问 |

## 与旧评分的关系

分享讨论对上一轮 Flash A1 的用户选择归因提出了争议：仓库旧报告记为表达问题，外部讨论认为应扣严格分。本轮把这类事实归因明确冻结为失败标准；条件表达与真正用户指令仍分开判断。

不改写上一轮报告和分数，也不把这次明确口径后的结果与旧严格分作简单涨跌比较。如果后续需追溯重判旧 A1，应单列复核记录，不覆盖原始判定。新题的从零流程、G2 产品基线和四组合要求也不同于旧 G1 现场续跑。

## 范围限制

这些是小数据、简单矩形内外关系的诊断题。它们能检验来源选择、筛选与解释，不能证明真实业务泛化、复杂几何、大量分页或整体 Agent 可靠性。标准答案已公开给方案审阅者和未来实施者，主测不称为盲测保留集。执行模型不得看到答案，评测适配不得针对每题增加解题提示。
