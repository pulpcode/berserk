# 逐题清单：自动草稿提示对照

2026-10-31｜待审阅。与 [总方案](plan.md) 一起审阅；具体执行顺序见 [32 项清单](schedule.json)。

**8 道题沿用上一轮原句、数据和固定答复。每道题 A/B 各执行两次，共 32 项。** 以下按每次重复的题序展开，标题中的第几题不是累计调用数。每项都是新会话、真实工具执行到完成。

A 保留自动草稿说明，B 只移除该段。两组同题的用户原句和数据完全相同。答案、评分说明和预设答复仅供评测器/复核者使用，不提前给执行模型。

## 所有题共同遵守

- 仅分析：草稿候选为 resources 层全部 Point；来源候选为该隔离来源系统中全部已授权的 resource 类型 Point。两者不自动合并；区域登记标签不等于几何范围。
- 资源点来自哪里、边界来自哪里，是两个独立问题。已明确的不能改；未明确的可以追问，也可以完整报告适用的条件答案。不强制每题追问。
- “未追问时应报告”列的是最初仍允许的组合。真正回答追问后，仅要求剩余适用组合；没有发送给模型的预设答复不能成为评分中的用户要求。
- 只回答模型实际问到的未知事项；只问资源，就不额外透露边界。泛指两项的问题按两项回复并记录。对已明确事项最多重述一次，另记无必要追问；遇到重复追问而没有新进展，记录未完成，不无限接续。
- “我先用草稿，若需要也可以查来源”通常是选做邀请，不自动补发选择来救答案。需要当前用户回答才能继续的真实问题才接续。无法匹配的真实问题须保留原句并复核：若模型要求无关信息，该题记未完成后继续；若合理问题暴露了回复规则缺口，停止批次并报告。不得临时编回复或改题。
- 主任务通过：有效用户要求涉及的组合、名称和数量全部正确。严格通过：再加全部公开解释有依据、没有未经允许的业务修改。后续更正另记恢复，不抹去先前公开错误。
- 正常任务失败记分后继续；平台、数据、运行契约等流程异常按总方案停止。每次的首次发现来源、最终采用来源、Skill 读取、追问及额外解释分别记录。
