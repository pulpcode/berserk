# Skill 加载对照：批次与判定

本批为已知重复错误的开发诊断，尚未授权真实调用。先完成可执行入口和离线验证，再核对套餐、模型及本批额度。不是完整标绘验收，不替换旧30槽成绩。

## 固定范围

6题：T1含糊类型、T2明确类型、R1局部读取后分析预览、R2完整草稿数量与名称、S1标绘三种图标时的目录附加说明、S2明确询问系统目录归属。原题与正向题以`loading-diagnostic/cases.ts`为准。

每题A/B各2次，共24槽。A为原生按需读取；B通过原有请求Skill选择入口加载当前map-annotations正文，不修改正文。第一轮A/B、第二轮B/A；各槽独立合成会话。工具、业务提示、初态和模型参数保持一致，随机身份与时间作为不可避免的运行差异保留，不声称请求字节完全一致。

建议上限：120次实际模型请求，输入4,000,000 tokens，输出200,000 tokens。槽位数不等于模型请求数，所有补读、澄清接续及失败请求均计入。上限只是调用前批准的硬边界，未知用量、响应模型漂移或关键效果错误停止。不能换模型、补跑失败或用旧批次剩余额度启动。

## 逐题审阅

- T1：选择依据不唯一时先进行必要澄清；得到预设车型回答后再保存。写后询问不补救先前擅选。未知问法可停留待复核，不自动提供额外事实。
- T2：明确类型直接执行，保存要求完整；不因修复T1而额外询问已明确类型。
- R1：正确生成要求的范围、仅预览不保存；只查基点时不得宣称整图只有基点。允许其他正确工具路径，不能用后来证据追补先前错误。
- R2：实际完整读取后准确报告对象总数与名称，不回避用户明确要求的总数、不重复进行无关查询。
- S1：正确创建三种对象和性质，保留旧对象；目录标签不能支持对完整外部标准的排除断言。
- S2：准确回答系统目录中的归属，有充分目录依据时直接回答，不泛化为外部标准结论。

各槽独立审阅完成程度、核心正确、过程事实、最终事实、实际效果和权限范围，给出原始路径。工具成功、结束语finished和Skill实际送达均不自动通过。文本含糊与明确错误分列。所有24槽保留分母，未执行、基础设施失败及待复核不能删除。

## 如何决定下一步

先核对B正文实际送达、A是否自行读取、工具定义一致及配对业务初态一致。如果A自行读取，则该对不是“有正文/无正文”比较，仍留在批次并单列。

至少两类问题上观察到B严格通过数高于A，且正向题完整性不降低、无新增关键效果错误，才将“改善方法发现/触发”列为下一项产品候选；仍需在原生按需模式下验证该候选，不直接部署显式全加载。

若只改善一个样本、A未复现错误、结果混杂或B仍出错，报告未证实或局部线索，不追加题目凑分。工具/Skill正文/返回结构/模型同时变化的结果不纳入该单因素对照。

本批仅有每格两次重复，不能证明统计显著性、普遍可靠率或某一句提示的因果作用。显式选择同时改变正文可见性、上下文长度和选择标记，结论仅限这一整套加载条件。
