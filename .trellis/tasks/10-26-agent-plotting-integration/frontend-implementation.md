# 前端实施边界

最小缺口：当前表单把显示默认值完整写回；保存失败后只更新修订依据，无法保留并发字段修改。固定版本读取尚未原子配对。

实现位置：`src/web/annotations/useAnnotations.ts` 成对刷新/错误分类；`FeatureEditor.tsx` 保留原始缺省并生成实际修改；`AnnotationWorkspace.tsx` 捕获编辑原点、引用保护、显式三方合并；新增纯 `edit-changes.ts` 和有限 `EditComparison.tsx`；原 CSS 增加核对区。测试在 `tests/annotation-edit*.test.ts` 和既有 annotations E2E。

保持服务顶层替换语义、DTO、数据库、单地图渲染、固定22项素材、现有4324试用环境和另一worktree不变。不会建设跨标签同步或通用协同编辑框架。通过纯函数与真实服务浏览器并发写入验证字段保留、同字段选择、二次冲突及未知回执。

## 已实现

- 成对提交 binding 与固定内容；读取失败保持上一完整版本，编辑起点不可写；乱序响应按 generation 丢弃。背景刷新不冻结本地输入或移走焦点。
- 表单按初始有效值识别实际变化，未操作的样式/角色/备注/业务属性保留缺省；顶层最小 changes 与样式/属性完整替换并存。
- 保存对比 B/L/R；不同字段明确确认、同字段逐项选择、同值不产生空修订；二次CAS重新加载核对且清空旧选择。对象/图层/基线身份/类型/可写状态变化阻止旧保存。
- 引用入口保护未保存输入；来源引用同样保护。未知保存结果保留原 actionId，未找到回执不清空或重发；未知期间冻结表单，避免新输入与待确认提交混淆。只读变化仍可显式取消本地编辑。
- 动态业务属性读取只取自有键；写入不吞掉非法键，仍交原服务校验拒绝。
