## 纳入范围

| ID | 能力 | 整合要求 |
| --- | --- | --- |
| R1 | 单地图与专业标绘 | 保留按需展开工具、选图标放置、22 个符号（20 个标准符号、2 个应用扩展）、方向与尺寸、线箭头、紧凑浮动编辑面板及保存视角保持 |
| R2 | Agent 读写新字段 | 通过现有标绘工具正确选择符号、读取与修改方向和信息性质；按需读取字段，只改用户要求的内容，保留对象身份和其他属性 |
| R3 | 来源及业务含义 | 区分来源对象、草稿和来源副本，区分现场记录、研判和方案；图标不证明真实资源或可用数量，复制来源不变成实时跟踪，发布/采用不表示已到场 |
| R4 | 人工与 Agent 接续 | 共用现有对象、权限、版本与回执机制；处理目标歧义、未保存编辑及并发变化，不静默覆盖人工修改 |
| R5 | 分析、保存与解释 | 保留既有空间分析能力；分析预览、保存草稿、发布和任务采用分别以实际结果为据；核心结果、过程说明与最终解释均需核实 |

沿用已接受的 Pi 原生机制、共享符号目录及现有标绘服务，不因整合另建 Agent 状态库或写入通道。产品仍只面向桌面浏览器。
