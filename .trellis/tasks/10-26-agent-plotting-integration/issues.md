# 暂缓事项

## PLOT-I01：Agent 标绘候选预览与用户确认

记录日期：2026-10-28。状态：**暂缓，未实施，不纳入当前重复错误修复**。这是仓库内的 issue 记录，未创建 GitHub Issue。

用户希望探索：依据充分时直接完成；有依据但尚存假设时先展示候选，由用户确认；缺乏选择依据时简短询问。2026-10-28 用户明确要求先搁置此机制，优先验证并修改反复出现的错误。

### 已确认的现状

- 共享图标目录有名称、别名、类别、标准/扩展来源和方向能力；没有通用消防车条目，也没有“默认水罐车”的约定。
- 前端已有人工未保存编辑预览；当前 Agent 标绘写入工具没有与之对应的结构化候选预览通路。
- 当前提问交互、草稿保存、发布采用和版本冲突各有既有机制。草稿已经保存不表示图标选择已获得用户确认；informationRole=plan 也不是待确认状态。

### 重新启动时再决定

1. 用可核实的匹配依据、用户授权及操作影响决定直接执行、预览或询问；不能依赖模型自报的置信度百分比。
2. 确认前的候选不能混入已保存标绘的统计、分析或发布内容。明确候选的显示、切换、取消、会话恢复及失效行为。
3. 用户确认内容与实际提交一致，继续复用版本检查及原动作回执；确认期间版本变化或本地人工编辑不能被静默覆盖。
4. 优先复用共享目录、地图预览、现有交互和保存服务；是否需要新接口或持久记录，待明确恢复需求后再定。
5. 验收同时覆盖明确指令直接完成、必要选择、取消和无回复，不能将所有写入改成逐次审批。

### 本轮边界

不增加候选层、确认卡、预览工具、待确认数据库状态、默认车型或模型置信度阈值。此 issue 不改变旧测评规则或成绩，不授权实现。后续重新启动时形成独立设计与验收。
