## 已核对契约

- Agent schema 仍从共享 22 项目录生成，未新增工具或服务端写入语义；标准/扩展、方向能力和别名来自既有字段。
- Skill 保留固定 Agent 基线的来源/事实要求，补明确对象身份、完整嵌套字段替换、未保存输入及并发接续规则。
- 原始缺省值与显式值分开处理；最小修改按原始对象生成，style/attributes 仍使用既有整体替换 API。
- binding 与固定 version 成对提交；旧加载结果不可跨身份配对。不同字段仍须确认合并，同字段逐项选择；第二次 CAS 后重新核对。
- 未知回执保留原 clientActionId，只查询原回执；不得用新 ID 重试。对象删除、类型改变、原层消失、只读与无草稿基线切换均阻止旧表单覆盖；取消可达。
- 新建对象遇到并发后可以明确确认后接续一次；引用与离页保护、本地表单、地图相机和焦点保留均由实际浏览器回归覆盖。
- 离线驱动只将产品输入送入 Agent，题目答案与评分规则留在驱动侧；预算、一次性批次、源码冻结、未知用量、错误证据和完整分母阻断均有自动检查。`recorded` 不自动等于语义通过。
