# 审阅入口：多源上下文接入与自动综合研判

日期：2026-09-23。状态：**实现完成，待用户验收**。

本期是能力验证，模拟场景和字段不代表后续产品设计。已实现范围、测试证据和研判质量限制见 [验证记录](research/validation-results.md)，2026-10-08 已更新线上服务，待用户验收。

本期交付：特情与态势更新都能触发自动分析，Agent 查询多源资料及 Axon 任务，解释变化和任务影响；结果按现有规则投递，人员可以继续分析。

## 本期范围

| 项目 | 实现范围 |
| --- | --- |
| 任务上下文 | 沿用任务管理权限维护可选业务引用与关注范围；只保存标识、条件和目标，不复制外部完整数据库 |
| 自动分析定位 | 扩展现有后台 Profile 和查询工具，同时支持特情、态势触发；不另建每席位常驻 Agent |
| 分析与投递 | Agent 判断可能影响的多个任务；本期仍按固定规则投递一个或多个席位，智能选择接收方另做增量 |
| 查询范围 | 首期使用一个共享模拟资料范围；服务身份读活动公共任务，人员读自身可见任务；综合结果接收者必须有该资料范围权限 |
| 结果与接续 | 用正常分析正文说明影响和缺口；人员通过“提问与处理”继续工作；所选任务只决定会话保存位置，不合并不同任务工作区 |

本期采用服务启动时加载的固定资料范围配置，保留查询与结果访问校验。动态撤权、存量资料治理及其管理页面／API 后置，不纳入本期审阅与验收范围。

## 这期如何证明有用

使用三个合成任务：同一路段上的补给方案、设备转移方案，以及相邻区域的无关方案。一条道路限制同时影响前两个任务；随后车辆减少可以独立触发分析，并按两个任务不同的数量要求判断。交换两任务的数量要求后，判断也应相应改变。还要验证资料缺失、时间不相关和人员后续追问。详见 [测试场景](research/simulation-scenario.md)。

后台调度、会话历史、文件操作与交接继续复用现有实现。新工作主要集中在任务可选字段、只读查询适配、综合结果访问范围和现有页面展示。

原始调研与代码依据保存在 [research/basis.md](research/basis.md)。其中研究建议以本目录 PRD、设计和验收中的本期范围为准。
