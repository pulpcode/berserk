# 验收清单：多源上下文接入与自动综合研判

状态：已实施并完成工程验证；真实模型表现及未覆盖项见 [验证记录](research/validation-results.md)，不将运行成功等同于研判准确。需求编号见 [PRD](prd.md)，合成数据见 [模拟场景](research/simulation-scenario.md)。

| MX02 | 两窗口编辑目标与关注范围；重复新建请求 | 同一 revision 控制全部字段，冲突保留草稿并可比较最新完整内容；相同 clientActionId 换 context 返回冲突，不误复用旧创建结果 | MC01 |

| MX09 | 同对象的前一日任务变体；未知对象 E3；部分来源不可用 | 区分时间不相交、仅区域候选、来源缺失，保留待核实项；不猜测未知对象；正常完成的部分分析可投递且正文明确局限 | MC04 |
| MX10 | 原样重送消息；报告追加修订；旧消息晚到 | 同 source/message 不重复初始作业；新修订独立保留；以业务时间／版本比较，不把接收顺序作为事实新旧依据 | MC03、MC06 |

| MX18 | 回归普通多轮、压缩、文件脚本、委派、交接确认和后台投递 | 现有机制正常；没有为了查询修改 Pi 压缩、放开沙盒网络、扩充子 Agent 权限或增加任意总调用上限 | MC02、MC07 |

## 验证方式

1. 单元／集成测试验证字段、权限、HTTP 适配、分页与错误、原生证据和现有状态衔接。使用隔离数据根、真实本地存储和可控模拟 HTTP，不以 mock 权限服务代替权限验证。
2. 桌面 Playwright 覆盖新增字段、冲突、结果／依据、收件接续及迟到响应；使用受控 provider，避免浏览器测试依赖模型措辞。
3. 实施获批后，用当前配置的真实模型在合成数据上运行 E1、独立 E2、S7 条件互换及未知／缺失资料场景；检查实际 HTTP、原生查询记录、原始来源和最终判断。脚本化 provider 通过不等于真实模型研判通过。
4. 记录使用的模型、配置、fixture 阶段、任务／作业 ID、实际查询与结果；不保存密钥或认证头。测试预期不作为模型输入。一次正确不代表普遍准确，不以改写期望文案掩盖模型未查资料或关联错误；本期结果不能推导为已具备 GIS／道路拓扑或真实业务普遍准确性。

本期验收不要求真实消防系统、全量任务同步、动态席位路由、持续态势驾驶舱或新的权限管理门户。动态撤权、运行中权限变更及存量资料治理后置，不作为本期通过条件。本次执行范围见验证记录；2026-10-08 已按用户指令部署，手工测试见 [线上验收指南](research/server-test-guide.md)。
