# 发布并自动拉取沙盒镜像

正式发布由发布方构建、验收并分发沙盒镜像。部署人员准备主机与私有配置，检出指定应用发布版本，运行现有一键部署入口。首次缺镜像时自动拉取，后续部署复用匹配的本地镜像。

当前 `deploy-preflight.ts` 在本地缺镜像时执行 Docker build，冷部署会在目标机拉取基础镜像并安装 Debian 和 Python 依赖。正式发布改用版本绑定的镜像摘要。开发者仍可用现有 Dockerfile 显式构建。

## 验收

- Ubuntu amd64 空镜像缓存执行部署，拉取发布版本指定的摘要，完成沙盒试运行和服务验收。
- 同一版本重跑命中本地摘要，跳过拉取。下一应用版本可以明确引用旧摘要或新摘要。
- 错误摘要、无权限、不可达及架构不匹配均在切换前报错。显式关闭沙盒时跳过 Docker 与镜像步骤。
- 两个发布版本分别绑定各自镜像，回退版本后使用旧摘要。实际执行探针确认挂载、文件读写和清理。
- 首版以已验收的 linux/amd64 为发布平台，其他平台待具备实际构建和探针验证后再加入。

## 已确认

采用公开 GHCR，目标主机匿名按摘要拉取。发布前从真实部署网络完成冷拉取及执行验收。
