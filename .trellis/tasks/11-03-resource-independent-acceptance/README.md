## 数据是真实存入测试系统的合成数据

[逐题清单](cases.md)是待建数据的完整说明，不是已经存在的业务数据。获准准备执行后：

- 来源记录放入本地模拟来源，由真实HTTP接口返回，经过现有解码、ContextService和工具读取。分页、coverage、源修订和有效时间均由接口真实返回。
- 标绘通过真实AnnotationService/API建图层和对象，取得真实固定版本。受控副本只能用真实from-source流程导入单体，不能手填可信关联。
- 用户引用由真实引用机制随消息发送；普通点击不作为引用。结果保存于Pi原生历史，续读使用真实resultRef。
- 预期答案、评分规则和追问后的冻结回答留在评测器侧。模型只接收题目原文、正常装配的引用/上下文与自己查询到的数据，不注入整张数据表或答案。

每次执行使用独立任务、会话、账号授权及数据目录。名称、坐标、数量和业务事实两遍一致；UUID、实际API版本及相对时间按每次执行映射并留档。不得复制第一遍会话或把动态版本硬写成预期数字。

## 验收门槛

- 正式主任务、严格正确均至少**15/16**，保留整体90%要求。
- 无越权、无无据身份合并、无无据分配/可用状态、无部分冒充全量，四项各**16/16**。
- 任何正式题不能两次主任务均失败。
- 三项已确认工具缺陷不得再现：空统计集合自校验中断、满足去重前提仍重复计数、缺少合并依据却给精确合计。任一再现，本轮工具修复验收失败，不能由其他15项成功或模型后来纠正抵消。

4项公开检查不并入16次正确率。模型业务错误仍如实记录；只有输入、接续、记录、用量可信才能继续正式执行。产品失败不能改称基础设施无效来移出分母。
