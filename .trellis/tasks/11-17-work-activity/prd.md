# 会话工作识别与面板展示

2026-11-17 用户批准已审阅方案，要求提交方案后实施。详细设计见 design.md。

## 目标
面板展示待接收工作、本席位正在办理的工作及本对话近期处理的零到多项工作，不要求用户管理会话关联。

## 要求与验收
- R1/AC1：待接收和席位办理中来自获准业务记录；分清 assigned、working/returned、submitted，读取不改变业务状态。
- R2/AC2：独立无工具模型请求识别对话工作；两项独立工作可同时展示，同一工作的两个文件不拆工作。
- R3/AC3：允许未匹配的自发活动、参考/不确定判断与空结果；依据可查看，可忽略当前版本推测，不伪造正式工作ID或状态。
- R4/AC4：既有会话首次打开可分析；每轮结束更新；打字/失焦不触发；关闭面板延后新分析，失败仅显式重试。
- R5/AC5：浏览器内存按身份和会话保留；同身份跨会话/页面/模型保留，用户/席位/登录态改变全清，刷新重算。
- R6/AC6：授权过滤、真实证据、来源和业务版本校验；迟到响应不串身份/会话，新轮次取消旧分析，权限撤销不展示旧内容。
- R7/AC7：个人空间只识别个人活动；分析超时/无效结构不影响主对话和正式待办，具备独立开关。
- R8/AC8：桌面可折叠面板、证据与原详情入口；不抢焦点，不额外设计手机端。
- R9/AC9：提供确定性边界测试、桌面浏览器验证和独立真实模型样例证据，报告语义效果与局限。

## 边界
不改 session_links、业务状态机、文件提交对象、附件导入、主 Agent 上下文或原生历史。WORK-SESSION-001 保持开放。输入建议原有未提交代码不并入方案提交。用户本轮未要求上线，不自动更新4316。

## 已确认决策
采用独立只读识别路线，业务数据仍为事实来源。浏览器内存可失效重算，不建立持久关联、向量库、后台工作流或跨设备记忆。无待澄清产品问题。
