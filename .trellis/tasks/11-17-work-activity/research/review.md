## Findings (fixed)

以下问题由原代码负责人修复，复核者检查最终代码和针对性测试；复核者未覆盖并行实现者的产品代码。

- **P1：导航返回期间，迟到 POST 可能先于新的授权 GET 展示缓存。** `src/web/useWorkActivity.ts:50` 在切换显示范围时清空投影，`:57`、`:134` 增加本次导航的授权版本门禁；迟到结果可写原会话缓存，必须等新的成功读取才能发布。浏览器用例 `a late analysis can cache to its original chat...` 人为阻塞返回 GET，先交付旧 POST，验证敏感内容仍不可见。
- **P2：同一工作可能同时出现回执卡与模型卡。** `src/web/work-activity-items.ts:8` 按正式 workItemId 合并，保留两种依据和权威状态；忽略仅移除模型贡献。`tests/web/work-activity-items.test.ts` 与首个面板浏览器用例覆盖两项独立工作、一项工作的回执合并和忽略后保留事实。
- **P2：模型空白标题或描述通过长度校验后可能渲染空卡片。** `src/pi/work-activity.ts:118` 拒绝 trim 后为空的字段；`tests/pi/work-activity.test.ts:37` 已覆盖纯空白标题和描述，保持无效输出返回 unavailable。
- **P2：操作依据无法定位实际确认回执。** 正常交接工具结果走 `InteractionCard`，原先仅给 `ChatMessage` 标记消息 ID，定位退回首个同轮消息。`src/web/ChatPresentation.tsx:95` 现给交互包装节点挂真实 `item.result.id`；`src/web/main.tsx:748` 可直接命中并展开祖先过程。首个浏览器用例核对聚焦节点 ID 等于实际 `work_item_action` 结果，而非用户消息。
- **P2：未通过准入的前台请求可能取消其他会话的辅助调用。** `src/pi/lab.ts:1745` 将跨会话取消放在任务、能力等准入完成后，仍保证获得模型许可前抢占；原会话输入建议既有早取消规则不变。`tests/work-activity-api.test.ts:117` 覆盖被拒绝请求不打断另一会话分析，另外两例验证单许可下同时抢占分析和输入建议。
- **P2：流式活动更新反复清空已重新读取的真实回执。** 原 `activity.active/backgroundJob` 判断在同一轮的每次活动更新都替换缓存，导致 `canAnalyze:false` 的新事实也消失，直到下一次读取。`src/web/useWorkActivity.ts:25`、`:33`、`:76` 现按前台 requestId/后台 jobId 标记 run，只在新 run 失效一次；`:89` 关闭推测时保留这个标记。同一 run 的后续活动更新保留已授权事实；上一失败轮次的 `source:null` 回执也会在新 run 立即失效。`:34` 的刷新键包含后台 id/status，`:142`—`:158` 捕获并比较完整活动键，迟到 GET 成功或失败都不能覆盖新来源，也不会把旧读取标为新 run。`tests/e2e/work-activity.spec.ts:149` 覆盖持续运行中的后续活动更新、取消后保留真实回执、取消后的下一轮延迟 GET 先隐藏旧事实再恢复。

## 复核范围与结论

- **业务事实与无副作用：** 追踪原生确认/成功工具结果 → 原始 committed action/receipt → 获准当前任务工作；普通读取、旧关联和助手口头声明不构成业务操作事实。标题与状态由宿主填充。本增量没有 session_links、数据库状态机、文件提交对象、主 Agent 上下文或聊天历史写入路径。
- **分析与权限：** 追踪 GET/POST 契约、正式登录/CSRF/view、席位/个人空间、参与者候选筛选、捕获模型及配置版本、20 秒总时限、共享许可、并发合并后逐调用者重新授权。失败/无效模型输出也重查权限。无工具、无自动重试、无服务端完成结果缓存。
- **来源与缓存：** 版本涵盖来源、实际证据、任务与获准工作修订；选择模型不使已完成结果失效。验证身份 epoch、登录 viewId 重挂载、非活动席位清空、原会话迟到结果、导航授权门禁、403 清除、来源变化失效、失败显式重试、关闭识别保留事实等实际代码路径。
- **界面：** 审阅待接收/本席位状态划分、本对话零到多项活动、个人空间、参考与不确定、依据入口、忽略、设置开关、默认折叠及桌面窄地图面板。查看最终 1440/960 桌面和地图分屏截图，主输入区可用、没有横向溢出或重复布局；早先重绘过程截图出现的底部重复内容在最终截图未重现，不登记为已证实缺陷。负责人补充双动画帧后截图及输入区底部不超出视口的断言。
- **规格同步：** 新增 `.trellis/spec/backend/work-activity.md` 及两层索引与最终实现一致。正式关联与跨对话接续问题 WORK-SESSION-001 仍开放；没有将本展示能力当作执行上下文修复。
