# 虚拟场景演示建设：临港仓储区火情

版本：v0.6；2026-11-05；状态：总体需求记录，来源系统调整建议待审阅。

> 2026-11-05：导演台及轮次隔离已经实施发布；下文较早阶段的“未实施”记录保留为历史规划背景，不代表当前产品状态。本次只补沿用双系统的来源与来报有限调整方案，见[模拟外部系统方案](external-systems-design.md)，收敛后的双系统命名与新版本业务来报已按后续授权实施；线上尚未更新。

## 目标与价值

把“发现火情→核实与持续研判→比较方案→人员批准→模拟执行→变化后修订→反馈”建设成一场简洁、可复演、可追溯的桌面浏览器演示。数据包含正常业务背景，使Agent需要从多源信息和资源中辨明相关性、可用性与时效；观众能在任务内理解事件进展。

## 建设需求

| 编号 | 要求 | 可观察结果/主要阶段 |
| --- | --- | --- |
| R01 | 五幕故事与背景数据一致，目标、类型/数量、时限、变化和结束点明确 | 人员能解释为何需要核实、比较及修订；P0 |
| R02 | 单体资源具有稳定身份、归属、细分车型、位置、状态、来源与时间；至少一半车辆不参与推荐路径 | 二十四车均可查询；忙碌/检修/未知与可用分开；P1 |
| R03 | 模拟数据经过真实来源接口进入Axon | 报告、道路、车辆可用现有来源查询和引用方式读取；来源不含答案；P1 |
| R04 | 可预览并推进一幕、暂停、继续、重演；事实变化与通知接收/分析分别可查 | 相同场景输入可复现；未批准不会跳过到场；P2 |
| R05 | 地图展示位置、进展、历史轨迹及最后更新时间，呈现记录/计划/执行事实区别 | 车辆移动有来源记录；旧位置可识别；背景正常存在；P2/P4 |
| R06 | 多来源及背景变化触发持续研判，旧观测晚到不覆盖较新事实 | 指出中轴桥影响，保留无关业务，结论有依据；P3 |
| R07 | 候选方案可保存版本、比较、修改，人员批准固定版本 | 车组、路线、模拟时序、前置条件和依据可定位；推荐不等于批准；P3 |
| R08 | 后台获准读取已共享方案的具体版本，依据变化可要求复核 | 它能读取A方案对R01的依赖；未开放席位私有会话/文件；P3 |
| R09 | 人员显式下达已批准且仍有效的安排，模拟服务维护占用、执行进展与回执 | 防止占用T02/T03车辆；重复下达不重复出动；结果未知可核对；P4 |
| R10 | 执行中可修订受影响部分，保持已到场事实及原审批/执行历史 | 三辆已到场车辆保留，四辆绕行；修订获批后再改变安排；P4 |
| R11 | 任务内综合查看目标、地图、来报、当前研判、方案、决定、行动和反馈 | 从已有任务主页进入，不需跨多个页面拼出故事；P5 |
| R12 | 工程行为与真实模型语义分别验证，保留失败和重演记录 | 全流程、干扰信息、时效和停止/重启路径有证据；P6 |
| R13 | 本期M1由场景后台统一维护虚拟时间，模拟来源和资源查询采用同一场景时点；真实接收/查询/登录/超时保持真实时间 | 手动推进、暂停和重演时业务有效期可复现；Agent和页面能区分两类时间，资源工具不自行改变来源业务状态；P0—P2 |
| R14 | 同一登录入口提供专用导演席及独立场景控制权限，四业务席保持原业务入口且不能访问导演台/控制接口；来源、任务管理与业务审批不隐式授予导演权 | 导演有专用页面与条件导航；业务席直访无权，不能读取未来步骤或借旧入口控制新场景；账号并行演示使用独立登录会话；P0/P2 |

## 范围外与后续事项

- 按管理域拆分成可独立对接的服务，后续按SIM-DOMAIN-001建设；本期复用现有模拟服务，保留数据责任与来源。
- 不建设真实指令下发、消防战术/火势物理模型、路由优化、任意场景生成器、通用审批设计器或新的Agent运行内核。
- 本期使用明确标注的合成行驶时序；不把预设ETA说成GIS或模型算出的真实行驶时间。
- 场景时钟纳入M1，但不建设独立时间平台、多服务时间广播或综合出动资格规则引擎；真实外部系统不跟随虚拟时间。
- 不建设移动端、三维、扫描雷达等与本故事无直接关系的特效，不要求影像识别模型。
- 场景验收不替代生产语义验收；付费模型批次及部署在对应阶段另列实际配置、预算和准入条件。
