# 场景业务闭环：来报分析、人员建任务与协作验证

状态：v0.2，2026-11-06 用户已批准“提交方案，开始实施”；方案提交为 `6987d34`，当前实施与验收中。

## 目标

在现有导演台、双系统来源和轮次隔离基础上，演示一次完整的业务起点：**外部来报 → 后台 Agent 初析 → 总体席决定是否创建任务 → 关联原信息 → 业务席协作**。同时验证重新演示不会混入上一轮的消息、任务和会话。

## 已核对的现状

| 已有基础 | 本阶段需要补齐 |
| --- | --- |
| 导演按事件投放、重新演示及历史只读 | 场景消息自动进入已配置的后台分析规则 |
| 后台预处理、任务判断、消息与任务关联、人员从建任务建议创建公共任务 | 建任务不能被预建主任务跳过；人员从有效分析创建任务也不应以模型必须建议新建为前提 |
| 公共任务、席位工作区、分派/接收、提交与审核 | 在同一场景中串起并验证这些能力，修补实际阻断点 |
| 已确认所属演示的来报、关联任务、Agent 分析作业与原生会话已按轮次隔离 | 复用隔离机制，补齐人工创建任务的自动归档范围，并回归结束、只读和跨轮拒绝检查 |

代码依据与兼容约束见 [design.md](design.md)。涉及的既有 issue 为 SIM-TASK-001，见[问题记录](../11-03-scenario-demo/issues.md)。

## 需求

| 编号 | 本阶段要求 |
| --- | --- |
| R1 剧情与初始化 | 仓库火情是唯一完整业务测试主线，由总体席在收到来报后决定创建。启动演示时系统自动创建交通救援、登高演练两个开场已有业务任务，用于续报关联和车辆占用判断，不各自重复完整流程。保留六站、二十四车、既有背景和十二步来源事件，不预写任务归属答案。 |
| R2 消息初析 | 沿用特情/态势两个来源和原生 Pi 预处理；拟向总体席投递初析结果，由总体席决定后续协作。本阶段不同时启用同一来源的持续分析，不自动建任务或派工。 |
| R3 人员建任务 | 有权限的总体席可从已成功、可读且仍允许操作的来报分析结果打开现有表单，确认创建公共任务；有建议可编辑，没有建议也可自行填写。新任务继承原来报/分析的轮次，业务席不选择轮次；旧轮结束后拒绝旧提交，不改绑新轮。取消、重复提交、响应丢失不产生额外任务；同一来报重新预处理后也不得重复创建。 |
| R4 关联与协作 | 后续来报可判断关联已有任务、建议新建或暂不归口；人员可核对、修正关联。复用既有分派、接收、提交和审核完成一次事实核实协作；关联任务不自动扩大来源读取权限。 |
| R5 重演边界 | 复用已有轮次隔离，补齐自动归档范围，包含人员从来报创建且符合归档条件的任务。不能归档的保留真实业务状态并只读；归档状态不决定是否隔离。旧分析、旧建任务表单和旧协作操作不得写入新轮。 |
| R6 验证证据 | 区分确定性工程测试与真实模型测评；记录实际模型、配置、场景版本、输入、工具依据和人工判定。执行成功不直接计为判断正确。 |
| R7 兼容与界面 | 新场景另增版本，旧三任务场景及原始证据保持可读；导演台只显示实际存在的任务入口，不增加独立任务面板或冗余说明。 |

## 验收标准

| 编号 | 可观察结果 | 对应需求 |
| --- | --- | --- |
| A1 | 新演示在首报前只有两个开场已有任务，没有仓库火情任务；旧版本仍按原三任务条件校验，不因升级被重新初始化。 | R1、R7 |
| A2 | 投放来报后，可分别核对接收回执、后台作业、分析结果和总体席投递；重复投放不重复入队。未配置规则或分析失败时如实显示。 | R2、R6 |
| A3 | 总体席能修改建议或自行填写后确认创建，继承原来报轮次，并可回溯消息编号 eventId 和分析作业编号 jobId；同一来报不同分析版本并发创建也不会重复建任务。导演和无权限席位无法执行。 | R3 |
| A4 | 主任务创建后，相关续报可关联到实际任务；无关信息有理由地不归口；至少完成一次人员分派→业务席接收→提交→总体席审核。 | R4 |
| A5 | 分析中、建任务提交中、协作中结束 A 后开始 B 的隔离回归通过；人工创建且符合条件的旧任务被归档。A 的迟到、重试及旧页面操作不进入 B；不能归档的旧任务保留真实状态并只读。 | R5 |
| A6 | 模型测评核对位置不确定性、资源占用/检修/未知、道路当前事实及旧观测晚到；有引用和合理解释才记为通过。未通过项及人工修正单独记录。 | R6 |
| A7 | 两种模式分别显示事件投放进度与业务任务状态，不根据投放进度生成业务完成结论；本阶段不伪造方案批准、车辆出发或到场。 | R1、R4 |

## 不在本阶段

- 七类外部系统、按管理域拆分、通用能力发现框架：继续留在 SIM-DOMAIN-001。
- 无来源入口的任务/个人空间归属：SIM-TASK-002 仍待定；不采用已撤回的隐藏页面上下文，也不另选替代方案或关闭原入口。
- 增加真正无关的来报对照、扩展抗干扰测评：留在 SIM-EVAL-001，后期丰富，不作为本期前置条件。
- 历史轮次恢复执行、结构化 A/B 方案与批准、车辆调派/移动/到场、任务综合页改版。
- 新 Agent 引擎、新流程设计器、自动连锁分析与自动派工。

## 审阅边界

以上范围已获实施批准。业务闭环验收只覆盖从已确认归属的来报分析结果创建任务及其后续操作，不能据此宣称所有无来源操作也已完成隔离。真实模型批次执行边界见 [首批测评限额](research/live-run-policy.md)；原始待审阅版本保留在方案提交中。
