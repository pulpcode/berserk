# IP 端口直连测试访问

## 目标及授权
用户在本会话审阅“监听地址、Host/Origin 白名单、安全组、重启验证”方案及 HTTP/备案说明后，明确要求尝试方案一。实施授权来自该回复，采用现有账号和数据。

## 范围
- 默认保持 loopback；显式配置后允许 HTTP IP:4315 访问。
- 精确来源白名单，保留登录、CSRF、权限及原 SSH 路径。
- 修复公网 HTTP 缺少 crypto.randomUUID 导致的前端操作失败。
- 备份线上被替换代码和构建结果，更新实际自定义启动入口，重启并验证。
- 不迁移数据、不更换账号、不部署 HTTPS、不发布无关本地界面改动。

## 验收
- 默认拒绝外部 Host；启用配置后接受指定 IP:端口，拒绝非白名单 Host/Origin。
- 公网 HTTP 登录、UUID 相关操作可工作，匿名业务请求仍为 401，缺 CSRF 仍为 403。
- 类型、lint、相关测试通过；线上健康接口及页面通过直连检查，保留可回滚备份。

## 访问范围
- 用户明确需要向开发组分享，不能仅限当前机器；采用不同网络可访问、现有账号登录的入口。
