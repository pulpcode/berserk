# W01-6 验收清单

状态：**实现后的验证结果见 [验收记录](research/validation-results.md)**。H 编号对应 [本期需求](prd.md)，不替代 W01 全量 T 用例和 MVP 验收。

| 编号 | 场景与通过标准 | 方式／关联 |
| --- | --- | --- |
| F01 | 真实模型调用需确认工具，卡片与实际参数一致；批准前执行计数为零、该请求不再调用模型；批准后只执行一次，模型收到实际结果后继续 | Pi 集成 + 真实模型／H01、H02 |
| F02 | 拒绝后工具不执行，模型收到拒绝结果；页面区分已拒绝、已批准、执行成功和真实执行失败 | Pi 集成 + 真实模型／H02、H07 |
| F03 | 直接构造工具调用仍受规则检查；AGENTS.md、工具参数中的“已批准”不能绕过；同请求的后一次调用需独立决定 | 集成／H01、H03 |
| F04 | 双击、双标签页相同响应只生效一次；相反决定或不同答案竞争只接收首个有效响应；错误会话／请求／类型不能推进执行 | API + 浏览器／H03、H05 |
| F05 | 待回答／待确认时停止能结束等待；迟到响应无效。验证停止先到、响应先到但后续未开始、工具已开始的情况；最后一种按实际效果展示，不声称回滚 | 故障注入／H05、H07 |
| F06 | 切会话、刷新、断线重连仅查询已有交互；回答草稿和聊天草稿保留，不重发消息／响应。其他会话继续，同会话第二条普通消息不被接收 | API + 浏览器／H04 |
| F07 | 响应丢失后查询能看到已接收结果，相同提交重试不重复执行；旧 pending 不能覆盖终态；服务端已有答案时旧草稿不可再次提交 | 浏览器／H03、H04 |
| F08 | 两种等待中异常重启均显示已失效、不可提交；已批准但缺工具结果时提示结果未确认；服务不重放消息或工具 | 子进程／历史测试／H08 |
| F09 | 导航区分待回答／待确认并计入需关注；蓝点仅表示新回复未读；不抢焦点、不自动提交默认选项，中文输入法、键盘及窄屏可用；完整命令可查看 | 浏览器／H01、H06、H11 |
| F10 | 交互／响应保存失败、桥接不可用均明确结束，不放行或捏造答案；显式整轮时限到期可停止；默认无新增等待倒计时 | 故障注入／H05、H07、H11 |
| F11 | 原问题、回答／跳过、确认决定和实际工具结果刷新／重启后可查，压缩后卡片仍保留；上下文仅接收一次工具结果；旧历史可用，跨工作区或畸形交互记录被拒绝 | 持久化／H07、H08 |
| F12 | confirmation_demo 默认不注册，子 Agent 无提问／确认演示工具；普通聊天、上传、文件读写、下载与只读委派可用；交互不新建容器，已建容器到请求结束正常清理 | 集成 + Docker 回归／H09 |
| F13 | 固定 AskUser 扩展在自动发现关闭时可被主 Agent 调用；单题／多题、单选／多选／纯文本／自定义文字正确回传题目与选项 ID；缺题、未知选项和混合答案被拒绝；回答后继续同请求 | Pi 集成 + API／H10、H11 |
| F14 | 跳过返回明确 skipped，不携带旧答案或默认选项；普通聊天提问仍可用；问题回答不能批准操作，确认接口不接受答案载荷；之后真正的受控操作仍需确认 | 集成 + 浏览器／H03、H10、H11 |
| F15 | 命令样例的允许／询问／禁止均符合预期，覆盖静态引号、绝对路径、包装、Git 参数、命令链与重定向；复合命令决定前连首条也未执行，禁止优先 | 解析器 + 集成／H01、H12 |
| F16 | 不支持的语法或有效语法无法可靠分析时询问；解析器不可用／规则异常时不执行；批准后执行原始命令和固定 cwd，不能替换参数或改变沙盒边界 | 故障注入 + 集成／H03、H09、H12 |
| F17 | 真实任务先询问格式，再按答案生成文件；测试目录内删除命令经批准产生一次实际效果，拒绝／停止保留原文件；刷新后仍能回答和决定 | 真实模型 + 浏览器 + Docker／H01、H02、H04、H05、H10 |
| F18 | 普通 Python／Node 文件脚本在未命中规则时可执行，内联代码／Shell 脚本按规则询问；固定扩展装载失败明确报错；上传文件不能自动注册为宿主扩展 | 集成 + Docker 回归／H09、H12 |

确定性测试检查实际模型／工具调用次数、归属、文件效果、持久记录和终态，不能只检查卡片文字。[命令样例](research/command-policy.md) 是 F15／F16 的输入，危险命令仅做策略判断或在独立测试目录验证，禁止命令通过执行计数证明未运行。

真实验收记录依赖版本、模型、sessionId／requestId／interactionId 和结果，不记录密钥。通用确认故障可使用默认关闭的演示工具；不以演示替代 AskUser 和 bash 的真实路径。产品验证结果、环境及具体边界见验收记录。
