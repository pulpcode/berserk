# W01-6 Web 人工交互：提问与操作确认（HITL）

日期：2026-09-18。阶段：W01 / S3b。状态：**已获用户批准并实现，通过开发验收，待用户浏览器验收**。

## 目标

Agent 缺少信息时，可以在网页向用户提问，收到回答后继续当前任务；准备执行需授权的操作时，展示具体内容，由用户确认或拒绝。为当前通用文件作业补齐人机交互，并为后续上报、下发提供操作确认入口。

复用 Pi 的工具、扩展、拦截、等待和继续对话机制。提问获取信息，操作确认授予一次调用的权限，二者分别记录、分别处理。

## 已有基础

W01-1～W01-5 已实现多轮对话、工作区与席位归属、AGENTS.md、默认压缩、只读子 Agent、上传和 Docker 文件作业。当前使用 Pi 0.85.1 SDK，同会话一次处理一个请求，不同会话可并行；网页刷新查询已有状态，服务重启不自动重放未完成请求。尚无真实上报、下发或跨席位审批。

## 本期要求

| 编号 | 用户可观察的行为 |
| --- | --- |
| H01 | 需确认的操作在执行前显示具体动作、对象和影响；命令确认展示完整命令与工作目录，内容与实际调用一致 |
| H02 | 确认后该次调用才可继续；拒绝则不执行，Agent 接收拒绝结果后说明或调整 |
| H03 | 确认只授权该次调用；重复点击不重复执行，提问回答不能替代操作授权 |
| H04 | 等待时切换／刷新保留本标签页的回答草稿和聊天草稿；重新打开页面可恢复服务端待处理项，服务仍在时继续原交互，不重发用户消息 |
| H05 | 停止结束当前请求，待回答／待确认项不可继续提交；迟到或其他会话的回答／决定不能推进执行 |
| H06 | 导航分别显示“待回答”“待确认”并进入需关注；蓝点仍只表示新回复未读 |
| H07 | 原问题、用户回答、操作决定及工具实际结果可查；已确认不等于执行成功，跳过提问不等于批准操作 |
| H08 | 服务重启后未完成交互失效，记录保留；已批准但结果不明时提示核对，不自动重放 |
| H09 | 普通聊天、上传、文件读写、下载和只读子 Agent 沿用已有行为；bash 按明确规则检查参数，沙盒边界不因批准而扩大 |
| H10 | 主 Agent 可按需使用 AskUser，支持单个或多个问题、单选／多选及自定义文字回答；用户回答后在当前请求内继续处理 |
| H11 | 用户可以跳过提问或停止；未回答的信息不伪造，不将默认选项当成用户答案；普通聊天提问仍可使用 |
| H12 | 服务端规则返回允许／询问／禁止，禁止优先；命令组合逐项检查，无法可靠分析时询问，规则故障不放行 |

## 验收方式

AskUser 使用真实任务验证，例如先询问报告格式，再按回答生成文件。bash 在独立测试目录验证删除前确认，批准后检查实际文件效果，拒绝／停止时确认文件未变。禁止命令通过执行计数证明未运行，不在用户文件上做破坏性试验。

保留默认关闭的 confirmation_demo，仅用于无业务系统条件下的通用确认、执行失败与竞态探针；不在日常界面常驻。详细标准见 [F01～F18](acceptance.md)，不替代完整 W01 的 T04 或 MVP 的 FG02。

## 产品边界

- 本期 AskUser 供主 Agent 使用；子 Agent 缺少信息时向父 Agent 返回，由父 Agent 决定是否询问用户。
- 提问使用回答卡片，操作授权使用明确按钮；通用自然语言批准识别后置。
- 等待期间同会话不接收第二条普通消息，其他会话继续；可在交互卡片回答，或停止后重新提出要求。
- 等待保留进程内 AgentSession 和已经创建的请求容器；默认无新增等待倒计时，已有显式整轮时限仍包含等待。
- 现有固定测试席位处理其可见会话，不代表生产登录或业务审批权限。
- bash 规则是可测试的命令入口检查，不保证识别任意脚本内部的删除／覆盖。工作区内普通脚本继续可执行；复杂 Shell 会增加确认，具体范围见设计。
