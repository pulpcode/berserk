# 持续后台态势研判：方案审阅

日期：2026-10-26。状态：**用户已批准实施与测试；实现进行中。**

隔离分支：`codex/continuous-background-analysis`。基线：`6ce86513022350fb752eaa3dc04a96a5d2d82a6e`。

## 1. 建议实现的体验

态势信息陆续进入后，后台 Agent 自动结合获准的任务说明和业务资料，接续上一轮研判，回答“事实变了什么、原判断是否仍成立、影响哪些任务、下一步做什么”。人员无需逐条点击“继续分析”。任务中可查看当前研判、变化依据及历史；重要变化进入相关席位待办。

例如：补给任务原计划 9:40 经 A 道路，要求 10 点前送达、使用 3 辆车。道路封闭后，Agent 核对时段与路线，指出通行风险；车辆减至 2 辆后，接续评估资源缺口；道路恢复后，撤回已失去前提的绕行建议，保留车辆问题。每轮说明采用了哪些资料、与上轮相比改变了什么，不把自己的旧推测当成事实。

## 2. 首期建议范围

1. **在现有“处理与投递规则”中显式开启持续分析。** 配置来源集合、分析方案和固定接收席位。一次配置后自动运行；任务页首期只展示，不再增加逐任务订阅开关。
2. **同一配置合并短时间来报，一轮自然分析可以涉及多个任务。** 不先把每条消息完整分析一遍、再固定调用第二个 Agent 重做任务分析。资料没有任务归属时仍可形成研判。
3. **承接 Pi 原生多轮历史。** 复用公开 SDK、工具循环及默认压缩，宿主只管理输入批次、已发布结果引用和通知状态，不建设第二套记忆或 Agent 编排平台。
4. **当前研判按任务及资料范围分别显示。** 同一任务出现在不同权限范围时保留分别可见的结果，不生成越权的全局合并结论。
5. **只有重要变化生成新提醒。** 普通核对更新研判和依据，不新增待处理项。原始来报仍可在工作总览追溯；旧模式保持原有逐条处理和投递行为。
6. **首期自动化限于查询、研判和文字建议。** 任务目标、正式方案、分派、验收、地图和文件不自动修改。用户可从固定研判版本进入本席位对话继续处理。

启用持续模式意味着固定接收席位可查看该配置下已发布的研判及其获准输入，即使本轮没有发提醒；必须同时满足所有配置来源的接收范围和资料范围。这项明确授权不能由“公共任务可见”替代。

## 3. 使用与交互

- **工作总览：** 获授权人员管理持续分析配置及运行；固定接收席位可浏览获准的已发布研判记录，包括没有任务归属或没有提醒的轮次，不因此获得管理权限。
- **任务首页：** 查看当前研判、相对上次的变化、尚未核实的问题、资料截止时间；可展开依据和历史。
- **工作待办：** 接收重要变化；提醒固定引用当时结果，后续有更新时提供“查看当前研判”。阅读或模型完成不自动标为已处理。
- **继续讨论：** 用户显式打开本席位对话，带入选定版本。后台更新不抢导航、不覆盖草稿，也不自动读取或共享该私有对话。

正常推送无需人员点击继续；配置、业务决策和异常恢复仍有明确操作入口。

## 4. 需要审阅的取舍

| 建议 | 原因及限制 |
| --- | --- |
| 首期以来源规则配置持续分析，自动查询相关活动公共任务 | 直接延续现有接入方式；暂不建设个人订阅、逐任务开关和私有任务自动分析 |
| 计划与进展先由任务管理者明确写入现有任务说明 | 现有任务没有统一的正式方案或进度正文，不能声称后台已读取各席位方案文件；自动引用共享文档后续独立设计 |
| 重要变化由 Agent 记录理由，宿主核验依据引用和版本 | 格式合法不代表判断正确；须通过真实模型场景评估误报、漏报及旧判断污染 |
| 队列保留，运行中断不自动重放 | 复用现有恢复边界；中断提示管理人员恢复，随后创建新轮次处理保留信息；不要求逐条重启 |
| 重要轮次产生独立待处理提醒，静默轮次不产生提醒 | 包括重要风险解除，人员仍需分别确认处理；首期不自动合并或结清旧待办，旧提醒标识已有后续依据 |
| 持续模式首期只用固定接收席位 | 同一原生历史必须具有一致的资料与受众范围；补充席位审批保留在旧模式，不直接嫁接到持续模式 |

普通更新的合并时窗建议先以“静默 5 秒、最长等待 30 秒”作为隔离验证参数；运行中新增信息进入下一轮，不反复中断当前轮。参数待测量后确定，不承诺固定端到端完成时限；首期不增加模型紧急度分类或抢占调度。

## 5. 如何验收

用同一任务连续输入“道路封闭→车辆减少→道路恢复”，验证无需逐条点击即可接续，并保留未解除的风险。增加重复消息、密集推送、旧通知晚到、任务说明修订、来源失败、无任务／多任务、权限隔离及服务中断场景。

工程验证检查触发、版本、发布与通知；模型验证另行检查判断质量。技术成功不能替代语义准确，失败和误判原样保留。当前只完成方案和只读代码研究，尚未运行产品修改后的测试或新模型实验。
