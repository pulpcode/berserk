# 上线时的配套事项（本次未执行）

实现发布后，既有部署的数据目录配置不会因仓库 example.json 改名而自动更新。部署时应只将 context-config.json 中 intel/situation 的 name、background-config.json 对应固定接入来源的 name 统一为“特情系统”“态势系统”。先核对 systemId/sourceId 映射，不按旧名称猜来源；不修改接入标识、凭据、权限、处理规则或历史消息。

新场景定义版本为3，旧版本快照、已生成消息及回执保留。必须在仍兼容旧版本的服务上先核清 pending 及通知接收结果，并由导演显式锁定（pause）旧活动演示，再配套升级模拟服务/宿主与配置。升级后旧定义不允许新 control/pause，而启用新演示要求旧轮已锁定；不得升级后直接改数据库标记绕过。完整备份及旧版配套数据留作回退。旧活动版本不自动改写或继续投放，使用新样例需人员显式重新演示，不自动终止/启用/投放新轮。不开展付费模型或自动规则启用。

七类系统后延至SIM-DOMAIN-001，SIM-TASK-001/002不在本次范围。
