# 界面审视

旧界面实际核对：1280×720 桌面下，图标身份位于名称和信息性质之后，方向说明占两行，四个同级折叠区使更多样式落到首屏以下。用户原试用 tab4 有未保存的水罐消防车45°，不刷新该页。

本次仅改既有组件呈现。ui-ux-pro-max 本地目录查询 progressive disclosure form fields desktop / progressive disclosure 未命中对应专题；不把无关检索当依据，采用 skill Quick Reference 的分组、按需展开、标签可读、保存固定可达等通用指导，并以仓库现有数据与编辑契约为准。

运行时 style.color 影响普通点与标签；专业符号本体颜色来自固定资产。隐藏控件前须核对真实使用，不因布局改变而删除既有数据。

独立审阅补充：图标替换目录作为表单内嵌搜索时，搜索 change 冒泡会误标脏；Enter 的原生隐式提交也会直接保存。新目录边界隔离这两种行为，同时选定图标关闭目录后把键盘焦点返回更换按钮。均按已明确的“目录浏览不写入、显式保存”契约修正。
