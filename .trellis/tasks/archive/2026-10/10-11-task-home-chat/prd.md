# 任务说明与新建对话同页

用户已审阅三种方案，明确要求开始实施推荐的“说明与对话同页”，上线并提交 Git。此前图标已确认为工作公文包/个人文件夹。

## 行为与验收
- 点击侧栏工作任务或个人空间，默认显示首页：任务名称、状态，上方说明（目标/背景/现有 context），下方新建对话输入区。
- 首次展开说明，支持折叠并按当前身份和任务记住选择；长说明可展开全文，不让长文把开始对话推出主要视野。
- 有权限时说明右上提供编辑；沿用现有编辑与冲突处理。
- 首页可以输入并发送第一个问题，复用现有 useChat / lazy workspace / conversation creation / model readiness，不引入新后端接口。等待、失败保留草稿、防重复、导航竞态、归档禁止新工作。
- 开始后进入正常聊天界面，保留任务名称与“查看任务说明”入口。已有会话/草稿不被覆盖。
- 保留相关信息、态势、eventId/jobId 深链接与浏览器前进后退。没有显式页签的任务入口默认首页，历史信息详情链接仍打开相关信息。
- 延续现有浅色设计与 Lucide；375px 和桌面可用，输入有标签，折叠 aria-expanded / controls。
- 最小前端修改 + 相关 e2e 回归；typecheck/lint/build/必要测试通过后备份并更新线上，浏览器验证。

## 边界
仅调整任务入口布局和新建对话衔接。复用现有接口和权限，不改后台信息处理、地图业务、认证规则。
