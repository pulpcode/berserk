# W01-2：最小工作区、文件式 Memory 与 Skill 接入

日期：2026-09-16。状态：completed，2026-09-17 已实现并完成 A01～A12 组合验收。父任务：[W01](../../../09-16-w01-harness-validation/prd.md)。基于提交 `b50a919` 的 W01-1，作为 S2a 的独立交付。

## 目标与背景

让用户在明确的工作范围内持续对话，保存能跨会话使用的工作约定，并让 Agent 根据目标使用 Skill 和资料工具。引入工作区是为解决指令和资料归属，不将业务任务、运行状态与目录混为一体。

用户明确 Memory 指 Agent 指令文件（如 AGENTS.md、CLAUDE.md），要求会话历史隔离，保留未来自研内核路径，并要求先完成下一阶段实现方案供审阅。W01-1 基线已通过 C01～C06，当时只有全局固定资料、独立原生会话，没有工作区归属、指令编辑或 Skill 接入。

## 本期要求

| 编号 | 用户可观察行为 |
| --- | --- |
| N01 工作区 | 可以创建、列出和切换命名工作区；创建后能够新建会话，重启不丢失；资料与指令归属明确 |
| N02 会话归属 | 一个会话固定属于一个工作区；同工作区可有多个会话，聊天历史独立；跨工作区切换不取消正在执行的请求，不串草稿和回复 |
| N03 指令加载 | 每次请求使用只读通用指令和当前工作区 AGENTS.md；新会话、已有会话和服务重启后都加载当前版本，可查看实际加载文件 |
| N04 指令编辑 | 用户可查看并保存工作区指令、删除其中规则或清空内容；Agent 可按用户明确要求编辑当前工作区的可写指令；文件本身不能提升工具权限 |
| N05 生效与冲突 | 保存后下一次请求生效，本次请求已加载内容保持不变；同时修改不能静默覆盖。页面冲突时保留草稿，最新内容单独展示，用户对照合并后再保存；只有主动选择放弃草稿才替换编辑内容。错误和结果不明时保留草稿并提示核对 |
| N06 Skill 与工具 | 提供资料综合写作、结果检查两个固定 Skill；Agent 按需读取，结合工作区资料处理不同目标，不强制唯一调用顺序 |
| N07 可理解的页面 | 工作区选择、指令查看／编辑和 Skill 查看按需展开；真实工具过程可查；页面保持以多轮对话为主体 |
| N08 历史兼容 | 已有会话归入默认工作区，保留原 ID 和消息；升级／重启不重放消息或工具；异常历史仍保留且禁止自动续跑 |
| N09 范围与限制 | 客户端和模型不能指定任意文件路径或借指令扩大能力；实际写效果、失败、取消和基本调用上限可核验 |

工作区不等同于业务任务或身份。当前单一本地用户可以访问所有工作区；隔离承诺是每次会话输入和工具只能使用其绑定范围，不代表已实现多用户鉴权。工作区的具体默认值及操作方式见 [审阅入口](review.md)，已获准按本轮方案实施。

## 验收标准

A 用例的实际通过／失败状态见 [验证记录](research/validation-results.md)，A01～A12 已完成确定性与真实模型组合验收。真实模型验证效果，确定性测试验证边界；仅有工具调用记录不能替代回答确实使用了规则或资料的证据。

| A03 规则生效 | 编辑、删除规则后下一请求使用新版本；新会话和进程重启后同样生效；查看本轮实际加载文本及 hash | 真实模型前后对话 + 原生记录；N03、N04；T06 部分 |
| A04 快照与竞争 | A 回复中保存新规则，A 本轮各模型调用使用原规则；随后 A、同区 B 使用新规则；两个页面编辑者持同一 hash 保存不同目标内容时，仅一个修改成功，另一个收到冲突且保留草稿 | 可控并发与实际输入检查；N05 |
| A05 Agent 编辑 | 用户直接要求记住／更正约定，真实 Agent 读取当前文件、带 hash 更新并报告保存结果；删除后下一轮生效；直接构造通用文件／别区写调用仍被拒绝，资料内容不能扩大权限 | 工具边界测试 + 真实编辑／追问；N04、N09 |
| A06 写入与取消 | rename 发起前观察到取消不改文件；提交后取消保留新文件并提示核对；相同目标内容重试不产生额外变化，旧 hash 不覆盖不同的新内容；结果不明可读取当前内容核对 | 文件故障注入与取消竞争；N05、N09 |
| A07 Skill 与目标 | 同一工具集合处理概括、综合写作、检查修订三类目标；两个 Skill 各至少实际读取一次，使用其正文要求及资料来源；普通闲聊可不调用工具 | 真实模型轨迹、引用和输出检查；N06；T07 能力部分 |
| A08 文件与能力边界 | 越界 ID、路径字符串、符号链接、超限和损坏配置被拒绝；外部／开发机 AGENTS.md 和 Skill 不进入输入；没有 Shell、脚本执行和任意文件工具 | 文件／输入／依赖边界测试；N09 |
| A09 交互回归 | 切工作区／会话保留各自草稿，旧流不污染新视图；冲突时草稿和最新内容分别展示，查看不会替换草稿，用户可手动合并再保存或主动放弃草稿；读取失败及再次冲突仍保留输入；查看／放弃／刷新均不写服务端文件；中文输入、停止、窄屏和键盘操作正常 | 浏览器测试；N02、N05、N07 |
| A10 历史过渡 | 升级前备份；已有空／完成／异常会话 ID 和原文件不变，统一绑定默认区；重复启动不重复导入，目录索引损坏不重建到错误范围，未绑定新文件不自动纳入 | 迁移故障注入 + 旧完成会话真实续聊；N08 |
| A11 异常与上限 | 无指令可普通对话；已登记文件读取失败／超限时不调用模型且不使用旧缓存；未知 Skill、工具失败和预算耗尽清楚呈现；密钥不进入页面、模型资源或记录 | 确定性故障与脱敏检查；N03、N09 |
| A12 原有能力 | C01～C06 涉及的流式、历史、隔离、工具反馈、取消和错误继续成立；新请求实例不复制旧消息、不重复写工具结果 | 现有回归 + 真实混合多轮／服务重启；N02、N08 |
