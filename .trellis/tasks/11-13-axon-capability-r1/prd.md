# 能力中心 R1：统一专家基础与协作闭环

## 目标与背景
用户选择专业专家并在原工作台连续完成任务；会话固定实际配置修订，刷新、重启、配置更新均不静默改版。用户要求基于 feat/chat-rendering-c 最新提交新建分支和并行 worktree，依照已通过评审文档直接实施。当前分支 codex/axon-r1-experts，起点 66d0cba。

## 需求
1. 内置通用助手、资料综合示范专家及 analyst/reviewer 统一技术纳管；用户目录只展示可选专业专家。原“新建对话”继续创建通用会话；专业详情操作统一为“与专家协作”。
2. 固定 expertId/revisionId/digest 和声明技能正文，releaseVersion 只用于正式发布版本展示。相同发布版本的不同内容形成不同修订。旧会话保持原修订，不静默覆盖。
3. 全局协作先选任务/个人空间，取消不建会话；创建空会话不发送草稿、不调用模型、不创建后台工作。所有入口接入绑定，动作 ID 持久幂等；参数冲突 409。
4. 每请求和每工具当前鉴权，专家不能扩大业务权限；工作区指令实时读取。普通停用阻止新工作并允许已接受工作收尾，紧急封禁/撤权关闭调用准入并取消在途执行。
5. 账号级 administrator 离线显式授予，普通用户管理接口 403；管理权不增加业务访问权。首轮只读管理界面和 API。
6. 版本化原生绑定与执行清单，严格解码；会话历史只有原 Pi 一份。旧会话清单与新会话区别明确，损坏不降级、不重放。最小能力库与只读内容、有界缓存、真实耗时观测。
7. 保留现有子 Agent 单层顺序只读、技能标签、文件、确认、交接、后台身份和模型选择行为。仅桌面浏览器适配。

## 验收
acceptance.md 追踪 R1 原文 A01—A12；确定性权限/格式检查必须通过，实际模型输入用于证明配置生效。真实模型和 Docker 与自动替身结果分开，环境限制如实记录。包括迁移 dry-run/apply 重入、故障恢复与停服完整备份回退。

## 范围外
网页创建/编辑/发布、个人和席位默认、动态技能包导入、MCP、后台 Profile 迁移、专家团、并行/嵌套、企业智能体部署。不得顺带升级 Pi 或覆盖原 worktree 未提交修改。
