## 目标与价值

主对话一轮正常结束后，在输入框内提供一条用户可能继续输入的话。用户可以整条采纳后编辑，也可以直接输入自己的消息，减少重复输入；建议不替用户决定是否执行工作。

## 背景与基线

- 用户已选择独立请求生成建议，并在调研后决定采用空框展示、输入隐藏、删空恢复的交互；整条采纳后由用户另行发送。依据见 [交互对照](research/interaction-comparison.md)。
- 当前主对话具有严格的成功轮次与最终回复标识；输入框已有中文输入法、引用选择、草稿恢复、运行中追加消息和人工确认机制。详见 [代码证据](research/code-evidence.md)。

## 首版范围

| 编号 | 用户可观察的行为 |
| --- | --- |
| R1 触发 | 仅在当前页面观察到本对话一轮前台回复正常结束，且对话空闲、输入框无草稿和附件/引用时自动尝试。单纯打开旧对话、刷新、聚焦、按键或切换模型不触发补算。 |
| R2 建议 | 最多一条，以用户口吻承接真实上下文，沿用对话语言。没有明确下一步可以没有建议，不强行给出“继续”等套话，不虚构文件、收件人或完成状态。 |
| R3 展示 | 输入框完全为空时，以灰色占位提示展示整条建议；生成期间不显示忙碌状态或阻塞主会话。灰字尚不属于草稿，输入框失去焦点不会单独清除候选。 |
| R4 输入与恢复 | 一旦输入任何文字（含空格、换行），整条建议隐藏，不比较前缀。已生成候选保留在本轮内存中；删除到完全空且展示条件仍满足时恢复原建议，不重新请求模型。采纳后再删空也可恢复；中文组词期间暂不显示。 |
| R5 采纳 | 输入框为空时，单独按 Tab 或点击“采纳建议”将整条候选填入草稿；仍可编辑，由用户另行发送。Enter 只处理实际草稿，不隐式采纳；Shift+Tab 与方向键保持原行为。Escape 丢弃本条候选，删空后也不恢复。 |
| R6 编辑兼容 | 展示仅限当前可见对话的空输入框；Tab 采纳还须该输入框获得焦点。引用菜单、中文输入法、人工提问/确认优先；运行、排队、恢复异常、上传或引用草稿期间不展示建议。 |
| R7 会话隔离 | 发送新消息、切换对话/席位/页面/模型或关闭功能后，取消未完成预测并丢弃候选。等待生成时开始输入也会取消该请求，之后删空不补算；晚到的响应不得覆盖新草稿或恢复候选。 |
| R8 用户控制 | 建议在“设置 → 个人偏好”提供开关，首版默认开启；仅记住本次登录、当前标签页的选择，刷新保留，不新增跨设备偏好存储。关闭立即生效，重新打开从下一轮开始。 |

## 交互示例

候选：“请把两份文件的修改点整理成清单。”

| 用户实际输入/操作 | 灰字展示 | 按 Tab 后 |
| --- | --- | --- |
| 空，已有本轮候选 | 请把两份文件的修改点整理成清单。 | 整条进入草稿，不发送 |
| 请把两份文件 | 隐藏，即使匹配建议前缀 | 保持正常焦点导航，不改草稿 |
| 请先检查 | 隐藏 | 保持正常焦点导航，不改草稿 |
| 仅有空格或换行 | 隐藏 | 保持正常焦点导航，不改草稿 |
| 删除到完全空 | 恢复本轮原候选，不新增请求 | 整条进入草稿 |
| 采纳后未发送，又删空 | 恢复本轮原候选 | 可再次整条采纳 |
| Escape 拒绝后清空 | 不恢复 | 保持正常焦点导航 |

## 边界与约束

- 独立模型请求复用现有 Pi SDK、模型目录和服务端鉴权，不把建议夹入主回复，不创建工具执行循环。
- 建议首版跟随当前对话所选模型及其已有配置；不新增预测专用模型配置。独立请求会产生额外模型用量，不能承诺复用主请求缓存。
- 未采纳候选及供删空恢复的同轮副本仅保存在短期内存，不进入正式聊天、草稿存储、业务记录或主请求用量。采纳后作为正常草稿保存，发送后才形成用户消息。
- 超时、无效结果、并发占用或模型失败均静默跳过；主回复仍保持其真实结果。不自动重试或更换模型。
- 仅桌面浏览器，覆盖窗口缩放、三栏和窄面板。

## 验收标准

| 编号 | 验收场景与结果 | 对应要求 |
| --- | --- | --- |
| A1 | 合格的一轮回复结束后恰好发起一次独立请求；重复 SSE/轮询、重渲染不重复调用。打开历史、失败、取消、中断及缺少最终正文证据时调用次数为零。 | R1、R2 |
| A2 | 模型可以返回无建议；失败、超时、截断、工具调用或格式不符时不展示，主会话状态与最终回复不变。 | R2、R3 |
| A3 | 候选展示时实际 textarea value、草稿、原生历史、业务文件和主请求用量不变；空草稿按 Enter 不发送。 | R3、R5 |
| A4 | 输入首个字符即隐藏，即使是候选的匹配前缀；空格和换行也算输入。删空后恢复原候选，采纳后未发送再删空亦可恢复；部分删除到匹配前缀不恢复，全程不新增请求。 | R4 |
| A5 | 空框中 Tab/点击整条填入，不能覆盖已有输入，也不自动发送；可继续编辑并刷新恢复已采纳草稿。Escape 明确拒绝后删空不恢复，Tab 恢复正常导航。 | R5 |
| A6 | 中文组词期间隐藏，composition/229 状态下 Tab、Enter 不采纳或发送；组词结束后若有文字仍隐藏，取消组词且输入完全空时可恢复已有候选。 | R4、R6 |
| A7 | 引用菜单、附件/地图/Skill/Agent 选择、人工交互、排队消息和恢复操作仍按原规则工作，无建议抢键或覆盖。 | R6 |
| A8 | 预测等待中输入后清空不能恢复迟到响应，也不能重新生成；与已有候选删空恢复明确区分。发新消息、A→B→A、模型切换、注销及身份失效均清除候选，旧响应不写新草稿。 | R7 |
| A9 | 跨席位/账号会话、伪造模型覆盖参数、已归档/结束任务、不可用专家等不进入预测；请求期间权限变化在回包前复核。 | R7、边界 |
| A10 | 1440px、960px 桌面和三栏窄输入区内，中英文、emoji 与 125%/150% 缩放下，灰字不与原占位文案重叠、不横向溢出或撑高输入框；长建议可查看完整内容，采纳后按既有多行/滚动方式编辑。 | R3、R6 |
| A11 | 输入框失焦仍可展示候选，但其他控件中的 Tab 不采纳；键盘可采纳和拒绝，建议不冒充 textarea value，也不重复朗读。普通 Tab 导航可通过 Escape 或 Shift+Tab 使用。 | R3、R5、R6 |
| A12 | 普通席位与管理员个人对话均可使用；开关关闭后不发请求，刷新保留该标签页选择，模型管理权限保持原边界。 | R8 |
