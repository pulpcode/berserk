| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| TA01 | 一消息关联两个任务 | 两任务各有理由，引用同一 event/job；原始信息和附件没有新增归口副本 |
| TA02 | 查询到无关候选 | 不因区域、关键词命中就必然关联；模型若误判，记为语义失败，仍能人工纠正 |
| TA03 | 暂不归口／未调用工具 | 空集合加说明显示暂不归口原因；空集合加新建建议单独展示，不混为无匹配；无字段显示未记录，原分析正常可读 |
| TA04 | 错误／私有／过期任务 ID | 整批拒绝且原集合不变；返回可更正错误，不泄漏私有任务；公共任务改版后要求重新查询 |
| TA05 | 失败、取消、强制中断 | 未成功的判断不进入任务列表或作为可创建的新建建议；重启不自动重放；已成功旧结果保持 |

| TA07 | 重新处理失败或漏调用 | 原完整关联仍指向旧作业及时间，不冒充新分析；成功空集合与此行为不同 |
| TA08 | 人员纠正 | 保留、补充、移除、恢复自动判断均生效；移除其中一任务不影响其他；后续自动结果不覆盖人员决定 |
| TA09 | 并发与不确定响应 | 同一人员决定 CAS 防覆盖、原样重试不重复；冲突保留编辑；恢复后查到实际决定 |
| TA10 | 公共与个人空间 | 服务只关联活动公共任务；人员收录自己的个人空间不向其他席位或后台暴露 |
| TA11 | 权限交集 | 可见任务但无信息权限不能看到标题、理由、计数、搜索命中、文件；有 source view 但无 scope 也不可读；明确送达的普通席位可读自身结果 |
| TA12 | 私有处理隔离 | seat_analysis、普通对话及工作文件不会因公共关联而公开；关联不改变投递范围 |
| TA13 | 版本准确 | 任务列表去重，详情正文／理由／附件均来自明确可读版本；人工保留固定版本；失效链接提示刷新而非静默换正文 |
| TA14 | 查看不开始处理 | 列表、详情、工具查询、关联、能力选项不建工作区、不导入文件、不调用模型 |
| TA15 | 人员接续 | 从任务入口固定当前任务；从收件单关联可预选、多关联需选；准备对话后仍需发送，后台分析仍需明确确认 |
| TA16 | 文件处理 | 两任务 × 两席位分别导入所选附件，编辑互不影响；同 action 重试不重复制；原附件／成果不变 |
| TA17 | 模型按需使用 | 新会话可按当前任务列信息并读取指定版本，工具结果进入 Pi 历史；默认上下文不塞全部历史 |
| TA18 | 页面切换 | 侧边栏保持；深链接／返回可用；切任务、切身份、刷新及迟到响应不覆盖别处草稿或误导航 |
| TA19 | 归档与说明变化 | 已归档任务只读、不接续；已有分析版本不被改写；旧依据明确提示，不自动重跑 |
| TA20 | 升级及旧数据 | schema 3→4 无数据丢失、可重开；旧 Profile/作业/analysis action/收件仍可用，未自动重算历史 |
| TA21 | 独立需求无任务承接 | Agent 在查询后提出包含名称、目标、理由的新建公共任务建议；建议进入结果但没有自动创建任务，原分析照常完成和投递 |
| TA22 | 不应新建的情况 | 已有任务可承接时关联已有任务；无匹配但仅供参考、信息不足或任务查询失败时不据此建议新建；模型偏差记为语义失败 |
| TA23 | 人工创建并关联 | 有任务管理及结果读取权限的人员可编辑后创建；任务与固定 event/job 的人工 include 同时保存，关联固定所选分析版本；普通席位和无信息权限人员不能调用创建接口 |
| TA24 | 创建重试与并发 | 双击、响应丢失重试、两人同时处理同一建议最多创建一项任务；返回可查的实际创建结果，改参数不覆盖原任务；事务失败时无部分写入 |
| TA25 | 建议不是审批流程 | 暂不采纳不阻塞投递、不占用作业；改选已有任务走人工关联；新建不自动分派、创建工作区、复制文件或运行模型 |
| TA26 | 重新分析与已建任务 | 已建任务及人工关联保留；旧建议显示创建回执，新结果标明版本；移除关联或归档后重试原建议不会再次建任务 |
| TA27 | 公共说明与来源权限 | 表单说明名称／目标将按公共任务规则可见；不自动整段填入分析和附件，创建关联不扩大源信息及分析的读取范围 |

## 人工能力验证

复用“道路限制 → 两个西区任务与东区无关任务”，再交换或修改任务条件。查看实际查询和关联工具结果，核对相关性理由、时间关系与信息缺口是否成立。不给模型预置答案，不以成功投递代替语义正确。

用户体验主线：席位 A 收到信息 → 查看两个关联任务 → 从补给任务继续提问并导入附件 → 在设备转移任务看到同一来源但独立理由 → 移除一个误关联 → 重新处理后该移除仍保留。席位 B 仅能查看自身获准内容，其工作文件与 A 隔离。

新增任务主线：收到独立文件编制需求 → 查询现有任务后建议新建 → 获准人员检查已有任务、编辑名称和目标 → 创建公共任务并关联 → 从新任务查看同一原信息和分析 → 明确进入对话时才准备本席位工作区。再用已有任务可承接、仅供参考、资料不足的输入作对照，不把每次无匹配都当成新建需求。
