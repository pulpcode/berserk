# 图层名称最小实验结果

2026-10-17。上一轮 Pro/Flash 结果已提交 **ae7236c**（未 push）。本轮候选与报告随本次提交保存；未部署。

## 结论

显式 `layerNames` 达到本轮预先规定的探索门槛，建议保留这一最小能力。名称/ID 误用从 **5 次降至 0 次**；新组正确处理同名、缺名和历史改名。没有错误写入或权限/固定版本回归。仍有一条回答的范围措辞歧义，不能称为全面稳定，也不继续为这一句堆 prompt。

模型、业务指令、原三个场景及评分口径相同；只改变 annotation_read 的名称选择器及对应服务行为。不是仅提示模型“不要抄错 ID”，而是让工具接受用户已经提供的名称，并由程序在已授权固定版本中精确解析。

## 具体变化

**普通查询（T01）：**

```text
A：layerIds:["仓储设施"] → 参数被拒 → 读全摘要获得 storage
   → layerIds:["storage"],offset:3,limit:2 → 正确回答东仓/山脚仓
B：layerNames:["仓储设施"],offset:3,limit:2 → 直接正确回答
```

**同名（T05/T12）：**A读到两个“临时停靠”后自行采用保存顺序第一个图层；B收到两个候选ID，明确询问选择哪一层。程序没有代替用户选层。

**缺名（T06）：**A把目标“备用观察”改答为“备用器材（不是备用观察）”；对象事实本身正确，但没有回答目标不存在。B明确说明“未找到备用观察”，再将相似名称作为可选线索。A第二次该场景也能正确处理，不能归因为旧接口必然失败。

**历史改名（T07/T14）：**两组都读固定 r1 的“潮汐观察”，返回“灯塔观察点”；没有改读当前草稿“夜间潮位”中的“新灯塔观测位”。

**额外确认（A-T09）：**已读出乙备注，仍询问是替换备注、保留旧备注还是改名；按原规则停止前置，比较没有执行。B两次正常完成。但 F2不使用名称选择器，不能把这个差异归因于本次能力，可能是模型波动。

## 剩余措辞歧义

B-T02 实际只读取 A甲/B甲的基础摘要及 note，回答：

> 名称、图层（现场讨论/discussion）均一致，仅备注内容存在差异。未做任何修改。

名称、图层和两份备注都有工具证据；在本次比较范围内该描述成立。但“仅备注”可能被读成所有字段都比较过，几何等字段本轮并未读取。主审按上下文未判明确硬错误，独立复核保留这一歧义；最终以 **13条确定通过、1条歧义** 报告，宽口径为14/14。它没有证明一般性的范围解释问题已经解决，也不据此追加本轮修复。
