# R1.3 实施计划

## 1. 抽出查询结果的公共视图

- 梳理 `ResourceResultCard.tsx` 中统计时间、来源覆盖、数量口径和条目依据。提取现有视图与授权读取逻辑。先用已有测试核对工具卡、历史版本、标题和分页行为。
- 用超过十项的资源结果覆盖来源不完整、未知实体与任务关系未确认。用独立期望值核对候选名单、纳入统计的条目和分类图。

## 2. 接入聊天展示

- 扩展资源组件白名单和模型提示，接入 `ResourceResultView`，验证来源与完整详情两种参数。沿用已有展示块与普通 Markdown 降级。
- 让每个聊天结果块共享固定引用及授权复查结果。验证展开、分页、撤权、并发读取顺序、旧会话恢复及工具卡独立入口。
- 使用同一结果验证两种布局，在已有合法地图证据的回合核对地图入口。用桌面分栏和键盘完成展开、翻页与读数检查。核对折叠前只有一次范围说明，来源与逐项说明在展开后呈现。

## 3. 补齐展示指引与验证

- 同步组件参数、资源口径和五类图型参考。对照 R1.2 实现核对选图、字段类型、单位、缺失值、样例及窄栏行为。
- 在 `experiments/harness-lab` 运行受影响 Vitest、`npm run typecheck`、`npm run lint` 和 `npm run build`。用 Playwright 验证两种资源组合、窄桌面、重启恢复，并重跑 R1.1 和 R1.2 原有浏览器用例。
- 先用确定性模型和真实原生工具取得证据，再记录在线验收所需的示例。正式切换版本时保留回退，真实模型阶段验收以 R1.4 记录为准。
