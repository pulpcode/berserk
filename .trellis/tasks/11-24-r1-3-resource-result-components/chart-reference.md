# 聊天图表与资源详情参考

通用图使用 `dataset-v1` 的 `ChartView`。下表参数示例假设工具已返回对应的列 ID，数值和来源由计算回执提供。

| 图型 | 参数示例 | 常见错误 |
| --- | --- | --- |
| 柱状图 | `{"kind":"bar","x":"team","y":["orders"]}`。长分类名可加 `"horizontal":true` | 分类重复，或把单位不同的列放入同一数轴 |
| 饼图 | `{"kind":"pie","x":"team","y":["orders"],"donut":true}` | 缺项、负数和零分母让构成比例无法解释 |
| 折线图 | `{"kind":"line","x":"day","y":["orders"]}` | 无序文字横轴或重复时点。缺失值留空并保留断点 |
| 雷达图 | `{"kind":"radar","x":"team","y":["quality","timeliness","coverage"]}` | 缺少至少三项明确量程的指标，或者数值超出量程 |
| 散点图 | `{"kind":"scatter","x":"hours","y":["orders"]}` | 坐标来自不同行。缺坐标的行从图中移除并提示 |
| 表格 | `ResultTable` 使用空参数 | 为了适配图表而把未知值改成零 |

图上标出单位。桌面窄栏优先保留可读的标签和数字，精确值通过键盘可展开的数值表读取。结果表格在自身区域横向滚动。

资源查询使用 `resource-v1`。分类柱状图比较固定统计范围内的条目数。核对来源时选 `ResourceResultView` 的 `sources`，核对逐项依据时选 `details`。正文保持一个详情入口，展开后可核对覆盖、候选是否纳入统计和固定来源。
