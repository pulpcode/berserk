# R1.3 资源结果组件化与展示规则技术方案

实施方案，基于已提交的 R1.2 实现 `4c5d76d`。范围和验收见 [PRD](./prd.md)，开发顺序见 [实施计划](./implement.md)。

## 1. 用户看到什么

正文先呈现必要统计、简短的范围与关键缺口，详情默认折叠。Agent 按问题组合指标、图表和一个详情入口。

| 场景 | 建议展示 |
| --- | --- |
| 比较不同类别的条目数 | 指标、分类柱状图、可展开的「查看来源与覆盖」 |
| 核对名单和每项依据 | 指标、可展开的「查看资源明细与依据」，其中有分页明细、逐条依据及完整来源说明 |

例如，一份任务资源结果列出 12 个候选，其中 10 项纳入统计、2 项关系未确认。柱状图只统计这 10 项，详情列出 12 个候选并标记哪两项未纳入。实体总量未知时，保留「未知」和已识别部分。用户依此理解图表与名单的统计范围。

沿用现有字级、边框、间距和图表主题。新增块把统计时间与适用范围放在一行，关键缺口用一句短提示。图表有明确的单位和可读数值。展开入口直接标明内容。详情使用可键盘操作的展开控件，加载和错误提示靠近入口，窄栏自然换行。

## 2. 组件和固定资源结果

| 落点 | 实施方案 |
| --- | --- |
| `src/presentation/resource-ui.ts` 和 `src/web/result-ui/spec-stream.ts` | 沿用 `berserk-ui-v1`、`resource-v1` 和 `Stack`。增添叶组件 `ResourceResultView`，只接受 `{section: "sources"}` 或 `{section: "details"}`，子节点为空。块头沿用固定 `resultRef`。模型只选组件和布局 |
| `src/web/result-ui/ResultUiBlock.tsx` | 从当前会话的前置授权工具消息取得 `ResourceResult`，沿用既有引用规则。指标、图表、范围与详情共用一份已校验的结果。完整补丁到达即可渲染 |
| `src/web/ResourceResultCard.tsx` | 抽出当前的来源覆盖、数量口径和逐条依据视图，供工具卡和聊天适配共用。抽出的普通 React 视图接收类型化结果和界面操作回调，可以独立渲染 |
| `src/web/situation/MapContext.tsx` 和 `src/web/situation/evidence.ts` | 保留聊天与工具卡已有地图入口，只用当前流程验证过的空间分析、标注或来源证据。资源查询本身目前不会产生这些地图入口 |

组件示例中的块头和补丁沿用现有结构。简写示例展示新增叶组件的参数。

```json
{"op":"add","path":"/elements/details","value":{"type":"ResourceResultView","props":{"section":"details"},"children":[]}}
```

`sources` 提供来源系统、固定标注、覆盖、排除和限制。`details` 另外提供数量口径、分页名单和每条依据。一个结果块按用户需求选用其中一个入口。现有 `ResourceMetrics` 继续读取 `summary`。分类柱状图继续调用 `resourceStatisticsItems`，条目数使用「项」。

## 3. 授权、恢复和兼容

- 初次渲染使用实时事件或会话快照中已通过服务端验证的结果。展开、翻页或主动重读时，复用 `GET /api/sessions/:id` 并重新匹配原 `resultRef`。沿用十项一页。读取结果必须属于当前会话。
- 授权复查的状态由各入口的 React 视图持有。聊天中的同一个展示块共享这次复查。复查失败时，当前视图清除旧结果并给出反馈。请求返回顺序颠倒、切换结果或离开会话时，过期响应不得写回当前视图。
- 统计范围内的记录、条目和已知实体保留各自口径。任务资源查询里的未确认候选按原规则展示，原有覆盖和异常原因依照 `ResourceResult` 的不同版本呈现。
- 同一个结果引用和回复展示块继续保存在 Pi 会话里。服务重启时，从原生回执恢复。复用已有服务器授权、工具、存储及构建配置。
- R1.1 的 `ResourceMetrics`、`ResourceBar` 和 R1.2 的 `dataset-v1` 保持兼容。回退到旧发布时，R1.3 新叶组件可能触发旧版的格式提示，普通回复正文和原工具回执仍可读取。生成指引先提供可独立阅读的 Markdown 结论。

## 4. 展示选择规则

为模型提供短提示。维护按图型组织的参考，列出字段、正确及错误例、精确读数入口和桌面窄栏行为。资源专用图使用前述分类条目口径，通用图采用 R1.2 已有计算结果契约。

| 用户想看 | 可用展示 | 校验重点 |
| --- | --- | --- |
| 比较类别 | 柱状图 | 分类唯一，数值系列可共用单位，空值保留 |
| 看变化 | 折线图 | 时间或数值横轴有序，重复点先在计算中处理，缺失值保持断点 |
| 看构成 | 饼图或环形图 | 同一总体，值可相加且非负，显示分母 |
| 比较多项指标 | 雷达图 | 至少三轴，固定量程和方向，保留原数值和单位供核对 |
| 看两个变量的分布 | 散点图 | 数值坐标来自同一行，缺坐标的行有遗漏提示 |
| 核对确切值或证据 | 表格或资源明细 | 行与来源可查，单位、状态与未知值有文字标识 |
