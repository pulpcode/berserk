# 创建技能交互优化（2026-11-16）

实施范围为新建/方法编辑及技能页冗余文案。父代理负责CapabilityCenter文案和最终全局检查、构建/部署；本报告不把前端验证等同于用户验收。

## 实现

- 点击创建仅打开名称/简介/可选使用说明表单，焦点进入名称；确认前不创建占位草稿，取消零写入。提交生成安全引号的标准SKILL.md，通过既有create(files)一次创建完整草稿、审计和动作回执。新文件与复制源互斥，格式/完整性由既有packageContent验证，无schema或额外状态存储。
- 当前管理员检查在锁内及复制读取后保留；同动作并发、丢响应或重启后返回同一初始结果，草稿后来编辑不倒填原回执。第一次响应现在与事务内保存的回执一致，扫描独立排队不会造成初始/重试响应差异。
- 常规编辑优先表单，文件/源码默认收起；YAML文档AST只修改目标字段，未知扩展、注释、其他文件保留。查看/无变化编辑不改原始字节，正文编辑不重写frontmatter，元数据编辑保留原正文及CRLF。损坏或未适配结构回退源码编辑；EOF结束围栏新增正文补必要换行。
- 修正旧复制的实际边界：已发布文件带size/hash/mediaType，不能直接通过严格draft输入DTO。新复制投影为path/contentBase64；已有旧复制草稿仅在客户端输入/比较边界投影，不迁移、不自动保存，显式编辑保存可用。不会在异步保存返回时覆盖用户后续输入。
- 删除技能页冗余说明，扫描状态/发现和实际错误仍显示，详细覆盖报告收起；发布前置提示与原按钮的detail.policy条件一致，policyBase仍仅作本地CAS。新建/表单控件复用Axon控件token，原始源码字体布局不变。
- 名称/简介不设置错误的HTML UTF-16 maxlength，仍由服务端原有码点限额校验；合法补充平面字符不截断，超限仍拒绝。
