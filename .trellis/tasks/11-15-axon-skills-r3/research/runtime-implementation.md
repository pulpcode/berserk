# R3 运行与历史接入记录

实现：PiLab启动/关闭SkillService及受当前账号过滤的动态提供器；元数据目录不读取全包或草稿，显式选择/实际skill_read才载入固定方法正文；完整包资源仅在请求激活后物化。新schema2技能信息、资源记录及composer v7与旧v1—v6正文/校验并行，子角色输入版本化，旧SkillRevision摘要路径不变。R2专家skillRefs固定新包修订，复制/恢复/校验/试用/发布保留依赖，专家自身门禁未取消。

执行：每请求独立/skills空根只读挂载，仅放实际激活包；模板/脚本输出仍/workspace。read/ls/find沿用SDK+容器操作，grep SDK固定在宿主启动rg无法重定向，故增加单个容器只读grep适配（仍原Pi工具循环），表达式/输出/行数/超时受限且路径锚定描述符。execution-image/files.py最终SHA256 4bcd42bb3a7ac7b6ac0bfd7f60e5726f9e946801a1d0a6faff856c1d8b9b9aef，要求新不可变镜像，不更新旧tag。

SkillTrials复用CapabilityTrials及原Pi会话/文件/确认/取消/重启机制，使用独立命名空间；用户+动作固定试用ID，参数变化冲突，记录重开不重跑。方法可在无Docker时运行；有Docker时方法也可使用原文件工具，不按包目录结构限制其运行能力；不额外做环境探测，缺实际工具只记录真实限制。独立公开试用摘要仅有同包digest的状态/时间，管理员私有文件/输入/调用日志不公开。

当前权限：组织技能仍业务席位范围，无席位管理员正式个人对话仅内置。实际账号、席位和canCollaborate在服务边界复核；策略提交回调检查当前已激活请求并按原Pi stop取消实际执行；普通停用允许已准入收尾，不能用追加输入扩大任务。未使用可选技能不连坐。
