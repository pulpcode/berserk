# 交互原型（待审）

用于直观看到统一工作待办、任务对话列表和工作总览的关系。所有内容均为示例数据，交互仅改变预览状态，不连接生产接口，不代表产品实施已批准。

- 工作待办：切换待处理、跟进、已办及类型，查看工作交接与信息处理详情。
- 对话列表：可点击“去回应”进入具体对话；最新设计要求状态精简为转圈、蓝点、橙黄色点，详见详细设计。
- 工作总览：查看同一工作记录的跨席位流程，点击回到对应详情。
- 席位预览：总体席示例已获总览授权，筹划席示例未获授权；实际权限不能通过席位名称推断。
- 信息处理：显式标记、撤销；各示例席位分别保留其处理状态。

源文件为 [axon-work-preview.html](axon-work-preview.html)，适用于对话内预览的 HTML 片段。

已检查主要点击流程、对话确认后的提醒消除、处理状态和计数变化、总览跳转及 375px 窄屏布局；浏览器未报告运行错误，最终脚本通过语法检查。本原型不替代方案验收用例或产品实现测试。
