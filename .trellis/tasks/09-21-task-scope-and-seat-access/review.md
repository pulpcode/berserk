# 首增量审阅：业务任务、可见范围与席位入口

日期：2026-09-21。状态：**实现完成，待用户验收**。

2026-09-21 用户批准实施，沿用 D01～D03。历史数据不强制迁移；采用停服完整备份后初始化新数据，备份保留供离线回查与回退。

本期只建立任务与访问基础：Axon 统一维护公共任务，私有任务用于独立工作；用户登录后进入自己的席位工作台。继续使用现有 Pi、文件、Agents 与席位交接。

## 使用过程

1. A、B 使用各自账号进入工作台，不再在聊天页面任意切换测试席位。
2. A 有公共任务创建权限，填写名称与目标、确认后建立任务；B 能在公共任务列表看到说明。
3. A、B 在同一公共任务内各自新建会话；系统分别使用各自工作区，过程文件和聊天不会自动互相开放。
4. A 向 B 分派具体工作，B 提交成果，继续使用现有确认与验收。
5. 席位可另建私有任务，处理自己的资料；其他席位看不到，它也不进入后续公共自动分析范围。

## 本期采用

| 选择 | 建议 |
| --- | --- |
| 身份入口 | 纳入最小账号登录与固定席位绑定；账号由维护命令开通，不建设账号管理门户 |
| 私有任务归属 | 本期先归席位，延续现有工作区边界；若希望人员换岗后仍归本人，需要改为账号所有权 |
| 公共任务可见范围 | 所有有效席位可见任务说明；私有文件、聊天和具体交接权限保持独立 |
| 任务管理 | 创建者所在席位负责编辑／归档；进行中、已归档两种状态，归档前处理完活动请求及未完成工作项 |
| 旧项目处理 | 可停服完整备份后重新初始化，不强制迁移旧项目 |

前三项为 PRD 的 D01～D03，沿用推荐方案实施。公共／私有互转、换岗交接与复杂成员权限均后置。
