# 需求：业务任务、可见范围与席位入口

日期：2026-09-21。状态：**首增量方案待审，未开始实现**。本稿按下列待审建议展开，不代表用户已经批准身份及私有归属的具体选择。

## 1. 目标

由 Axon 统一维护业务任务。公共任务由有权限的席位确认建立，系统能知道当前开展的工作；私有任务用于独立工作，不进入公共任务目录及后续公共自动分析范围。用户通过独立身份进入自己的席位工作台，继续使用已有多轮对话、文件和协作能力。

本期只交付任务与访问基础。后台事件、队列、智能分流和管理台另行逐期设计，不以本稿审阅代替后续批准。

## 2. 已确认的方向

- 用户同意先做“业务任务与可见范围”，并讨论拆开当前同页面任意切换测试席位的入口。
- 项目与业务任务在产品中表达同一层对象；WorkItem 是其下明确分派和验收的一项工作。
- 公共任务由系统维护；私有任务不纳入系统公共业务运转。
- 工作区仍按任务 × 席位隔离；公共任务不意味着共享所有会话、文件或 Agent 指令。
- 复用 Pi 原生会话、工具、压缩、Agents、HITL 和 Docker；保持桌面端、一套应用与部署。

## 3. 待审产品选择

| 编号 | 本稿建议 | 取舍 |
| --- | --- | --- |
| D01 身份入口 | 本期纳入最小账号登录，每个启用账号固定绑定一个席位；工作台不任意切换身份 | 比独立测试网址多出认证工作，但能提供实际访问限制；测试入口仅在隔离开发模式保留 |
| D02 私有归属 | 本期私有任务归席位，沿用现有文件与会话归属；页面称“席位私有” | 同席位换人将继承该席位任务，不等同于个人永久私有。若要求始终归本人，应改为账号所有权，需重新审阅访问与迁移设计 |
| D03 公共范围 | 所有当前有效席位能看公共任务的名称、目标、负责席位和状态；各席位工作区及具体交接仍按原权限 | 本期不建设任务成员／邀请管理；若公共任务也要分组可见，需增加成员范围，不能只改页面筛选 |

D01～D03 尚待确认。文档中“我的私有任务”若出现，仅指当前席位私有任务，不把账号与席位当作同一对象。

## 4. 本期需求

| 编号 | 要求 |
| --- | --- |
| TS01 | 登录后由服务端确定账号与席位，浏览器不可通过修改席位编号冒充他人；普通工作台移除测试席位切换器 |
| TS02 | 公共任务统一保存名称、目标、负责席位、状态；有创建权限的席位经明确确认建立，创建后其他席位可见任务说明 |
| TS03 | 任一有效席位可建立自己的私有任务；他人不可列举、读取、修改或借其编号创建会话，私有任务不默认进入公共处理 |
| TS04 | 公共任务下每个席位拥有自己的工作区及会话；首次开始工作时按需建立，不复制其他席位的文件、指令或聊天 |
| TS05 | 保留 WorkItem 分派、提交、退回、验收及固定文件交接；仅在公共任务内跨席位分派，任务公开不扩大某一 WorkItem 的交接权限 |
| TS06 | 任务基本状态为进行中／已归档；归档保留历史并停止新的处理，归档不表示工作项已验收；负责人可重新开启 |
| TS07 | 用户可区分公共与席位私有任务，在同一桌面工作台切换任务、会话和文件；已有未读、草稿及流式反馈保持 |
| TS08 | 退出／过期后不能继续读取受保护数据或提交新动作；重新登录可查看已有结果，退出不自动回滚或重跑正在处理的请求 |
| TS09 | 旧任务编号、席位目录、会话及文件保持可回查；迁移明确旧项目的公私归属，不能静默把旧私人资料变公开 |
| TS10 | 任务／文件／会话／工作项／下载及模型工具执行统一核验身份和资源范围；公共任务管理权限不授予他人私有内容读取权 |

归档条件建议为：无活动处理、文件写操作及未完成 WorkItem；不满足时提示原因。归档后的历史可读，重新开启后再继续工作。不新增成果审批状态机或自动推导任务完成。

## 5. 范围与后置

本期增加：最小登录、任务目录、公私范围、任务元数据维护／归档、工作区衔接、入口调整、旧数据迁移及回归。账号开通、密码重置、席位能力由受控维护命令完成，无公开注册和账号管理门户。公共任务创建／归档先提供页面操作，不新增 Agent 管理任务工具。

后置：人员换岗／席位交接、一个账号多席位、组织架构、SSO／MFA、成员邀请、公共与私有任务互转、任务依赖、后台事件与作业、智能分流、领域系统和完整管理台。现有模型密钥与服务器可继续使用；本轮设计无需新凭证。

## 6. 通过条件

使用两个独立登录会话验证：A 建立公共任务，B 看到说明并在自己的工作区处理；A 的私有任务及公共任务内的过程资料均不能被 B 越权读取；公共任务下已有分派与成果交接正常；退出、跨标签页、归档竞争和迁移保持一致。对应 [TA01～TA16](acceptance.md)。
