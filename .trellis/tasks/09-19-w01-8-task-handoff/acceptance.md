# W01-8 验收清单

| 编号 | 场景与通过标准 | 需求 |
| --- | --- | --- |
| H01 | 旧单席位数据打开后，会话／文件／AGENTS.md 不变；启用双测试席位仍只运行一个服务，旧席位 ID 和 Pi JSONL 字节不被迁移或重写 | K01、K11 |
| H02 | A／B 分别拥有同任务工作区；切席和双标签页独立显示会话、文件及草稿，迟到 SSE／GET／上传只更新原席位；另一席位不能停止、回答或批准原请求 | K01、K11 |
| H03 | 测试路径仅接受配置白名单；会话、摘要、指令、Skill、上传、预览、下载、交接文件等都校验范围；伪造 body 席位或跨任务 ID 被拒绝。可主动切换测试席位不冒充真实认证 | K01、K08 |
| H04 | A 分派目标及两份输入资料给 B；确认前 B 看不到准备单或副本，确认后只有一个待办；新建 B 工作区的 AGENTS.md 为空且没有 A 聊天，已有 B 工作区不被覆盖；分派不调用 B 的模型 | K02、K03、K08 |
| H05 | 打开详情不改变状态；B 明确签收后进入自己的会话，多会话关联同工作。活动请求中不能改关联，不会绑定另一任务；刷新读回本席位会话关联；文件复制后可用 Pi 工具和脚本处理 | K03、K04、K08、K12 |
| H06 | 自然语言准备分派／提交／退回，模型调用工具生成具体确认；不明确对象时提问；取消或拒绝无业务交接，普通文字“批准”或旧批准不绕过规则 | K05、K09 |
| H07 | 提交确认后，A 下载到的字节与确认预览相同；准备后修改／删除源文件不改变副本；副本损坏或复制失败不产生可用提交 | K06、K08 |
| H08 | 完成提交1→退回意见→修改→提交2→验收通过；两次文件都可查，只有当前提交可验收；重复验收或另一席位操作被拒，聊天完成不代替工作完成 | K07、K10、K12 |
| H09 | 原目录、未提交副本、对方 AGENTS.md／聊天不因知道 ID 或相同文件名而可读；交接链接仅允许业务双方；导入只能到同任务本席位，不覆盖已修改同名文件 | K08 |
| H10 | 页面重复点击、prepare／commit 响应丢失、相同 operationId 重试返回原回执；两个基于旧 revision 的不同提交只有一个成功，无重复 Submission | K09、K10 |
| H11 | 业务事务成功、Pi 工具结果或 SSE 未保存时强制终止；重启可从任务详情查询已提交版本，旧工具仍显示缺结果，新请求不重复原业务提交 | K09、K11 |
| H12 | 分别在复制中、副本完成但事务未提交、等待确认时退出；不出现虚构待办／提交，未公开副本不泄露，旧未提交准备单失效；查询不执行动作 | K06、K09 |
| H13 | 同工作区两个普通对话仍可并行；业务确认等待沿用当前停止规则；提交后父请求可结束，等待对方验收不占用 Agent 或沙盒 | K05、K10、K11 |
| H14 | 页面和工具调用同一业务校验；页面不能直接提交 Agent 等待中的准备单绕过其 HITL；Agent 没有跳过确认的 commit 通道，Subagent 无写交接工具；页面放弃准备单后不可再提交，已提交效果不被取消 | K05、K08、K09 |
| H15 | 375px、键盘、焦点、表单草稿、切换和刷新可用；刷新可继续仍有效的确认；待办不混用蓝点，查看不签收，错误不清空输入，不确定结果先查询而非自动重发 | K01、K09、K12 |
| H16 | 独立数据完成两测试席位真实 DeepSeek／Docker 的文件编制与交接闭环，并完成旧功能回归、停服备份／读回及唯一 4315 入口发布检查 | K01～K12 |
