# W01-8 审阅入口：任务分派与成果交接

日期：2026-09-19。状态：**已实现，已部署，待用户验收**。

目标：席位 A 分派目标和资料，B 用现有对话与文件工具完成工作，再通过确认提交文件；A 可验收或退回，B 修改后再次提交。

实现与验证结果见 [验证记录](research/validation-results.md)。正式服务 4315 已更新。

## 本期行为

| 事项 | 本期方案 |
| --- | --- |
| 身份入口 | 按你已选择的方式，在页面切换两个测试席位；仍是一个服务，人员登录后置 |
| 文件归属 | 每个席位保留独立工作区；只有明确交接的文件副本对业务双方可见 |
| 管理什么状态 | 管理一项分派工作的待签收、办理中、待验收、已退回、已完成；普通文件不加草稿状态机 |
| 何时形成版本 | 每次提交保存一份固定文件；不对每次文件写入自动留版本 |
| 怎样确认 | 用户预览并确认服务保存的具体副本；自然语言走现有 HITL，页面提供同样的明确操作 |
| 分派后如何执行 | 接收方自己开始办理、发起对话；不自动启动后台 Agent |
| 等待对方时 | 提交工具返回后本轮可以结束；待验收保存在业务记录里，不保持 Agent 一直运行 |
| 新增存储 | 小型 SQLite 保存工作、提交与回执，文件另存；Pi JSONL 和 workspace-index v2 保留 |
| 本期限制 | 每项工作一个承办席位，每次提交一份文件；人员认证、转派、多级审批、外部系统和调度后置 |
