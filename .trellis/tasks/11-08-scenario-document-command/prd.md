# 场景第一轮 · 文档协作与控制席指挥入口

用户已批准本轮方案，进入实施。

## 目标与要求

复用普通文档和工作交接，让业务席提交、总体席审核后交给控制席，由控制席确认实际指令并取得模拟外部系统接收回执。席位之间按业务约定协作，指挥接口按明确权限执行。

- R1 复用普通文件及固定交接副本，保留提交、退回、审核和分派记录。
- R2 审核和交接是软流程；不新增方案实体、专用审批状态或审批前置检查。普通指令允许无方案附件。
- R3 控制席获得独立下达授权，页面、Agent 工具及服务端一致校验；导演、总体和其他业务席不获得该权限。
- R4 指令经人员确认后，通过 HTTP 发送给模拟外部系统，保留稳定编号、实际内容、操作者和回执。外部最小接收接口只确认接收。
- R5 重复请求、结果不明、重启和换轮时保持原指令归属与结果可核查。

## 验收

A1 实际席位走通编写、提交、退回、复交、审核、控制工作交接，附件字节一致，对应 R1。
A2 授权控制席可确认下达，缺少审核记录不构成新门禁；未授权直接调用和工具调用被拒绝，对应 R2/R3。
A3 接收回执来自实际外部 HTTP 服务，接收结果与确认内容一致，取消不发送，对应 R4。
A4 双击、重试、未知结果核对、重启及切轮不重复投放或误归新轮，对应 R5。

## 范围与待定项

车辆占用与行动反馈、专用方案体系、综合任务页、七系统拆域均后延。原生人员确认、来源权限和轮次隔离继续适用。用户已确认新增独立业务控制席，复用登录和协作能力，单独授权下达。详见 design.md。
