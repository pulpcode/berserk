# 第一轮方案 · 文档协作与控制席指挥入口

v0.1 · 2026-11-08 · 用户已批准实施

## 目标

让业务席提交普通方案文档，总体席审核后交给控制席，由控制席确认具体指令并发送到模拟外部系统。本轮打通文档交接和指令接收，第二轮再建设车辆行动及动态反馈。

## 业务怎么走

| 步骤 | 操作 | 留下什么 |
| --- | --- | --- |
| 编写 | 总体席分派筹划等业务工作，业务席在现有任务工作区编写普通文档 | 普通工作文件 |
| 提交 | 业务席通过现有工作提交，将方案文件交给总体席 | 固定文件副本及提交记录 |
| 审核 | 总体席使用现有工作审核，选择退回修改或验收通过 | 已有审核意见和对应提交记录 |
| 交接 | 总体席将认可的文件和执行要求，分派给控制席 | 控制工作及附件 |
| 下达 | 控制席阅读并核对，准备车辆、目的地、路线等指令，人员确认后发送 | 实际指令、下达人及外部回执 |

例如，总体席认可“临港仓库支援安排.md”，将固定副本交给控制席。控制席核对七辆车和路线，确认后发送。文档里写了安排，仅表示提出了安排；外部接收回执表明收到了指令，车辆出发和到场需等后续执行反馈。

## 软流程与权限

上述顺序作为席位职责和演示操作约定，写入简短职责说明，复用现有工作交接。现有工作本身的提交、审核状态照常使用。

指挥接口检查当前调用席位的明确授权，以及任务、来源范围和有效演示归属。接口不检查前面是否存在审核通过、交接完成等业务节点，也不要求文档具备专用方案状态。方案附件用于追溯，可不带附件下达，并如实记录。

控制席 Agent 可协助读文档、核对事实、整理指令，发送沿用原生人员确认机制。前端入口、Agent 工具和服务端执行同一权限检查。后台来报分析不获得下达权限。

| 角色 | 业务职责 | 下达资格 |
| --- | --- | --- |
| 业务席 | 核实、编写与提交文件 | 无 |
| 总体席 | 审核，向控制席交接执行要求 | 无 |
| 控制席 | 核对指令、确认下达、核查回执 | 单独授予 |
| 导演席 | 准备场景、投放事件、重新演示 | 无 |

**已确认的席位安排**。用户已确认新增独立业务控制席。实施时沿用现有登录、工作区和协作能力，加入业务工作接收席位列表，单独授予下达权限。现有总体、情报、筹划和态势席继续承担各自职责，导演席仅负责控场。

## 本轮建设什么

1. 复用文件提交、退回、验收与工作分派。转交采用普通固定文件副本，记录其文件编号和 hash；不新增方案实体、方案审批权限或跨工作流门禁。若当前附件只能从本席工作区选取，则沿用导入后再交接的路径，核验转交前后字节一致。
2. 在控制席现有任务工作区提供“下达指令”入口。最小输入为车辆、目的地和已有路线引用，以及可选的方案附件、执行说明；Agent 可以准备，人员在现有确认交互中核对。页面沿用现有风格，仅呈现必要字段、结果和回执查询。
3. Axon 增加受控接口适配和最少的下达记录，保存任务归属、稳定指令编号、实际内容、可选附件、操作者、发送时间与外部回执。按任务查询本人获准的记录，沿用已有私有文件和工作权限。
4. 为使本轮可真实验证 HTTP 下达，模拟外部系统增加最小“接收指令／查询回执”接口，持久保存收到的内容并返回接收编号。它属于外部模拟服务，可暂与现有模拟服务共用部署。本轮不据此产生车辆出动、占用或到场事实；动态执行由第二轮补齐。

不从文档自动推断批准，不因总体席审核而自动发送。记录“提交文件版本”即可追溯采用的内容，不建设“已批准方案版本”的新状态。

## 下达结果如何处理

- 同一指令编号、同一内容重试返回原结果，修改内容须形成新指令。双击、刷新不重复提交业务效果。
- 接收结果不明时显示“待核对”，按原编号查询；外部拒绝或离线时展示真实结果。收到接收回执后显示“已接收”，车辆执行状态等第二轮反馈。
- 指令从已绑定演示的任务取得后台归属，业务席不选择轮次。换轮时旧准备和旧确认不能发送到新轮，晚到回执仍属于原指令。本轮沿用现有隔离方式，无来源任务归属继续按 SIM-TASK-002 后续决定。
- 不把私有文档复制到公共日志。附件按原权限读取，外部接口仅接收必要执行内容及内部归属，不默认发送文档全文或私有对话。

## 怎么验收

使用实际业务席操作完成“编写—提交—退回修改—重新提交—总体席认可—交给控制席—确认下达—查询接收回执”。核对跨席文件一致、指令内容与人员确认一致。

直接调用接口、通过 Agent 工具或绕过页面时，未授权席位均不能下达。获授权控制席无需提供系统审批状态也能下达，证明软流程没有变成新门禁。再验证取消确认、重复请求、接收结果不明、服务重启及中途换轮。

本轮沿用普通文档与工作页面，暂缓方案卡、方案比较、自动有效性判定、车辆移动、行动反馈和任务综合页。漏关联与正文质量问题保留为已知模型问题，本轮不将其零错误作为开发前置条件。当前关联复验为 83/84，并非指令准备正确率。
