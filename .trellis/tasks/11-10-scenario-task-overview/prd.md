# P5：任务首页进展整合

2026-11-10拟定；2026-11-11获准实施

## 目标

单击侧边栏任务后，在现有首页掌握目标、可读取的分析、工作与执行进展，再进入原有详情核查或办理。UI简洁、克制，减少重复标题、说明及大面积卡片。

## 已确认的方向

- 保留“任务说明、相关信息、态势”三个页签，不增加页面层级。
- 用户认可任务首页交互示意方向；示例内容不是预置业务结论。
- 普通文档及工作交接继续采用软流程，不增加方案实体、硬审批、强制业务阶段。
- 用户已于2026-11-11批准编码和验证，完成后审阅结果；不自动发布。

## 要求

| 编号 | 要求 |
| --- | --- |
| R1 | 首页依次呈现目标、分析、工作进展、执行进展及新对话入口；信息按权限和实际可用性展示 |
| R2 | 原始目标可展开和编辑；分析区区分已发布持续研判与单条来报分析，显示真实出处和时间口径，不生成新摘要 |
| R3 | 从原有工作与文件记录读取状态和固定版本；跨席观察权限不等于参与、附件或私有会话读取权限 |
| R4 | 增加按任务授权的只读执行摘要，展示实际车辆状态与查询时点；不开放完整指令记录或下达权 |
| R5 | 相关信息承担原文、分析和关联依据追溯；态势承担地图、位置与轨迹，首页不复制地图 |
| R6 | 空数据、拒绝、失败及旧数据明确区分；旧任务只读，不因打开首页触发模型、指挥或场景推进 |

## 验收

1. 在“三车到场、四车受阻”情形下，首页可读到真实执行事实，并能进入本席获准的工作、信息和指令详情。
2. 无持续研判时，只能显示明确标注的关联来报分析，不冒充综合研判；无获准分析时不填示例结论。
3. 已提交、退回、验收及固定附件版本能追溯到原记录；无参与权限的观察席看不到附件正文、私有会话或办理按钮。
4. 新增执行摘要跨席只读；未授权来源、别的任务、旧轮资料、未发送准备和不确定结果不能被计为本任务已执行事实。
5. 改道、取消、重复车辆和多次指令不重复累计；不完整或不同时点的结果不伪造完整总数。
6. 新建对话、相关信息与原有地图保持可用；桌面窗口缩放、键盘、详情关闭及错误重试可用。获批后在服务器验证。

## 不在本期

自动再研判、模型正确率优化、任务关注范围自动预填/补车、无来源任务轮次归属、方案卡与自动有效性判定、共享任务文档库、七系统拆域、历史演示恢复执行、最终P6完整业务验收。

详细拟议行为与新增范围见[设计](design.md)。方案中的新增摘要权限和读取范围随v0.1一并获准；实现结果另待审阅。
