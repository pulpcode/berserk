# 精简折叠侧栏导航

## 需求
用户已确认本轮从 main 创建独立 worktree 实施，并在完成后本地启动供 UI 验收。
折叠侧栏只保留固定数量的全局入口：品牌/展开、新建对话、工作待办、工作总览、态势地图及授权的其他全局入口；设置固定底部。
任务空间、个人空间、旧测试模式项目的列表与创建入口在折叠态全部隐藏，展开后沿用现有名称、分组和创建按钮。

## 边界
行为位于 styles.css 的桌面折叠态规则；预计修改该文件和现有 chat.spec.ts 的相关断言。空间导航组件保持挂载，以保留分组状态。保持当前 64px 栏宽、Logo 展开行为、草稿和页面选择；不添加搜索、浮层、设置或手机专项修改。必要时同步 frontend/harness-lab.md 的导航契约。

## 验收
- 折叠时任务/个人/测试项目列表及其创建入口不可见且不可聚焦；入口数不随空间数量增长。
- 全局导航及设置可用，设置仍固定底部。
- 展开恢复原列表、创建按钮、分组状态与滚动位置，切换工作区仍保留草稿。
- 桌面宽窗口和窄窗口无溢出，现有 Logo/键盘展开行为通过。
- typecheck、lint、build 以及相关浏览器测试通过。
- 启动独立本地服务，提供验收 URL。
