# W01-3：上下文管理与压缩（S2b）

日期：2026-09-17。状态：**已实现并通过验收，待提交**。代码基线：`7903039`。

## 1. 目标与范围

用户在同一会话中持续讨论和调用工具，历史变长后仍能继续工作。本期采用 Pi 默认自动压缩，保留既有 AGENTS.md 独立加载和原始历史保存，通过实际续作验证效果。

项目负责模型配置、受控调用、网页状态和停止；Pi 负责判断压缩时机、选择摘要范围、生成默认摘要、保存和恢复上下文。

## 2. 既有基础

W01-1 已完成多轮对话、工具、停止和原生历史；W01-2 已完成工作区归属、Agent 指令文件和固定 Skill。当前为单一本地用户、单进程、独立会话。

实现位于 experiments/harness-lab：src/pi 负责默认压缩、受控模型流和原生历史；src/server 负责配置及 API；src/web 负责状态、设置和摘要详情。原始历史投影继续用于网页展示。

## 4. 用户可见行为

- 需要压缩时显示“正在压缩上下文”，成功后继续本次工作；摘要在请求详情中查看，原始聊天记录保持原样。
- 使用 Pi 默认摘要，不要求用户配置压缩提示词。较长的一轮可能压缩其前半段，近期保留范围按内容量确定。
- 停止只结束当前处理；后续新输入重新检查上下文，不自动补发上一条消息。已保存文件和完整摘要保留。
- 模型设置补充上下文容量、输出能力和原生压缩参数；未知时先提示配置，再由用户自行发送。
- 正常任务可以持续调用工具；模型调用、工具调用各自处理超时，用户始终可以停止。整轮总时限仅在服务端显式配置后生效。
