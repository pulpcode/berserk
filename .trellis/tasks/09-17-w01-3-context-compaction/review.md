## 需要关注的行为

- Pi 自动判断是否压缩。普通长对话和较长工具循环均可触发，无需用户填写压缩要求。
- 摘要范围之外的近期消息保留原文；特别长的一轮可以压缩前半段。磁盘和网页仍保留完整原始记录。
- 当前 AGENTS.md 继续按请求加载，不被历史摘要替代。
- 页面显示压缩状态，提供摘要详情和停止。停止后，下一次新输入重新检查上下文。
- 正常任务默认不设累计工具次数、模型调用次数或整轮总时长上限；用户可以随时停止，服务端可以显式设置整轮时限。
- 模型调用与工具调用分别处理超时。模型空闲超时默认 300 秒，由宿主 HTTP 数据进展计时；持续有响应时不会因为任务超过该时长而停止。工具超时通常返回错误供模型调整，写效果未知时先停止核对。
- 回答依据模型输出能力和剩余上下文确定额度；摘要保留 Pi 原生额度。模型瞬时错误沿用最多额外 3 次原生重试；上下文超限可先压缩再恢复一次。最终失败明确结束，不从头重跑用户任务。

## 后置能力

压缩补充要求、关键项目数据的专门保存与按需加载、手动压缩、Agent 原文检索均不作为本期前置工作。复杂预算、费用额度和重复循环检测后置；Subagent、正式运行管理和业务接入按既定阶段推进。

关键数据以后可以独立保存并参与上下文组装，不能仅靠摘要保证准确；本期先验证默认压缩的实际效果。
