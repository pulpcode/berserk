# W01-3 验收清单

状态：**B01～B13 组合验收通过**，证据见 [验收记录](research/validation-results.md)。需求见 [PRD](prd.md)，技术契约见 [设计](design.md)。

## 1. 方法

确定性测试使用真实 Pi 会话与默认压缩入口，替换模型流或 HTTP，检查实际输入、原生文件和调用次数。浏览器测试验证交互；真实 DeepSeek 测试验证摘要及续作质量，两者不能互相替代。

真实测试使用已有密钥和独立临时目录，通过原生参数提前触发，保留真实模型容量。测试真值仅在验证端保存；记录实际内容、调用数和 usage，不另设 10 条验收总量限制。

### B09 边界用例

- 持续工作：默认任务跨过 8 次工具、32 次模型尝试及 120 秒仍能正常完成；次数与用量记录完整。
- 输出额度：回答／摘要采用各自额度，超过 2,048 token 的合法摘要额度可送达提供方；按 M 或 Pi 额度截断时明确提示，不把截断摘要保存为成功。
- 模型超时：持续输出不因空闲窗口时长而停止；真正停滞和显式单次请求时限到期按原生分类处理。显式整轮时限覆盖摘要、重试和恢复，不因进展重置。
- 工具超时：取消收敛后返回错误，模型可调整并继续；未知写效果停止并核对，不自动重做。
- 重试与恢复：瞬时错误最多额外重试 3 次，provider 不暗中重试；空摘要、截断、认证等最终失败明确结束。原生一次溢出恢复可成功，再次失败时停止，不重新 prompt 原输入。

## 3. 证据与通过条件

记录 sessionId/requestId、模型／配置／Pi 版本、C/M/R/K、实际输出额度、各类超时和重试设置；保存摘要 ID、保留边界、原生估算、实际 usage 及后续答案。调用次数作为观测值。对最新纠正保留“原文—摘要—后续答案”内容对照；对文件修改保留 hash 与工具次数。报告不含密钥、Authorization 或内部思考。
