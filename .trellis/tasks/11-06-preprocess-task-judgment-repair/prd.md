# 普通初析任务判断修复

状态：v0.2，2026-11-06，**实施与三轮复验完成；工程通过，关联语义未全部达标，待用户审阅**。主审阅文件为 [修复方案](design.md)，执行顺序见 [实施清单](implement.md)。

## 目标与事实

**第一优先：让每条信息正确、完整地关联到所有需要考虑它的已有任务，可以是一条或多条。第二优先：确有额外独立工作不适合由现有任务承接时，再建议新建，并保留原有关联。** 真实保存是底线，不能用正文中的“已记录”代替；新增建议也不能替代关联覆盖。

有依据的潜在影响需要纳入，但须说明条件和待核实部分，不提升为已确认影响。仅凭同名、同一区域或理论上可能有关不能强行关联；资料不足也不能冒充已经确认无关。

- [本次复验](../11-05-scenario-business-flow/research/full-repeat-results.md)中，E05三次分别为正确判断但未记录、正确关联并记录、漏关联主任务。完整目标均进入模型请求，未发生压缩，不能归因于该目标缺失。
- [10月27日](../10-26-continuous-background-analysis/research/multi-task-results.md)已出现同类漏调；既有 [修复](../10-26-continuous-background-analysis/missing-record-repair-report.md)只接入持续研判，修复前的普通初析尚未接入。
- 修复前契约要求“关联已有／建议新建／暂不归口”三选一。这是确认的设计限制，但其对本次漏判的因果贡献尚未经过对照验证。

## 需求与验收

| 编号 | 本期要求 | 可观察验收 |
| --- | --- | --- |
| R1 真实完成 | 明确要求任务判断的普通初析，须有本作业真实记录及匹配的原生成功回执；其他方案保留可选记录 | 漏调、失败调用、旧回执或仅正文声明不能计为完成；正常记录无额外调用 |
| R2 原生补做 | 复用既有Pi结束检查及同会话补做，最多2次，程序不代写答案 | 同一作业/请求/会话内完成；成功仅投递一次；连续遗漏最终失败，原始证据保留 |
| R3 首要目标：关联覆盖 | 在宿主限定的授权业务范围内发现活动任务，按完整目标逐一核对哪些任务需要考虑本信息；包括有依据的潜在影响、有效印证与持续约束，记录所有相关任务 | 不以关键词命中、首个匹配或引用重合替代完整核对；理由说明事实、目标与影响/不确定性。既查漏关联，也查无依据误关联；检索缺口、无法判断单列 |
| R4 第二目标：新增工作 | 完成已有任务关联判断后，确有额外独立目标不适合由现有任务承接时，再建议新建；允许与已有多任务关联并存 | 新建建议不能替代或清空应有关联；目标内的未知项不自动另立任务；仅新建/仅关联仍有效，暂不归口与另两项互斥 |
| R5 展示和人员决定 | 状态取自真实数据；关联与建议分别展示；创建仍由人员确认 | 缺记录显示未完成，不投递成功分析或生成有效新关联；不改写原始正文，不自动建任务 |
| R6 兼容隔离 | 保留旧快照、可选记录语义、权限、事件级创建去重和轮次隔离 | 旧记录可读，旧作业不追改要求；取消/版本/结束竞争不越权、不写新轮；持续研判无回退 |
| R7 分层验收 | 执行完整性和模型质量分开验证；主要语义验收覆盖全部来报及当时任务，E05仅作为已知回归点 | 程序门禁全部通过；3轮完整复验按“信息×当时授权范围内活动任务”逐项核对漏关联、误关联、潜在影响表述、无法判断及实际保存；新建合理性单独评分，不能抵消关联失败；保留每次失败，不择优补跑 |

## 范围外

不改场景事实、主任务目标或对象引用帮助过测，不注入任务ID或标准归属答案。不新增Agent引擎、第二执行循环、自动建任务/派工、新页面或额外审核模型。不扩展七系统、无来源创建归属、历史恢复和新增无关来报测评。实施与三轮真实复验已获批准；线上产品发布仍待后续授权。

## 审阅重点

按已对齐意图，本版明确：**先保证所有应考虑本信息的已有任务关联正确、完整，再考虑额外独立工作。** 技术上拟采用显式记录要求、最多2次原生补做及关联与建议并存；重点审阅覆盖核对和验收口径。本版已获批准，实施与复验记录见research/，最终结果待用户审阅。

本轮结果：[三轮复验报告](research/retest-results.md)。39条均真实保存，E05三轮完整关联；按冻结全量口径仍有5项漏关联、9项无依据关联，R3整体语义验收尚未通过。
