# R1.1 聊天结果流式展示

## 目标

在原桌面聊天中，从一次真实资源查询得到固定 ResourceResult。Agent 在同一次正常回复中编排指标和柱状图。完整组件应在回复结束前出现，重开原会话后恢复原始展示。

来源为[分享讨论的 R1.1 开发范围](https://chatgpt.com/share/6b046523-a9e0-83ea-9ae2-8336a23d5448)及本次开始实施的指令。

## 要求

- 原有回复可交错呈现 Markdown 与版本化的专用 UI 块；界面保留普通代码示例和原工具详情。发布开关控制新生成，历史仍可读取。
- 首批目录支持纵向布局、统计指标和 ECharts 柱状图。指标和图表读取当前会话中获准公开的固定结果，保持统计时间、关系、可用性与未知语义。
- UI 描述只包含布局和固定引用。Pi 原生正文和工具回执负责历史保存，现有 SSE 负责流式传输。json-render 和图表依赖集中在展示模块。
- R1.2 承接通用计算文件、数据格式和其他图型；R1.3 承接资源详情组件和设计规则；R1.4 承接更广的异常兼容和验收矩阵。

## 验收

1. 使用真实工具与可控的原生 Pi 回复证明，在流结束前聊天已出现实际资源指标和柱形；后续组件与文字继续到达。
2. 真实记录数、统计条目数和空值与工具回执对应。柱状图标出计量口径，排除统计范围外候选，未知实体总量展示为未知。
3. 任意分片、重复快照和终态替换后仍只展示一次；普通 Markdown 与代码围栏渲染正常。无法解析或无法绑定原结果时给出明确提示。
4. 刷新与重入原会话恢复原图，关闭生成仍可回看。验证桌面三栏、窄聊天栏及容器尺寸变化。
