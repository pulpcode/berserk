## 实现

工程：[experiments/harness-lab](../../../../experiments/harness-lab/README.md)。本地 Web 支持新建／列表／切换独立会话、多轮流式回复、精确停止、独立草稿、错误提示、固定只读资料工具及 Pi 原生 JSONL 保存／读取。页面和 API 使用项目自己的消息与事件类型，Pi 包和原生格式封装在 src/pi。

服务为单一本地测试主体，仅监听回环地址；不包含生产登录、任务分派、Run 表、确认恢复或 Ubuntu 部署。已完成会话可恢复；不完整协议历史保留并提示新建会话。不保证执行中崩溃自动续跑。

## 版本与模型

- Node.js 24.14.0，npm 11.9.0，TypeScript 5.9.3。
- Pi coding-agent／pi-ai 0.85.1（MIT）；Fastify 5.12.5、React 19.3.0、Vite 7.3.6。依赖精确版本及传递依赖见 package-lock.json。
- DeepSeek 默认端点 `https://api.deepseek.com`，`deepseek-flash`，显式 `thinking: {type: "disabled"}`。用户已配置本地密钥。
- 用户不设置“首轮最多 10 条用户请求”的验收总量限制。单请求仍限制 90 秒、4 次工具调用／5 次模型调用、每次模型输出 2048 tokens，可在约定范围内配置。
- 初始默认值 deepseek-chat 已纠正。依据：[官方更新记录](https://api-docs.deepseek.com/updates/)、[模型说明](https://api-docs.deepseek.com/quick_start/pricing/)、[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)，2026-09-16 核验。Flash 上下文声明采用官方 1M。
- DeepSeek 函数名不允许点号，Pi／协议侧采用 source_read，公开事件与页面映射为 source.read。
