# 第二轮 · 外部模拟执行与反馈集成

2026-11-08 · v0.2 · 已获实施授权

## 目标

让控制席指令在外部模拟系统形成有据行动，Axon 可查询执行、接收反馈并支持人员调整。沿用普通文档软流程及第一轮明确指挥权限。

## 要求与验收

| 要求 | 可观察的验收结果 |
| --- | --- |
| R1 外部维护执行事实 | 接收与执行分开，允许出动后才占用、出发，来源查询与逐车记录一致 |
| R2 当前条件核验与原子占用 | 忙碌、未知、检修及不支持路线有具体原因，同车并发不重复占用，单指令整批受理或拒绝 |
| R3 场景时间驱动 | 导演手动推进才产生行动，节点按时序处理，无指令无到场，迟发不回填过去 |
| R4 受阻和人员调整 | 桥封后未过桥车受阻，经控制席确认的新调整继续绕行，已到场事实保留 |
| R5 反馈集成 | 态势来源发布自然业务回报，Axon核验归属、查询执行并按原规则分析投递，不自动改派 |
| R6 一致性与隔离 | 重复、未知、取消、重启、晚到和重演可核查，旧轮不影响新轮 |
| R8 确定性参数推演 | 更换车辆、路线及下达时刻后，结果按实际位置、路径长度及配置速度改变；模拟服务零LLM调用，同输入可重复，缺数据明确拒绝 |
| R7 简洁呈现 | 指令详情有逐车进展，地图有来源位置和轨迹，导演现有列表融入行动节点 |

## 背景与约束

第一轮已上线 f6ff748，具有人员确认、明确下达授权及 HTTP 接收回执，尚无执行受理、占用或行动进度。来源目前整对象应用预设变化，动态执行需要统一来源事务和修订处理。

范围为当前合成消防世界和明确支持的模拟路径；普通文档与工作交接继续复用。七系统拆域、真实导航与车辆接入、独立方案审批、综合任务页改版及历史恢复执行留待后续。SIM-TASK-002 无来源任务归属继续待定。

具体行为见 design.md v0.2。用户已要求完善后提交并实施。
