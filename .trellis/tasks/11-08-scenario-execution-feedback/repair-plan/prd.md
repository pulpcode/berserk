# 本轮问题修复 · 需求与验收

2026-11-08 · v0.1 · 待审阅，未实施

## 目标

让外部执行反馈提供足够的业务事实，让历史查询可以完整分页读取，并减少 Agent 对状态、时间和资源占用的错误解释。保留当前确定性模拟与普通文档软流程。

## 验收

1. 不同车辆、路线、部分改道及分批到场的反馈，均能沿来源引用核对目的地、逐车状态、位置、路线及适用的受阻原因；没有事实则明确未提供，不补预设答案。
2. 原两组超限条件可分页读完。页体积有界，翻页集合与来源匹配，无漏项、重复或无限空页；变化前后状态、修订、业务时刻及状态延续确认保留。地图与现有指令详情仍能读取完整轨迹。
3. 256 KiB宿主保护保留；读取失败或只读部分时不能表述为完整核实。历史概要明确未附累计轨迹，不能冒充完整轨迹。
4. 工程通过后固定候选、输入和评审口径，从新数据完整复验三轮。事实解释、关联、新建建议、查询完整性和真实记录分别报告；保留全部失败，不择优补跑。
5. 原13条来报沿用原目标与判定口径，新增执行反馈单列。带09:35期限的执行评估另列，不混入旧口径；只能按实际结果报告按时或未达标。

## 边界

优先R1/R2，R3做必要的小幅调整，R4不扩大为新一轮专项研判正确率工程。继续沿用特情、态势两来源，外部模拟零LLM，业务指挥仅控制席确认；不新增硬审批、自动改派、席位权限或常驻UI说明。不改变速度、准备时间、路网和原来报来凑结果；不改写旧轮报告、通知、回执及已归档复验证据。

本版的产品边界按既有约定提出，待用户审阅批准后进入实施。
