# 对象编辑浮动面板按内容收缩

用户要求：右侧对象编辑面板仍有大量空白，改成按内容高度收缩的浮动面板，让地图得到更多空间。

## 验收标准
- 对象编辑时地图使用整个可用区域，右侧不再保留整列空白。
- 面板靠右悬浮于地图上，常用区按内容高度收缩，保存/取消紧随内容。
- 展开更多属性或图标目录时面板自然增高，达到可用区域上限后仅内容区滚动，标题与保存/取消仍可见。
- 宽桌面、窄桌面分屏及较矮窗口均无页面横向溢出；为顶栏、地图底图/署名保留间距。
- 面板外空白地图可拖动、缩放；面板内操作不穿透地图。
- 保留单个地图实例、镜头、预览、精确角度、鼠标旋转、脏数据和显式保存行为；收起后仍可继续编辑。
- 原4324服务更新，已有账户与数据、用户原未保存页保留，提供新试用页截图。

## 边界
只调整对象编辑状态的布局与对应验证；未编辑时标绘工具目录沿用原行为。不引入面板拖拽、尺寸持久化、自动镜头避让或后端修改。
