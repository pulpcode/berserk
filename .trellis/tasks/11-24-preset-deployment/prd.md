# Axon 预设一键部署

## 目标

从 main 部署到全新环境时，运维只选择一次部署预设，即可开通该实例所需席位及对应登录账号，并完成实例启动验证。

## 现状

- `access:admin initialize` 初始化空库和登录签名配置，业务席位需逐账号开通。
- `seats:check` 只读核对席位清单、数据和有效集成配置。
- 登录页从启用账号构建席位选项，独立管理员通过账号角色进入同一下拉框。

## 首版范围

- 提供演练预设，开通总体、情报、筹划、态势、导演、控制六席及一个独立管理员。
- 部署入口接收实例数据目录及环境配置，从既有发布流程接管首次账号开通、预检和启动验证。
- 复用现有席位 ID、权限与集成规则。初始化时一次性交付初始账号凭据。
- 同一预设安全重跑。已有密码、会话、席位配置和业务数据保持原值，发现冲突则报告。

- 沙盒默认开启，实例可显式关闭。启用时验证 Docker 和镜像后发布，关闭时允许在无 Docker 的环境部署。

## 范围之外

运行时自动建席、网页账号管理、旧实例席位迁移、部署外部来源服务。外部服务地址和凭据仍由目标环境提供。

## 验收

1. 空目录执行一次，服务健康，匿名登录选项返回预设的六席及一个管理员入口。
2. 管理员、导演、控制及普通业务账号按实际配置获得各自权限。
3. 第二次执行后无重复记录，已有密码、会话及数据仍有效。
4. 缺少外部配置或与已有状态冲突，启动前报告具体字段。中断后用同一预设继续可完成。
5. 启用沙盒时，Docker 或镜像不可用会阻止版本切换，成功部署后能通过应用完成容器文件操作。关闭时可在无 Docker 的宿主机部署。
