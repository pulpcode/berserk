# 席位工作列表／泳道图：已批准方案

日期：2026-11-04。用户在泳道效果图交付后明确要求“好的，提交当前方案，然后开始实施”。本任务选择 **D 席位泳道** 与现有列表组成双视图；旧备选仅留作研究记录。

目标：同时看清席位、工作名称／状态和分派方向，沿用当前简洁界面。

范围：共用筛选、列表分页、200 项以内完整泳道查询、独立分派、摘要复用、视图与历史恢复、缩放／平移、异常及撤权清理。

不包括：其他栏目视图、分派表单、工作依赖／流程编辑、后台接口或数据库变更、私有权限扩展、手机端开发、push 或线上发布。

关键验收：每项工作可查；箭头固定发起→承办；超过 200 项不画截断图；筛选与返回不丢失；无业务写入；键盘与桌面分屏可用。具体要求见 [PRD](prd.md) V01～V12。

技术边界：复用既有摘要接口；独立 workView 路由；前端 SVG 与 HTML 工作按钮；无新图平台依赖。多工作布局用平移／缩放阅读，不虚构工作时序。
