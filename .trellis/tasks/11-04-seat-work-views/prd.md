# 席位工作：列表与流转图双视图

状态：用户已批准列表／泳道图方案，进入实施。日期：2026-11-04。

## 目标与用户价值

在“工作总览 → 席位工作”内提供两种展示同一批获授权工作的视图：列表便于逐项定位和核对，泳道图便于理解席位之间的分派关系。切换展示不改变工作本身或当前筛选。

## 已确认背景

- 用户已明确要“列表列举”和“流程图”两种视图，并选择以席位间工作流转为图的主要含义：谁分派给谁、工作名称、当前状态。
- 工作总览还包含研判记录、信息流转、处理运行、规则与审批；本方案只涉及席位工作。
- 最新 UI 已统一页头、移除总览菜单与介绍、将各栏目筛选改为标签／控件左右同排。本方案沿用该外观。
- 当前席位工作已有只读摘要列表、任务／相关席位／状态／标题搜索、分页和摘要详情。只读摘要能力不授予办理、文件或私有会话权限。
- 现有接口单次最多 200 项，默认每页 25 项；各页没有共同快照游标。早期“跨页抓取全部后画图”仅为讨论，不视为已确认需求。
- 用户要求方案落盘、先不实施。随后明确否定首版大卡片连线的呈现，要求视图切换／刷新靠近内容、移除总数与箭头操作说明、图控制改悬浮图标并支持滚轮缩放；这些是本轮确定的修订。

- 本轮用户提供横向泳道图参考，要求先制作清晰、简洁、美观的效果图。新增 D 席位泳道候选：每条泳道代表席位，独立工作以跨泳道分派箭头连接；用户后续已明确选定并批准本方案。

## 需求与验收

| 编号 | 要求 | 可观察验收 |
|---|---|---|
| V01 | 同一栏目提供列表／泳道图，默认列表 | 首次打开仍是列表；切换只改变席位工作，其他栏目保持原样 |
| V02 | 两视图共用当前四个筛选条件 | 切换后任务、席位、状态、关键词不丢失；图和表按同一业务条件取数 |
| V03 | 列表保留逐工作摘要 | 每个工作 ID 一行；标题、所属任务、分派双方、状态、下一步责任方与更新时间可查；保留分页 |
| V04 | 泳道图准确表示实际分派 | 发起席位和承办席位始终可区分；箭头固定发起席位→承办席位，提交、退回或验收不反转；不推断工作依赖或先后顺序 |
| V05 | 双向、多项及同名工作不混淆 | A→B 与 B→A 分开；同向多工作逐项展示；同名不同 ID、不同任务保持独立 |
| V06 | 同一摘要详情和原有权限 | 图中工作与列表工作进入同一摘要；只有参与者保留原“进入工作详情”入口；仅总览权限不扩大内容访问 |
| V07 | 视图、筛选和浏览器历史可恢复 | 刷新／前进／后退恢复所选视图；摘要返回恢复原视图、筛选、列表页码或泳道图相机；返回焦点可见 |
| V08 | 明确展示结果范围 | 图不将列表当前 25 条当全量；采用下述 200 项有界查询，超过范围明确要求缩小筛选或切回列表 |
| V09 | 大数据、长名称和窄桌面仍可读 | 字段组整组换行；长标题可查看完整文本；图有缩放／适应视图，列表有局部滚动；不挤成单字列或隐藏工作 |
| V10 | 读取和展示没有业务副作用 | 切换、展开、缩放、刷新不分派／签收／提交／验收，不调用模型，不修改任务或会话 |
| V11 | 错误与撤权有明确信号 | 普通刷新失败标识上次结果；401/403/404 清除旧摘要；无结果、加载、超限各有独立状态 |
| V12 | 键盘与文字可完整访问 | 切换、工作、聚合组、图控制可用键盘操作；方向和状态不只靠颜色；原生按钮保留焦点样式 |

## 已确定的交互修订

- 标题行只保留页面标题。视图切换和刷新移入席位工作的筛选工具区，紧邻搜索及结果，不作用于整个工作总览。
- 移除独立“共 n 项工作”提示与“箭头：发起席位 → 承办席位 · 点击工作查看摘要”常驻说明。
- 关系图使用画布右上角 32px 悬浮图标：缩小、放大、适应视图；滚轮以指针为中心缩放，空白拖动平移。画布外正常页面滚动，图标保留悬停提示／可访问名称。
- 列表保留默认入口，第二种展示固定为泳道图；不实施其他备选视图。

## 已批准的展示方向

2026-11-04 用户在泳道效果图交付后明确回复：“好的，提交当前方案，然后开始实施”。本版选定 D 席位泳道，与现有列表组成双视图；A/B/C 留在 alternatives.md 作为历史比较，不实施。

泳道以席位 ID 分行，工作节点位于承办行，独立分派起点位于发起行，折线连接。工作名称与状态直接可见，同方向多工作逐项展示。所有匹配的获授权工作均来自真实接口，不能将原型 4 个示例写死。

单次完整图查询最多 200 项；超限引导筛选或列表。状态使用原业务状态文字；短状态标签仅作为辅助，不套用当前席位的待办桶语义。

## 不在范围

流程编辑器、节点连线编辑、工作依赖建模、自动分派／催办、整体完成率、跨席位全文或文件授权、其他总览栏目的视图改造、移动端开发、新数据库表、新图数据接口、Git push 与线上发布。

## 风险与边界

200 项以上不绘制部分图；任意规模全量图延后，不能连续抓取变化中的页来伪造一致快照。工作较多时允许平移、缩放和切回列表，不通过截断节点隐藏工作。多席位、同名席位和长标题须验证；席位身份以 ID 为准。
