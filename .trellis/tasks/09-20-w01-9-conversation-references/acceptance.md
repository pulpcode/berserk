# W01-9 验收清单

状态：I01～I15 已通过确定性测试、浏览器与真实模型组合验收；待用户查看，已部署至唯一线上 4315 实例。结论见[验证记录](research/validation-results.md)。

2026-09-20 补充调整：`@` 两级菜单已完成并部署。
| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| I01 | `@` 选文件 | 先选“项目文件或文件夹”后才加载文件列表；可返回类别入口；根目录与子目录可查找；同名文件按路径区分；与上传、文件面板引用去重并共用数量限制 |
| I02 | `/` 选 Skill | 可查看说明、选择、更换、移除；只出现当前工作区可用 Skill；选择时不调用模型 |
| I03 | `@` 选子 Agent | 首层选“子 Agent”后显示角色列表；只读职责清晰；选择时不启动任务、不切换主会话角色 |
| I04 | Skill 显式加载 | 首次模型输入包含受控 Skill 正文；不用等待 `skill_read`；未选择时按需工具仍可使用；无授权扩大 |
| I05 | 真实角色委派 | 明确要求 reviewer 检查指定文件，真实调用匹配角色的 `subagent`；显示过程与结果，主会话继续回复；不能用伪卡片代替工具执行 |
| I06 | 文件＋Skill＋角色 | 子 Agent 获得明确子任务、文件引用和所选方法；不复制父会话全文；包括无 `skill_read` 的 analyst；只读权限不变 |
| I07 | 选择与实际结果 | 所选角色未被调用或调用失败时不显示已完成；正文、选择标签、实际工具卡片可区分；模型不执行要求不靠隐藏重试掩盖 |
| I08 | 独立草稿 | 双席位、两个工作区和多个会话间切换，正文／上传／选择不串；刷新可恢复待发选择；发送后下一条不继承选择 |
| I09 | 首次发送与迟到结果 | 创建会话期间继续编辑、上传晚完成、候选查询晚返回均更新正确草稿；完成事件不覆盖新草稿 |
| I10 | 对象失效与越界 | 伪造 Skill／角色／hash、额外权限字段、跨工作区文件、非法路径及符号链接被拒；失效项有错误，模型未调用，草稿保留 |
| I11 | 文件变化 | 发送前删除文件可恢复；发送后改动文件按实际内容读取，不声称引用锁定版本；不新增文件复制或锁 |
| I12 | 键盘与中文输入 | Enter 选候选不误发；Escape、Tab、组合输入、光标编辑、粘贴邮箱／路径／代码不误创建选择；移除标签不删正文 |
| I13 | 窄屏与添加菜单 | 375px 下列表、长路径、标签及发送按钮可操作；菜单与符号入口一致，错误和焦点可见 |
| I14 | 历史、压缩与中断 | 刷新／重启／压缩后原文和选择可回看；旧 JSONL 无需迁移；准备失败释放活动标记；中断不自动重放选择或委派 |
| I15 | 业务交接回归 | 文件选择用于上报时对象明确，仍弹原确认；取消选择不删文件；原有普通对话、上传、只读委派和双席位交接可用 |

契约、作用域及事件竞争用确定性测试；候选交互用浏览器测试。I05、I06 至少包括真实模型和真实文件工具轨迹，保留实际调用与结果证据；不把未执行的验收项目写成通过。
