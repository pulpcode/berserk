# W01-9 需求：文件引用与 Skill、子 Agent 选择

日期：2026-09-20。阶段：S3e。状态：已实现并通过组合验收，待用户查看；尚未部署。

## 1. 目标

让用户在发送消息前明确选择“处理哪些文件、采用什么方法、希望哪个子 Agent 参与”。复用已有文件作业、Skill 和 single 子 Agent 能力，保留自然语言交互。

用户已确认：文件、Skill、Agent 入口合并为一个开发阶段；`@` 与 `/` 分工；Agent 选择采用本条任务的子 Agent 委派，结果返回主会话。

## 2. 使用场景

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 指定材料 | 输入“比较这两份方案”，用 `@` 选择两个文件 | Agent 获得准确路径，读取材料后比较 |
| 指定方法 | 输入“检查论据和遗漏”，用 `/` 选择 review | 本条请求加载 review 方法说明 |
| 指定角色 | 输入“核对这份方案”，用 `@` 选择 reviewer 和文件 | 主 Agent 组织只读检查，子 Agent 结果回到当前对话 |
| 组合使用 | 选择文件、review 和 reviewer，再填写目标 | 子 Agent 获得必要目标、文件引用和所选方法，主 Agent 汇总结果 |
| 提交成果 | 选择文件并输入“上报这份方案” | 文件引用帮助确定对象；正式提交仍由业务工具准备并请求确认 |

## 3. 本期要求

| 编号 | 要求 |
| --- | --- |
| R01 | `@` 候选区区分文件与子 Agent；`/` 提供可用 Skill；添加菜单提供等价操作 |
| R02 | 文件仅来自当前席位、当前工作区；支持目录浏览、文件名筛选及相对路径前缀，不把其他席位的交接副本混入普通文件列表 |
| R03 | 选择后生成可移除标签，填写目标后发送；选择、切换及查看说明均不调用模型或执行工具 |
| R04 | 每条请求可选多个文件、一个 Skill、一个子 Agent；文件数量沿用当前服务配置，并与上传附件合并计数、去重 |
| R05 | 所选 Skill 正文由服务端受控加载；不要求模型先猜测应该读取哪份 Skill；未选择时保留现有按需读取能力 |
| R06 | 所选子 Agent 是本条请求的明确委派要求；主 Agent 通过既有工具执行，必要时先澄清；不得仅凭选择标签声称已执行 |
| R07 | 正文和选择项一同归属于当前草稿；切换席位、工作区或会话、首次创建会话、上传完成及发送失败均不串草稿或丢选择 |
| R08 | 历史显示本条消息的选择项，实际子任务继续显示进度／结果卡片；刷新、重启和压缩后原始选择记录可回看 |
| R09 | 无效文件、失效 Skill／角色有明确错误，保留输入；不悄悄换对象、扩大权限、自动重发或自动重新委派 |
| R10 | 支持中文输入法、键盘选择、触屏和窄屏；候选区打开时 Enter 只选择，不能误发消息 |

“只作用于本条请求”指下一条草稿不自动保留这些选择。历史中的文字和方法仍可能作为正常对话上下文被模型参考；不承诺从模型上下文中立即抹去。

## 4. 范围边界

- 当前子 Agent 继续只读、独立上下文、一次执行一个子任务；主 Agent 仍可完成写文件、执行脚本和业务提交。
- 上传文件仍是工作目录中的普通文件；引用不复制、不锁定、不生成成果版本，也不保证后续读取时文件未被其他会话修改。
- 不提供任意 Skill 安装、工作区文件自动变成 Skill、角色新增／编辑、永久切换主 Agent、多角色同时选择、并行或递归委派。
- 不提供跨工作区引用、席位 `@`、会话 `@`、全文检索、文件夹整体作为附件或任意 slash 命令执行。
- 不新增 Run／审批状态、独立历史数据库或自动重试机制。验收以 [I01～I15](acceptance.md) 为准。
