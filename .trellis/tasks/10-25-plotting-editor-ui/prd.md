# 简化标绘对象编辑面板

## 背景与授权
用户在同一 worktree 的连续标绘试用中提出“对象编辑的组件ui是否可以简化”。沿用此前已授权的交互迭代与服务试用，做现有属性面板的局部简化。

## 目标
默认面板突出图标、名称、信息性质与方向，让专业标号的常用操作无需翻阅长表单；不改变单地图工作流。

## 验收
- 专业标号以紧凑的图标识别行与就近更换入口呈现，保留标准/应用扩展标识。
- 名称、信息性质与方向保留直接编辑；数字方向与鼠标旋转继续双向同步。固定直立标号不显示无效方向输入。
- 尺寸、地图标签、图层、备注等低频设置归入单一“更多属性”；坐标与业务 JSON 按需展开，坐标新增仍直接可达坐标输入。
- 样式只呈现当前几何/标号实际适用的控件；隐藏字段与已有属性无损保存。
- 保存/取消固定可达，保留现有草稿、预览、脏数据保护、显式保存、镜头保持及只读限制。
- 宽桌面与窄分屏可用；更新原 4324 服务前端，保留已有账户、数据与用户当前未保存页面。

## 范围
仅前端属性表单、局部样式、受影响已有交互测试及规范；不改 API、存储、符号资产或地图旋转算法。
