# 设计

行为差距位于 FeatureEditor.tsx 与 annotations.css：当前名称和标号识别行重复，说明及四个同级折叠项占据首屏，专业标号也能看到无效的通用样式。

- 常用区：当前图标/标准属性 + 更换按钮（只打开本地替换目录）；名称；信息性质；可定向对象的真北方向与一句短提示。
- 更多属性：适用尺寸/样式、地图标签、图层、备注；坐标和业务 JSON 使用内层低频展开项。避免一层之外再建立复杂导航。
- 显式坐标新增初始化展开更多属性和坐标；更换目录折叠行为不能重置输入。
- 保留现有表单状态、校验、preview/save/cancel 数据链。折叠和替换目录开关不触发 dirty/write，选择新标号才更新预览。
- 仅更换显示布局，不引入通用表单框架、状态机或新组件库。
