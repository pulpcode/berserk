## 2. 背景与已确认事实

- 平台沿用 Pi Agent、现有 Node 后端和 MapLibre；遵循现有身份、任务、来源访问和标绘版本规则。
- 输入可来自标绘，也可来自已接入系统中带有空间位置的业务对象。其已有名称、类别、状态等属性可参与筛选与解释。
- 当前来源几何契约为 WGS84 经纬度的 Point、LineString、Polygon；标绘写入目前只接受简单单环面。详见设计中的代码依据与复杂几何限制。
- 卫星影像中可见的建筑、底图中可见的道路，不会自动成为结构化分析数据。
- 底图 a79f1ae 与 main@75fc7f1 已提交快照已合入本分支，空间分析架构仍可行。结果投影及工具契约整理已可复用；查询范围误报仍未解决，scope 未进入默认产品。实施前重新核查并行状态。
- 产品仅面向桌面浏览器，三栏布局、窗口缩放与地图窄面板属于验收范围。

## 3. 功能需求

| ID | 需求 | 可观察行为 |
| --- | --- | --- |
| R1 | 理解分析对象与范围 | 识别用户引用的业务对象、标绘、图层和区域；通过真实数据确定完整对象引用；歧义时澄清，不凭名称估算位置或边界 |
| R2 | 基础测量 | 计算两点地理距离、点到线最短距离、线长度和区域面积，返回明确数值与单位 |
| R3 | 空间关系 | 对支持的点、线、面组合判断包含、相交、分离；明确边界接触的语义 |
| R4 | 范围查询与分类统计 | 筛选指定区域或距离范围内的对象，结合已有属性过滤，并按已有类别统计数量 |
| R5 | 邻近查询与排序 | 在明确候选范围内，按地理距离返回最近对象或排序；不得解释为沿道路最快到达 |
| R6 | 缓冲范围 | 围绕点或线生成指定距离的范围，供展示和后续筛选使用 |
| R7 | 组合分析 | 完成范围生成、筛选、排序或统计的多步分析，说明实际参与范围和步骤 |
| R8 | 可解释结果 | 给出来源、参与对象、计算条件、可获得的版本与时间信息；区分无命中、数据不足、计算失败 |
| R9 | 地图核对 | 在现有地图上定位相关对象、展示分析范围及结果；对话数值、对象列表与地图一致 |
| R10 | 按需保存 | 分析默认不写入标绘；用户明确要求保存时，通过既有草稿工作流保存可无损表达的结果；发布和采用保持独立 |
| R11 | 权限与兼容 | 沿用现有身份和任务/来源权限；保留原始对象坐标、标识和持久数据；支持历史会话与固定标绘引用 |
| R12 | 底图独立 | 对同一输入数据和参数，影像、路网、混合视图下计算结果一致；切换不破坏结果、选择或未完成绘制 |

### 数据范围

包括用户有权访问的既有标绘、已接入的空间业务对象以及这些对象已有的属性。本期不新增外部系统集成、全国数据生产、地理文件通用导入平台或业务知识库。

“当前地图可见”“任务关注区域”和“可访问的全部来源”是不同范围。查询以明确传入的候选范围为准，页面缩放或隐藏图层不自动改变分析范围。

### 方法与结果质量

- 检查几何、单位、输入完整性和算法适用条件。
- 不能把局部页、缺失几何后的子集或失败来源包装成完整统计、完整排序。
- 可以说明资源点空间上最近；没有装备、人员、可用状态和专业约束时，不能据此作出派遣决策。
- 原始对象只读。计算输出是派生结果，其存在不代表已经保存、发布或采用。
- 历史结果展示当时依据；“查看当前来源”属于独立查询，不覆盖原分析事实。
- 方法选择须有适用条件、步骤依赖和错误示例，并能追溯到参考资料或本项目契约；参考项目的能力和评测结果不等于本平台已经具备或验证。
- 分别验证工具计算正确性、Skill 对方法选择的作用，以及正常产品流程中是否能发现和加载 Skill；使用独立用例和实际执行结果判断，不能只评回答措辞。

## 4. 验收标准

| ID | 验收内容 | 对应需求 |
| --- | --- | --- |
| AC1 | 使用独立预期值验证距离、长度、面积、包含、相交、分离；单位和数值误差符合已声明的方法与容差 | R2、R3 |
| AC2 | 对明确候选范围验证区域内筛选、最近对象排序、分类计数；缺失属性和边界对象行为可预期 | R1、R4、R5 |
| AC3 | 完成“点/线缓冲 → 对象筛选 → 排序或统计 → 地图展示”全链路，无需模型转抄中间几何 | R6、R7、R9 |
| AC4 | 对分页中断、超限、缺失几何、无命中、来源不可用、版本变化分别给出准确状态；不产生虚假的全量结论 | R8 |
| AC5 | 结果能核对来源、对象、时间与版本；相同输入快照、参数和算法版本得到一致结果；保留历史结果 | R8、R11 |
| AC6 | 浏览器中对话数据、对象列表和结果几何一致；窄面板可正常使用，定位不打断正在绘制的图形 | R9 |
| AC7 | 用户请求保存后，保存几何与预览一致；保留并发冲突、幂等与权限保护；无法无损保存时不写入错误结果 | R10、R11 |
| AC8 | 中国和澳大利亚各使用一组已知位置样例，在三种底图下验证同一分析结果；切换、快速切换及底图失败不破坏结果和标绘 | R12 |
| AC9 | 跨任务、跨席位、来源无权访问、账号失效与取消均不越权；新旧原生历史共同可读 | R11 |
| AC10 | 真实模型能选择正确对象和方法、满足组合步骤依赖并按范围解释；“最近”不被报告为“最快”；方法规则可追溯，比较无新增 Skill、明确加载与按需加载的效果，含未用于调优的保留用例；工具正确性、语义、加载及副作用分别评分，保留全部失败 | R1—R10 |

数据夹具应有独立的已知结论，不把预期答案放入产品 Skill 或业务来源。确定性验证和真实模型验证分别记录，不能以执行成功替代语义验收。

AC10 的用例分布、三组条件及拟定门槛见 [实施计划第 4 节](implement.md#4-验证矩阵与-skill-效果评测)，已随本方案批准，执行结果单独记录。Skill 未观察到增益时应如实说明并精简无效内容，不通过削弱基线、删除失败或选择性重试证明效果。

## 5. 不在第一阶段范围内

- 道路导航、最快路线、行车时间、道路等时圈等路网计算。
- 海上航线规划、漂移预测、风流海况模型。
- 高程、坡度、通视等栅格或三维分析。
- 从影像识别道路、建筑、设施或灾情。
- 动态轨迹预测、持续监测和自动告警。
- 资源调度、专业作业推荐、预案推演及自动业务决策。
- 新建业务知识库、额外 Agent 循环、通用插件框架或第二套结果存储系统。
- 新增移动端开发与验收。
