# 空间分析

使用平台真实对象、固定引用和空间工具完成只读分析。卫星影像、底图切换、页面隐藏图层都不会改变计算对象。普通分析可以独立使用本方法；需要编辑、保存冲突或发布流程时再查标绘方法。

## 1. 分开确定候选与参照

从本轮请求确定候选集合、参照点/线/面、属性条件、固定版本和所需结果。候选与参照可以在不同图层；候选范围限制不能自动变成参照所在位置。用户明确限制读取的范围则必须遵守。

已有完整引用或ID足够时直接用；读取会话标注的基础摘要，核对真实name和完整分页，找到参照与候选，再定向读取缺少的几何/属性。来源对象用 situation_query，不能用同名的草稿对象替代。先补查已有信息，确实多义且必须选择时才询问；选择须来自真实回答。不能凭名称猜坐标、类别、边界或道路连接。

## 2. 按问题选择操作

- measure：两点用distance；点到整条线用point_to_line；折线长度用length；面面积用area。输入WGS84经度/纬度，输出米或平方米，换算时使用相应单位。
- filter：input是候选，spatial.target是区域或距离参照；属性条件是实际字段的AND。要求精确半径范围时用distanceM，不把近似buffer的多边形包含冒充精确距离阈值。
- nearest：先完成候选筛选，target为参考点，然后按count排名。结果是地理最近，不是最快或可通行；不擅自扩大同距数量。
- relate：contains包含边界，intersects也包含接触，disjoint表示无交集。relate的input为区域、target为被判断对象；filter的区域在spatial.target。
- 需要区分严格内部和边界时，contains:true不足以证明严格内部。现有工具没有通用三分类结果；只有实际几何足以可靠判定时才给该结论，否则明确尚未确认的部分，不把“含边界覆盖”当成边界判断完成。
- buffer生成点/线范围用于预览或后续分析；生成范围在geometry，items仍是原输入对象。
- summarize按输入对象的实际字段分类计数，不是将字段数值求和。

几何、字段、页或权限不足时按具体错误处理，不能当成零命中。操作不支持的关系要如实说明，不能以名称或相近操作代替。

## 3. 连续分析使用真实结果引用

用前一步返回的resultRef，不从助手文字拼ID。生成范围继续分析时用`{kind:"result",resultRef,geometry:true}`；继续使用原对象时选geometry:false或实际itemIds；无生成几何的结果直接复用items。referenceItems只作参照，不能混入候选。缺少选择时按错误补参数，无需重算固定结果或额外向用户确认。

例如先筛范围、再筛属性、最后取最近若干项，每一步输入使用前一步真实命中集合；不能排名后再补筛选。read查看固定旧结果，不换成最新来源。用户要求保存时先取得草稿读取依据，再用annotation_from_analysis保存原几何；分析完成不等于已经保存、发布或采用。

## 4. 根据结果回答

回答用户要求的数量、对象、距离或分类，并交代实际范围、版本/时间与必要限制。candidateCount是该次筛选前数量，items是结果集合；hasMore仅描述本次筛选后分页。工具结果没提供的字段、对象方位或任务状态不能自行补成事实，需要时定向核实。

用户问边界就给有依据的边界结论；用户问距离不能省略计算来规避错误。核实前不先报确定数字，发现过程说错应明确更正，不能用最后答对掩盖此前错误。无需向用户输出内部检查清单，Skill不授予额外权限。
