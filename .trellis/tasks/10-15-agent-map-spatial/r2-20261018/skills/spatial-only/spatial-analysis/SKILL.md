使用平台真实对象和空间工具分析。底图、视口和图层显隐不是候选数据或权限；影像中可见的道路、建筑不自动成为计算对象。空间分析不自动保存标绘。

## 确定当前范围

从当前请求确定起点、候选集合、参照区域、属性条件、固定版本和所需效果（分析、预览或保存）。用户限定优先，任务背景不能扩大范围或增加资源需求判断。完整引用足够就直接使用；缺身份、字段或版本时用 situation_query / annotation_read 定向读取。跨会话配对与图层名称解析按 map-annotations 方法处理。

多候选无法唯一确定时，需要唯一结果或执行动作就先澄清；纯信息查询可分别核实并给出完整条件答案，标明各自身份与范围。不能默选首项或自行合并；无法覆盖必要候选时先澄清。宽范围读取后只计算其中一部分，应区分读取范围与计算范围。

## 检查数据与选择方法

输入为 WGS84 经度/纬度，先核对真实几何类型、必要属性与单位。不要将米制坐标当经纬度，或猜坐标、边界、属性、道路连接；数据不足时补查或说明缺口，不做未经支持的坐标转换。

查询结果只证明其实际返回范围：

- annotation_read 的 query 回显选择与 fields；objects.total 是该选择范围分页前的对象数，hasMore 只涉及后续页。未请求的字段没有显示，不代表字段不存在；需要时定向补读。
- situation_query 带过滤的空集只证明该查询无匹配，不能泛化为整个来源没有对象。问题仍未解决时，依据已知身份或合理查询继续查证。
- candidateCount 是操作输入候选数；filter 结果、nearest 前 N 项是输出。前 N 项不代表候选全集，不能据此否定其他对象或其属性；summarize.total 是对象数，不是容量。

工具检查权限、类型、必要分页、版本、几何和规模；Skill 不授予权限。完整候选内空集才是无匹配，缺页、缺必要字段、失败或超限都不是零命中；不能将当前页当全量或扩大用户限定范围来凑答案。

- 距离：measure 的 distance 用于两点，point_to_line 用于点到整条线。都是地理距离，不是道路行程；经纬度差不是米，线端点不能代替整条线。
- 长度/面积：length 累计折线各段，area 使用真实面轮廓；不用端点距离或包围盒替代。结果为 m / m²，转千米/平方千米分别除以 1000 / 1000000，保留合理精度。
- 空间关系：relate 的 contains 要求 input 为面、target 为被判断对象，包含边界；intersects 包括边界接触，disjoint 表示无交集。部分相交不等于完全位于，相交不证明道路连通；严格内部、仅接触边界不能冒充已支持的关系。
- 范围与属性筛选：filter 的 input 是候选，空间条件 target 是参照区域或对象；使用真实属性和空间条件。缺失字段不同于不匹配，以工具缺口为准。
- 最近 N 个：先完成全部限定条件，再 nearest；input 为候选点，target 为一个参考点。按地理距离排序，同距按完整身份稳定排序，不因并列扩大 N，也不把局部最近说成全部来源最近。
- 范围几何：buffer 用于点或线，distanceM 为米，后续以 resultRef 引用 geometry。仅判断点距线是否不超过阈值可测距或距离过滤，无需额外生成面；缓冲是近似范围，不擅改阈值或承诺测绘级精度。
- 分类数量：先筛选，再 summarize 实际字段，按完整身份去重；null 单列，字段缺失按错误处理。不能把全部候选数描述成区域内数量。

## 依赖计算、固定引用与恢复

一次 spatial_analyze 只做一个操作，按真实依赖组合：需要范围几何时 buffer → filter → summarize，需要最近对象则在筛选后 nearest；接受等价方法，不强制无必要步骤。

source 输入保留完整 systemId/objectType/objectId 和明确候选范围；annotation 输入使用固定 ref 及图层/对象选择；result 输入只用实际返回的 resultRef。集合使用 items，生成范围使用 geometry:true；同时有生成几何和原对象时显式选择 geometry:true，或用 geometry:false / itemIds 选原对象。referenceItems 是参照对象，不是后续候选。不要从摘要抄坐标或编造结果引用。

续问“刚才的范围”沿用真实 resultRef，需要恢复内容时用 read；固定读取不刷新来源。用旧范围筛选时，让 spatial.target 引用原 geometry，不重新 buffer 或用原点距离阈值替代固定多边形。用户要最新情况才重新查询分析，并区分两次快照。

错误按标识处理：参数方向或 geometry/items 选错就纠正并继续使用原固定结果，无须重复确认；身份歧义查询或澄清；来源变化需核实是否接受新快照；不可用或不支持的条件如实说明。保留已成功结果，不缩小范围、猜数据或把失败步骤包装成完整分析。一次参数错误不证明整类几何不受支持，应核对类型与输入方向。

## 核对可见回答

先完整回答问题，再说明必要范围、时间与实际缺口，不向用户展开内部检查清单。必要事实不足就补查或计算，仍不可得则说明缺口；不要以简短为由漏答。中途说明、问题选项和最终答复都须对应证据：

- 身份、数量、数值、单位和顺序与结果一致，nearest 按 items 顺序及 distanceM 回答。方向、边界位置、额外距离需要相关几何或计算依据，不从名称、示意或另一个范围推断；contains 命中不能区分内部与恰在边界。
- 范围和时间来自 scope、completeness、provenance，多来源不保证同一瞬时。未读取状态不等于状态不存在；“本轮未发布/采用”不等于“从未发布/未被采用”。
- method / limitations 限定精度和适用条件，不自行保证误差可忽略或扩大范围后的覆盖情况。
- 类别对象数没有映射就不能换算成车辆、人员或运力，任务背景也不提供这种映射。最快到达、道路通行、派遣判断需要路网或专业依据，本期不据最近距离作答；必要时询问是否改为地理距离，不暗中替换问题。

省略无依据且非必要的附加结论；“建议”“仅供参考”不能豁免事实准确性。尚未核验时说明正在核对，不提前报确定数字；已发生错误、失败和限制如实说明并纠正，不隐藏可见错误。

地图入口由界面产生，不手写 URL 或原始几何 JSON。按实际回执区分分析、预览、保存、发布和采用，调用意图不等于已完成效果。只改名称、颜色等请求走标绘工具，不额外空间分析。

## 保存分析结果

仅分析或预览不保存。用户明确要求保存时，读取 map-annotations 方法，沿用草稿、图层与版本流程；已有足够固定依据不重复读。annotation_from_analysis 使用真实 resultRef 保存已展示几何或指定结果对象，不手工重画或重算替换；原请求已要求保存则无需再次批准。

工具重检权限和草稿版本，只保存无损兼容的几何；含孔或多面不能删孔、取首块或换包围盒降级。失败保留分析事实，按标绘错误/回执规则恢复；未知写入结果先核对原回执，不换标识重试。保存、发布、设为任务当前是独立动作，不自动发布或采用。
