## 明确本次范围

从当前请求确定起点、候选集合、目标区域、属性条件、固定版本和所需效果（分析、预览或保存），区分比较双方及各自角色，不机械沿用上轮目标；用户明确要求继续时沿用对应的固定引用。用户明确限定优先；任务背景、自动草稿和引用是理解线索，不自动变成本轮分析范围或排他限制。例如“仅统计所选图层”要保留限定，而“比较所选图层与其他图层”允许读取比较对象。

已有完整对象引用、固定标绘 ref 和明确的对象/图层 ID 足够时直接使用；缺少身份、字段或版本时用 situation_query / annotation_read 定向读取，不要求每次重复查询或用户逐项点选。只知图层名时可用 annotation_read 的 layerNames 精确解析。多个同名先看本轮上下文能否区分，不默认取第一项或合并；纯查询能分别给出完整答案时，逐项标明身份和条件再给结论。必须确定唯一结果或写入目标、且仍不能区分时才提问；真实回答前不冒认用户已选择。

按用户条件筛选得到的集合、跨图层比较、生成范围和固定结果续问都可作为正常分析路径。读取范围不等于计算范围，引用某个对象不等于只能访问该对象。完整引用或唯一名称匹配证明找到了该对象，不证明符合用户意图；将实际输入的对象和角色对照当前请求。不要猜坐标、边界、属性或未提供的道路连接。

## 选择方法

先核对真实几何类型、必要属性、单位和坐标约定：输入采用 WGS84 经度/纬度；不能把米制坐标或其他坐标系直接当经纬度。前提不满足时定向查缺口或说明限制，不凭名称补齐几何、字段或做未经支持的转换。

- 两点相距多远：measure 的 distance；点离一条线多远：point_to_line。它们是地理距离，不是沿道路行驶距离。不要把经纬度差当米，也不要拿线的端点代替整条线。
- 线有多长：length；面有多大：area。折线长度包含各段，面面积来自真实轮廓，不能用端点距离或包围盒替代。结果单位分别为 m 和 m²；需要展示千米、平方千米时按 1000、1000000 换算，保留合理精度。
- 区域包含对象、对象相交或分离：relate。contains 要求 input 为一个面、target 为一个被判断对象，是区域覆盖目标并包含边界；intersects 包括边界接触；disjoint 是没有交集。部分相交不等于完全位于区域内，相交也不表示道路连通。严格内部、仅接触边界等不同问题不能直接冒充已支持的关系。
- 区域内且符合属性的对象：filter。确定候选范围后再按真实字段与空间条件筛选。空间条件中的 target 是参照区域或对象；input 是待筛选集合。缺失字段与不匹配不是一回事，以工具报告的数据缺口为准。
- 最近的 N 个：先完成全部限定条件，再 nearest。input 为候选点集合，target 为一个参考点。按地理距离排序；同距按完整对象身份稳定排序，N 不因并列自动扩大。明确实际候选范围，不把局部范围的最近说成全部来源的最近。
- 需要点或线周围的范围几何：buffer，距离用 distanceM 的米数。后续用 resultRef 引用生成的 geometry。若只需判断某个点距线是否不超过阈值，可测距或按距离过滤，不必额外生成面。缓冲是近似范围，不能自行扩大阈值或承诺测绘级精度。
- 按类别计数：先获得符合条件的集合，再 summarize 指定实际属性字段。按完整对象身份去重；null 是单独类别，字段缺失要按错误处理。不能先统计全部候选，再把它描述成区域内数量。

## 执行、引用与恢复

一次 spatial_analyze 执行一个操作。按实际依赖组织 Pi 的正常调用：例如“线周边某距离内的可用对象分类数量”，可先 buffer，再用范围结果 filter，并把筛选结果交给 summarize；需要最近若干对象时，在全部筛选完成后 nearest。等价的正确方法可以省略不必要步骤。

input 的 kind 为 source 时保留完整 systemId/objectType/objectId 身份和明确的来源/区域候选范围；kind 为 annotation 时使用固定 ref 与必要的图层或对象选择；kind 为 result 时使用宿主实际返回的 resultRef。引用筛选集合使用结果 items；引用缓冲面使用 geometry:true。结果同时有生成几何和原对象时，必须指定 geometry:true 选生成几何，或 geometry:false / itemIds 选原对象；referenceItems 是参照对象，不是后续候选。不要从摘要抄坐标、编造结果引用，或把重新查询后的变化数据说成前一次快照。

对“刚才的范围”“继续统计”等续问，使用已知真实 resultRef；需要恢复内容时用 spatial_analyze 的 read 操作。读取固定结果不会刷新来源。指定旧范围用于区域筛选时，让 spatial.target 沿实际结果依赖使用原范围几何；不能重新 buffer 或用原点距离阈值替代固定多边形。用户要最新情况时重新查询、重新分析，并区分两次依据。

定向读取后核对实际 query、fields 和分页：annotation_read 的 objects.total 是筛选范围内分页前总数，hasMore 表示该范围还有后页；未请求的字段不能当成空值。需要逐项核对时补齐必要字段和页面，不为只问总数而机械读完整几何。nearest 的前 N 项不当然等于全部候选，读取摘要也不证明全图仅有这些对象。

工具负责权限、类型组合、分页收集、版本、有效几何和规模限制；Skill 不授予权限。不能因为用户说“全部”就把当前页当全量，也不能扩大原先限定的区域。工具失败、缺失几何/属性、版本变化和超限都不是零命中。只在完整的实际候选范围内得到空集合时说明没有匹配对象。

遇到错误，先看错误标识和缺口：参数方向或 geometry/items 选择错误按契约纠正，保留同一固定结果继续，不额外请求确认；对象身份歧义用查询或澄清解决；来源变化需核实是否接受新快照；来源不可用或不支持的算法条件要明确说明，不靠改小范围或猜测数据制造成功。保留已成功的固定结果，不能把失败步骤包装成完整组合分析。一次参数错误不证明工具完全不支持该类几何，应核对实际类型和输入方向。

## 核对答复

先明确结论对应的对象或条件，再给核心结论和必要的时间/限制；短任务不必展开检查过程。核实前不先报确定数字或声称已经读过、保存成功；发现错误及时更正。对照实际结果检查：

- 对象身份、数量、数值、单位和返回顺序一致。nearest 按 items 顺序及每项 distanceM 回答；candidateCount 是该操作输入候选数，不是命中数；summarize.total 是对象数，不是容量。例如一个“车辆”类别点，只能说明一个该类对象，不能无映射依据推断一辆车或运力缺口。
- 范围与时间来自 scope、completeness、provenance；多来源读取不保证同一瞬时。未读取某状态不代表它不存在；“本轮未执行发布”不等于“该草稿从未发布或未被采用”。
- 方位、边界和距离说明需要实际几何或测量支持；名称、列表顺序和界面印象不是方位依据。contains 为真仅说明被包含（含边界），既不证明严格内部，也不证明恰在边界；精确方位、边界距离等必要问题需定向查几何或计算，现有能力不足时说明缺口。method / limitations 只支持已声明的精度和适用条件，不能自行声称误差可忽略或扩大范围就一定覆盖某对象。
- 每项附加数量、排序、状态和专业含义都要有证据。“建议”“仅供参考”不豁免事实准确性；核心计算正确但附言错误，仍然是错误回答。无依据的额外判断不写成事实；用户要求的必要结论应补查或计算，不能靠省略或多问一句回避可完成的任务。

地图入口由界面产生，无须手写 URL 或原始几何 JSON。按实际回执区分完成分析、预览、保存、发布和采用，工具调用意图不等于效果已发生。

“最快到达”“道路可通行”“最适合派遣”需要路网或专业依据，本期不能据最近距离给出这些结论。必要时询问是否改为比较地理距离，不暗中替换问题。仅改名称、颜色等普通标绘请求走既有标绘工具，不额外执行空间分析。

## 保存分析结果

仅分析或预览不发起保存、发布或采用。用户明确要求保存时，读取 map-annotations 方法并沿用已有草稿、图层和版本流程；已有足够固定依据时不重复读取。通过 annotation_from_analysis 的真实 resultRef 保存已展示几何，或选择结果中的具体对象；不手工重画，也不重算后替换原结果。原请求已要求保存就不再重复征求批准。

保存工具会重新检查权限和草稿版本，只有能无损表达的几何可保存。含孔或多面结果不能靠删除孔、取第一块或包围盒降级。保存失败保留分析事实，按标绘错误/回执规则处理；未知写入结果先核对原回执，不换标识重试。保存、发布和设为任务当前是不同动作，不自动发布或采用。
