# R3 Skill 正文试验版变更记录

日期：2026-10-22。依据已提交的[改进方案](../post-round1-improvement-plan.md)（审阅稿 `ef5d4a2`）及[本轮实施记录](../r3-implementation-20261022.md)。本目录是隔离试验素材，不是产品默认 Skill；本轮没有真实模型测试，也没有采用任何试验版。

## 三组文件怎么区分

| 目录 | 标绘 Skill | 空间 Skill |
| --- | --- | --- |
| `skills/baseline/` | 当前产品原版 | 当前产品原版 |
| `skills/map-only/` | 只改正文 | 与产品逐字节相同 |
| `skills/spatial-only/` | 与产品逐字节相同 | 只改正文 |

两份原版均直接复制当前产品 `experiments/harness-lab/fixtures/skills/`，没有继承未采用的R2试验版。六文件的完整YAML前言（名称和简介）保持原样；没有修改 `src/resources/service.ts` 目录简介、Skill选择机制、工具接口或权限。因此本轮可以比较正文指导，不能把效果变化归因于目录简介优化。

## 标绘 Skill 具体改了什么

新增或替换三处正文，其余规则保持原文：

| 位置 | 本轮指导 | 为什么这样改 |
| --- | --- | --- |
| 独立草稿说明后 | 每轮区分读取、比较和修改对象；保留会话、固定引用和对象角色；跨会话同名/短ID不能证明相同身份 | 防止沿用上一轮目标或把比较双方混为一体；共同基线身份规则来自已有标绘契约 |
| 原“用户指定已有图层”段 | 已有明确且适用的ID可以使用；只知名称时优先 `layerNames`；区分找不到与同名；信息足够直接完成；纯查询允许分别完整回答，条件与结论一起给出；唯一目标仍有歧义才澄清 | 把原来的“同名先问”细化，避免不必要提问，也不默认选第一个或合并。现有写入读取依据仍须满足，不把合法ID当成跳过写入检查的理由 |
| 原结果说明段开头 | 准备读取、已取得数据、尝试写入、保存成功分别表达；实际返回才支持效果陈述 | 防止计划或调用被解释成已完成；既有回执恢复、版本、当前采用状态规则继续保留 |

用户明确限制与上下文引用分开解释。引用某图层可以是比较的一方，不自动排斥其他合法对象；模型推断可以支持查询，但不能冒认真实用户确认。跳过、取消和未回答都不能替代选择，明确目标且已有授权时不再额外索取批准。

## 空间 Skill 具体改了什么

保留原有章节和七类方法，只调整范围、数据解释及答复核对段：

| 位置 | 本轮指导 | 为什么这样改 |
| --- | --- | --- |
| 明确本次范围 | 核对本轮对象、角色和限制；允许直接合法引用、按条件筛选、跨图层比较、生成范围、固定结果续问；同名按上下文、条件答案、必要提问处理 | 不新增“范围证明”前置步骤，也不把用户引用变成只能访问该对象的名单。引用有效、名字唯一仍不能证明模型理解了请求 |
| 执行与恢复中新增一段 | 核对实际 `query`、`fields`、`objects.total`、`hasMore`；区分筛选范围的分页前数量、当前页、前N项与全部候选 | 使用已有工具字段；不为了总数机械读取全部几何，也不能把未返回字段当成空值 |
| 核对答复 | 对象/条件和对应结论一起表达；核实前不报确定事实；几何方位和边界声明要有依据；包含边界不证明严格内部或恰在边界 | 针对数字正确但附加解释错误的历史现象；用户要求的必要结论应补查或计算，不靠省略来降低错误 |

距离、长度、面积、关系、筛选、排序、缓冲、分类统计的已有类型和单位要求保持原文；结果依赖、`geometry/items`选择、固定范围续用、分页/失败区分、权限、无损保存和未知写入回执处理均保留。没有新增计算方法、工具、持久状态、强制的读取顺序或通用范围令牌。

## 参考依据和需要自行验证的部分

源码依据详见[已审视记录](../research/range-binding-design-review-20261022.md)。本次没有复制外部代码或重新开展外部项目评测。

- Codex和DeepSeek Harness启发的是：检查能核实的输入与版本，不把“输入有效”当成“选对目标”。本候选只解释边界，复用本项目已有检查。
- Hermes启发的是区分真实回答、未回答，以及真实写入效果；没有引入其工具实现或额外审批。
- Claude Code公开资料支持按需提供方法说明；本轮保持现有Pi受控目录和加载方式，不增加另一套加载器。
- 同名条件答案、跨会话对象角色、GeoJSON/空间方法与全文事实核对仍是本项目自建规则，必须用本地对照实验验证，外部项目不能替我们证明正确率。

具体字段含义来自已有 `conversation-references.md`、`map-annotations.md`、`spatial-analysis.md` 规范及产品Skill。编写遵循 skill-creator 的精简指导原则：保留必要契约，避免把个别失败升级成所有任务都必须履行的步骤。

## 隔离与效果判断限制

正文实现者只读取已审阅方案、既有规范、产品Skill、历史R2变更记录和已有源码审视记录；**未读取新R3用例、预期答案或评分文件**。不以新题调词。本记录也未把新题编号、对象、坐标或答案写入Skill。这里只能说明编写者隔离，不声称整个项目已达到人员、模型或研究方向上的完全盲测。

另一份Skill保留原版，是单因素对照所需的控制，但其原有“同名先澄清”表述可能与试验版的条件回答许可同时出现。两份正文都被模型读到时需记录实际输入和先后顺序；不能把这些独立组称为已统一改好两份Skill的完整产品方案。后续如要组合采用，需要独立验证。

静态检查不能证明这些文字改善了模型行为。下一步仍需区分正文是否在关键决定前进入模型输入、读到后是否遵守、是否增加不必要提问，以及整段回答和实际修改是否正确；正常按需加载和显式加载分别报告。未读Skill但答对可以通过，未读到候选的波动不能说成候选的收益。
