## 这组能证明什么，不能证明什么

它可检查评分器能否区分正确数量、缺失属性、手工推导、真实工具回执和虚构过程。3条构造负例只是控制明确的检查题，不能作为模型真实失败频率或生产准确率证据。

8条共用5条基础轨迹、只有1个家族，且3条错误刻意明确，覆盖比原计划更窄；即使8/8，也不能声称评分器覆盖全部空间业务、写入越权或复杂歧义。这是启动小范围诊断的校准，不代替整体90%验收与新保留集。若不接受这一局限，则继续保留当前未启动状态，另行准备更广的新材料；不自动放宽标准、扩预算或产生模型费用。
