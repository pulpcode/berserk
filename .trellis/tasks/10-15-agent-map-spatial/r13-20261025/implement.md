# R13 实施与检查顺序

> 待用户审阅批准 [plan.md](plan.md) 后才可开始。本文件是计划，不是已完成记录。

## 1. 冻结与范围核对

- 保留 R12 方案、初始/补充结果、原始失败、两版复核、候选产品文件的哈希；不混入当前 main 的并行修改。
- 固定共同代码基准 6a631a4、依赖锁文件、两份 Skill 正文与目录 metadata、businessContext、原题干和配对初态字段。
- 固定 F01—F05 各 E0/E1 一次及执行顺序，记录 C03/C06 合并依据；固定 F05 的已知构造说明。
- 固定新预算及一次性执行标记；本次提交计划不代表启动任务。

## 2. 仅新增任务内评测适配

预计文件职责（批准后确定命名，不在本次创建程序）：

- `runtime.ts` / `cases.ts`：归档相同运行时、真实接口创建隔离夹具、规范化配对快照、原始多轮输入及澄清映射。
- `provider.ts` / `budget.ts`：实际推理参数、原生历史回传检查、原始响应记录、逐次尝试及预算保护；复用已有解析、用量和证据工具。
- `live.ts`：走真实 HTTP/Pi 循环，等待本条用户要求结束，再发预定下一轮；记录状态，不代模型决定方法，不按结果追加“修正答案”提示。
- `*.test.ts` / `tsconfig.json`：离线模拟 transport 和真实本地工具检查；不能创建真实批次 claim 或读取在线 Key 执行请求。

默认不编辑 `experiments/harness-lab/src`、Skill 正文或旧轮次程序。若依赖要求必须变更产品/SDK 内核或扩大方案允许范围，先返回方案审阅，不偷偷进入另一项实验。

## 3. 必要离线检查

| 检查 | 通过条件 |
| --- | --- |
| 组别配置 | 所有真实出站模板准确 E0 disabled / E1 enabled high，其余固定参数一致；父/子/压缩调用分别有记录 |
| 工具闭环 | 模拟模型发真实空间工具请求，工具真实执行，后续输入含匹配回执，第二/更多响应最终结束；没有首个工具请求即停止 |
| reasoning 历史 | SDK 解析非空/零思考、tool_calls、工具返回和下一条请求；实际线上格式的历史字段不丢失、不串组、不泄到公开答复 |
| 普通工具错误恢复 | 真工具参数错误返回模型，模型修正后继续；这不会被网络无重试保护错误拦截 |
| 多轮状态 | F02 三轮保存各自 resultRef，F04 两轮保存最初结果；每轮状态独立，不将后续授权提前使用 |
| 按需 Skill | 无预加载正文或候选泄漏；真实 skill_read 可用；正文和目录版本一致，未读取也正常执行并记录 |
| 配对环境 | 新身份隔离，规范化初态一致；同组自然计算结果可变，但不复用历史工具结果 |
| 保留/停止 | 参数、模型、用量、SSE、网络错误和重复调用保护可观测；有进展不被单项次数/时长提醒切断 |
| 预算 | 请求发出前记账，下一工具循环计新请求，未知用量阻止外发；达到完成预留时不开新对，总上限不可突破 |
| 澄清 | 普通文字与 ask_user 分开记录，仅原文重述允许项一次；未知问题和权限批准不会自动填答 |
| 评分 | 必要结果与全过程事实分开，工具调用不算通过；测试包含 R12 已知误述、表达歧义、明确自纠和多轮状态证据 |
| 保护历史 | 旧 R11/R12 材料、产品候选、原始结果和 claim 哈希未变，模拟轨迹与真实目录分开 |

运行新增测试、R13 范围 TypeScript、从仓库根命中实际文件的 ESLint 和 `git diff --check`。不为纯文档修改重跑模型或全产品套件；确有共享代码改动时才增加相关确定性测试。

按 Trellis 工作流由实施和检查代理独立核对离线结果；主会话独占真实执行入口。真实请求前核验当前审阅授权确实覆盖最终冻结方案，不能把过去 R12 授权当成 R13 授权。

## 4. 批次执行（尚未授权）

- 不做独立收费探测，F01 两组就是首对正式任务；请求、耗时、异常均计入十项及预算。
- 首对协议、循环和历史回传正常则推进后续预定四对；模型语义答错如实记录，不能因此改提示重跑。
- 每个用户轮次让原生工具循环完成。对已进行中的任务，数字阈值仅提醒；只有方案明示的技术异常、无进展、权限或预算条件才能停止。
- 没有自动恢复、补测、第二轮或额外裁判；任何未完成项保留初始原因与已产生用量。

## 5. 复核和交付

- 冻结原始数据后先遮蔽组别及私有思考，基于公开轨迹、真实回执及前后状态做程序核对与 Agent 独立复核。
- 每组5项，逐项主任务/严格判定、未完成原因、Skill读取与执行、查询/计算/解释失败、工具自纠、成本列齐。
- 只对本轮同题两组做配对，不使用旧“正确答案”当新对照；任何评分分歧留原句和依据，不静默改标签。
- 检查全部已发请求、真实模型、用量、证据哈希、初态等价以及历史不变；用结果报告结束本轮，不自动开始下一轮。
