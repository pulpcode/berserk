# R13 完整任务执行协议

本轮仅使用 `6a631a42b99b01de334cd2017c07bf0d9d58a560` 的共同产品归档，两组均原生按需加载 Skill。R12 历史答案、工具路径和预加载正文不进入模型上下文。旧夹具只用于核对业务事实；模型看到新建隔离会话的真实业务数据。每对先准备两份会话并比较明确字段归一化后的业务快照，再发出第一笔模型请求。

## 请求及执行

- 固定 F01—F05 × E0/E1，共 10 个任务，交替先后顺序；F02 三个用户业务轮、F04 两个业务轮。每项一次，无自动重试或补位。
- 唯一模型入口：`https://ark.cn-beijing.volces.com/api/plan/v3/chat/completions`，请求 `deepseek-v4.1-flash`，响应精确核对 `deepseek-v4-1-flash-261017`。
- E0 `thinking=disabled`，不传 effort；E1 `thinking=enabled, reasoning_effort=high`。两组 `max_tokens=32768, top_p=1`，不传 temperature。
- 适配器只改上述生成字段，不重写 messages、tools 或工具历史。原生 Pi 执行工具并继续请求；合法 JSON 的参数错误可由模型自行纠正。所有请求，包括子任务或压缩请求，都经过同一配置和共享账本。
- SDK 原生保留 thinking signature；同轮工具续跑校验 reasoning_content，跨用户轮遵守 SDK 默认历史行为。私有思考不混入公开回答或盲审材料。E1 未观测到思考内容/用量不单独中止；E0 出现正向思考信号中止批次。
- 工具仍待执行时不能视为任务结束。只有原生请求自然完成、没有未答交互，才能推进预先批准的下一用户轮。F02/F04 缺少实际范围结果时停止当前任务，不能编造“刚才结果”。此检查不替代最终语义评分。
- 普通澄清与交互 API 均只允许对题干已明确的来源、对象、保存范围重复一次原题；缺少事实或新增权限的问题记待用户，停止当前任务。是否接口合规另评。

## 预算与停止

共享上限 96 次模型请求、250 万输入 token、40 万输出 token（包括思考，不再次加算 reasoning_tokens）。每次请求发出前，将 `UTF-8 请求体字节数 + 4096` 作为输入预留，输出预留 32768；完成后用实际 usage 结算。usage 不明保留失败记录并停止，不以零计费。

新配对仅在扣除预留 24 次请求、60 万输入、131072 输出后仍有余量时开始。恰好达到这条保留边界也不新开配对；已开始配对可继续使用共享余额。12 次请求、24 次工具、10 分钟仅提示，不中止正在推进的单任务。无总请求时间上限（不传 LLM_REQUEST_TIMEOUT_MS，使用 SDK 默认），HTTP 空闲上限 300 秒。

协议异常、提供商/网络错误、输出截断、模型漂移、源码/运行时变化、技术运行错误或关键权限越界停止批次。未完成、未知用量与未执行条目分别保留，不自动恢复。正常能力失败、缺少下一轮依赖、普通未答问题停止该任务并单列。

## 执行入口

从 `experiments/harness-lab` 执行：

```sh
node --import tsx ../../.trellis/tasks/10-15-agent-map-spatial/r13-20261025/live.ts prepare /绝对路径/全新冻结文件.json
node --import tsx ../../.trellis/tasks/10-15-agent-map-spatial/r13-20261025/live.ts run /绝对路径/.local/spatial-r13/全新批次目录 /绝对路径/全新冻结文件.json 4667
```

由主会话完成离线检查和独立复核后执行一次。凭据通过既有本地环境载入，不写入证据。固定 `.local/spatial-r13/live-claim.json` 使用排他创建，不依赖输出目录，不能换目录绕过重复执行。离线测试显式使用 `/tmp` 下 `r13-offline-*` 独立声明，不接触 live 声明或真实模型。

冻结包括新驱动、批准方案和评分规则、五份历史夹具实际内容、直接复用的旧 helper/HTTP 脚本、SDK 及共同运行时哈希。主会话另在开始/结束验证 `history-before-20261026.json` 全历史与产品快照，避免逐请求重复扫描大量日志。
