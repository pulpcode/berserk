仅扩充测评任务、夹具、执行驱动、离线检查与报告。产品固定 B 版 c95b3d3；沿用 af13107 归档后只替换该提交两份 Skill 的隔离运行方法。工具、后端、Skill 正文及目录不改，不合入 main、不部署。工作分支 codex/agent-result-grounding，起点 8da9d3e。之前各轮原始证据和评分不改。

正常按需加载 Skill，用户请求不显式选中 Skill，首请求不预塞正文。每项独立会话，必要的多轮操作属于同一项任务。24 项不是 24 次模型请求，也不是旧题重复 24 次。本轮不设 A 组，不据此宣称 B 比 A 更好。

## 怎么评分

每项分别判断：主任务完成、过程说明事实正确、最终回答事实正确、实际副作用正确、对象/版本/权限边界正确。严格通过要求五项均通过且技术流程完成。数值正确但算错对象仍是主任务失败；正确结果附带明确误述是严格失败；后来更正不抹掉之前已展示的错误。

普通文字澄清与交互 API 契约覆盖分开。T03 若正确识别歧义并等待选择，可完成该题的消歧目标；允许完整且准确的条件答案，不要求模型猜测唯一目标。读取 Skill 不作为正确性必要条件；记录实际调用、成功返回、正文是否进入后续请求，以及是否晚于关键决策。

检查全部可见过程及最终回答，并与原始工具回执、版本、几何和前后状态核对。先由主 Agent 审阅，再由独立检查 Agent 复核；这不是人工盲评。解释含糊且证据不足时保留待定和敏感性分析，不把一种不利解读自动当事实错误。

总体保留计划分母 24；每类计划分母 4，分别列通过、失败、技术中断、未执行、待定。另列已完成任务口径，不能把中断算模型错，也不能从计划分母删除。故障恢复覆盖与任务结果分开。

本轮是扩大诊断，不是独立保留集正式验收，也不能用一次作答估计生产稳定正确率。整体 90% 的正式门槛保留；本轮高于 90% 也不自动宣布整体验收通过。
