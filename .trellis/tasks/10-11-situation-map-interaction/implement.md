# 实施与验证计划

状态：2026-10-11 已获准实施，按以下步骤执行并记录实际验证结果。

批准实施后，先通过 trellis-before-dev 完整读取相关层规范，尤其是前端草稿、身份切换和迟到响应约束；不能只依赖上下文清单截取的片段。

## 1. 顺序与检查点

| 步骤 | 工作 | 完成检查 |
| --- | --- | --- |
| 1 | 读现有约束，补契约用例：geometry、道路状态、时间、引用、源修改与通知分离 | 新旧对象均能正确校验；非法数据有明确错误 |
| 2 | 扩展独立模拟服务、持久保存当前测试；选择实际区域、准备与底图对齐的几何和新实例；补受控状态修改/报告发布/发送接口 | 重启保留修订；重提不重复修改；通知使用真实 HTTP 接入 |
| 3 | 增加宿主只读地图接口、公开底图配置、配置区域和模拟控制授权适配 | 与 Agent 查询同源同权限；普通席位不能修改模拟源 |
| 4 | 实现在线 OSM 底图、共用地图与三处入口、对象详情、查询依据定位、刷新和异常反馈 | 底图署名与模拟标识明确；当前态势一致；导航/草稿/HITL 保持 |
| 5 | 扩展对象引用输入及原生历史投影，加入派生对象链接及 Markdown 定位交互 | 地图可向对话传资料；回答可点击定位，模型不生成链接时仍有依据入口 |
| 6 | 增加设置中的模拟控制页；完成端到端验证并准备人工测试数据 | 保存、发送、接收、分析状态可分别核对；不代替用户审批 |

不是六个独立建设阶段，实施在同一阶段内按上述顺序完成。在线开放底图纳入本期；自建地图服务、付费供应商、空间运算或新的业务授权模型有具体需求时另行审阅。

## 3. 测试安排

确定性测试覆盖 PRD A1～A8、A10；真实模型验证 A9，不用模型测试替代接口权限测试。

- **源契约**：点/线/面坐标合法性、缺失位置、道路未知状态、旧空 properties、版本推进、持久恢复、游标失效。
- **源通知**：先保存后发送；同键重复接收；同键不同内容冲突；接收响应丢失后查回执；保存与发送不同成功状态。
- **权限与上下文**：席位鉴权、后台服务 scope 不被浏览器借用、模拟控制授权；只加载所选对象；老 composer 历史仍可读，取消不自动重放。
- **浏览器**：三个入口同对象；任务筛选的并集；无范围、无位置、源离线；跨席位/任务迟到响应；地图面板不挡输入和确认卡；键盘选择、关闭、引用；1280/1440 宽度。
- **回答定位**：普通对话和后台正文的有效链接、同名不同编号、旧修订、只有报告对象引用、无依据/畸形链接、流式未完成链接；未生成链接时依据按钮可用。历史重开与点击时权限均核对。
- **在线底图**：A11 中的加载/故障、署名、模拟标识及业务刷新不重载瓦片由自动化瓦片替身验证；人工浏览再核对实际 OSM 服务连通性和几何对齐。Playwright 不对公共瓦片服务自动平移、缩放或批量获取。
- **真实闭环**：新任务与新来源编号 → 修改道路/车辆 → 发送通知 → 现有后台研判与投递审批 → 人员地图提问 → 道路恢复 → 比较新旧依据。后台等待和审批使用既有机制，不新增自动批准。

实施完成后在包目录运行既有 `npm run typecheck`、`npm run lint`、`npm test`、`npm run build`，再跑受影响 Playwright 场景。测试输出分为工程通过情况、真实模型实际结论、未覆盖内容；不提前填写通过结果。

实际浏览器验收需具备 WebGL 环境；无 WebGL 时给出对象列表与“地图暂不可用”，保留查询与引用能力，但不能据此宣称地图渲染验收通过。

复用 boat/road-demo 中 MapLibre 的图层、源更新和本地 worker 接入经验；不搬入其离线瓦片、路线规划服务或 API Key 配置。在线底图连通性在实际浏览器核对，不能仅用服务器联网结果替代。
