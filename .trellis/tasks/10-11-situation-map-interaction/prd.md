# 需求：态势模拟与地图交互接入

状态：已审阅，获准实施；以下为验收目标，不代表已全部实现。

## 1. 目标与基础

让人员能看懂空间关系、查明态势来源、围绕地图对象提问，并可重复验证“态势变化 → 自动研判 → 席位接收 → 后续办理”。

现有系统已有独立模拟查询服务、后台通知接入、多源分析、任务关联、投递审批、席位工作区和文件交接；尚无地图、空间坐标或可视化模拟控制。既有道路记录不包含结构化通行状态，车辆记录表达资源池数量，不是单车位置。

## 2. 产品要求

| 编号 | 要求 |
| --- | --- |
| R1 | 模拟区域、道路线及资源池位置可展示；道路通行状态和资源数量可受控修改；报告可发布新修订。无位置的对象仍可查询，不虚构坐标 |
| R2 | 验证人员可分别“保存变化”和“发送通知”；可核对发送内容及 Axon 接收回执；一次通知重送不重复启动处理 |
| R3 | 全局地图、任务地图、对话侧面板复用同一数据和交互；保持现有侧边导航及对话草稿 |
| R4 | 点击对象查看当前状态、资料来源、修订及业务时间；Agent 回答正文中的对象链接及查询依据均可定位对象；引用对象到对话后，由人员明确发送 |
| R5 | 任务地图以任务引用和区域条件帮助定位，不把筛选当成授权，也不宣称图中全部对象都已被判断为影响该任务 |
| R6 | 地图查询与 Agent 查询均执行既有资料范围权限；任务页面另校验任务权限；个人空间、文件和对话继续隔离 |
| R7 | 新状态可刷新查看；来源异常、部分数据、无位置、历史依据与当前状态不同均有明确反馈，不呈现为“没有风险” |
| R8 | 保持已有后台 Profile、关联、投递与交接流程；正常浏览不启动分析、不自动通知席位、不修改任务方案 |
| R9 | 使用在线 OpenStreetMap 底图提供真实地理背景，叠加模拟态势并持续标识；本期不自建地图服务，底图故障与态势源故障分别呈现 |

仅面向桌面浏览器。主要验收宽度为 1280 和 1440 CSS 像素；沿用现有视觉样式，不新增手机端适配目标。

## 3. 验证场景

建立一组新的验证任务和独立模拟实例，名称与编号带本轮标识，与此前测试区分。

选择一个小范围真实区域作为地理背景，预置道路几何与所选底图道路对齐，资源池和业务区域由测试场景配置；通行限制、资源数量、报告和任务均为合成条件。控制页围绕这一场景提供操作，用于验证通用能力，不建设任意场景编排平台。

- 西区补给任务：09:40 开始办理，需 3 辆车。
- 西区设备转移任务：10:20 开始办理，需 1 辆车。
- 东区任务：作为相邻区域对照，不能因地图距离近而直接判定受影响。
- 初始：西区道路可通行、车辆池 4 辆。随后道路限制至 10:10，车辆降为 2 辆；再发布道路恢复，车辆仍为 2 辆。

人员先看地图和自动分析，再引用道路、车辆池询问两个西区任务的影响。恢复后核对：地图道路已恢复，当前车辆仍不足以同时满足全部需求；是否调整任务时限或安排仍由人员决定。合成日期在准备测试时统一生成，业务时间与实际查询时间分别记录。

这些条件只写入测试数据和任务要求；模拟接口不得返回“影响哪些 Axon 任务”“应投递哪个席位”或预期分析答案。

## 4. 验收标准

| 编号 | 可观察的通过标准 | 对应 |
| --- | --- | --- |
| A1 | 地图道路、区域、资源池位置来自源接口；对象编号、修订、状态与 Agent 实际查询结果一致 | R1、R4 |
| A2 | 保存状态后地图能刷新；未点击发送通知时不产生后台作业；发送回执可跳转现有处理记录 | R2、R8 |
| A3 | 同一通知重送仍对应原接收记录；修改内容需新通知编号；发送失败不回滚已保存态势 | R2 |
| A4 | 三种地图入口能定位同一对象；回答中的有效对象链接打开右侧地图，无效引用不误定位；未生成正文链接时仍能从查询依据定位。打开、筛选、选择和引用均无模型请求 | R3、R4 |
| A5 | 两个任务可以查看同一道路；地图不复制文件、不串用工作区；任务筛选不自动创建信息关联 | R5、R6 |
| A6 | 无资料权限不能通过接口或深链接读到对象；无模拟控制权限不能改数据或发送测试通知 | R6 |
| A7 | 道路恢复后，旧分析仍保留旧依据；查看地图明确是当前状态，不能将旧依据替换成新数据 | R7 |
| A8 | 来源离线保留已加载画面并标注更新失败；首次失败、无位置和确无对象分别呈现；迟到响应不串席位或任务 | R7 |
| A9 | 真实模型能使用引用对象继续查询和回答；实际错误、遗漏、额外提问如实记录，不以成功状态代替质量判断 | R4、R8 |
| A10 | 原有登录、待办、任务信息、对话、附件自动导入、审批和交接回归通过；不新增容器常驻地图进程 | R3、R8 |
| A11 | 人工浏览能加载在线真实底图，署名与“模拟态势”持续可见；瓦片失败有提示，态势对象和列表仍可使用。自动化测试使用受控瓦片替身，不扫描公共瓦片 | R9 |

## 5. 范围之外

真实外部业务系统建设、商业地理数据采购、自建瓦片服务与离线地图、道路拓扑与导航、资源自动调度、连续仿真、时间轴回放、地图编辑/共享标绘、模型自由绘图、Agent 修改源事实、精细区域授权与动态撤权管理。

上述能力后续按需求单独设计。本阶段空间字段和只读接口可扩展，不预先建设通用 GIS 平台。
