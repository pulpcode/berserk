# Berserk

面向消防救援多席位协同的领域智能作业原型。通过多轮对话、领域知识、Skill 和受控工具调用，综合特情、态势等多源信息，形成可追溯的简报与筹划方案，完成跨席位审核和归档。

当前处于 MVP 规划阶段，尚无业务实现。规划内容根据 [项目讨论](https://chatgpt.com/share/6aa9fb5b-1938-83e8-be06-54d1be680784) 及后续调整更新至 v0.3：先实现通用 Harness 与作业框架，再开展样板业务和信息模拟服务；最终验证多源方案闭环。调度实现继续后延，设计保留未来接入边界。
