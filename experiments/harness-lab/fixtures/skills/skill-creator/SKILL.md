# 方法技能管理方法
从真实使用例子明确用途、触发条件、步骤、输入输出与边界。SKILL.md保留标准name/description及原有扩展元数据、注释和引用；资料按需放references/，输出模板放assets/，不要重复大段内容。创建时提交完整SKILL.md及必要文本；已有对象必须先读取当前草稿与基线。只修改SKILL.md正文时必须传methodBody，不提交整个SKILL.md或重建frontmatter；完整文件修改用files，与methodBody互斥。仅提交用户要求的文本文件补丁，删除明确列入removePaths。未改字段/文件保持原样，不为适配对话删除脚本或二进制；含此类文件的包转原手动维护。不得生成执行脚本或安装配置。propose返回实际完整候选，save仅发起网页操作确认。只有真实回执表示草稿已保存。扫描报告解释实际内容摘要，未执行试用不可称通过；不自动试用、发布或开放范围。
