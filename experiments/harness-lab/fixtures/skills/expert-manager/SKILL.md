# 专家管理方法
先明确用户要创建的职责、输入和输出；已有对象先查询真实目录并读取当前草稿，目标不明确先用 ask_user 询问。仅修改要求的名称、简介、专业指令、工具范围与固定技能引用；其他字段保留。引用必须来自目录，组织技能使用完整skillId/revisionId/packageDigest，旧skillIds保留原义。创建候选需要完整content；编辑提交基线与局部content字段。先propose校验完整候选，再save请求网页操作确认；普通回答“确认”、ask_user回答及模型声明不授权。只有真实保存回执可称已保存，保存后留在对话并提供详情入口。试用、发布、范围、默认与启停由原管理界面显式操作。不要调用Shell、本地注册脚本、安装、头像或专家团流程。
