使用平台提供的真实对象与空间工具完成分析。底图、页面可见范围和隐藏图层只是显示状态，不能作为候选数据或权限。卫星影像里看见的道路、建筑不会自动成为可计算对象。空间计算不会自动保存标绘。

先明确要回答的量、分析对象和候选范围。已有完整对象引用或固定标绘引用足够时直接使用；缺少身份、字段或版本时用 situation_query / annotation_read 定向读取。名称有多个匹配且不能由用户上下文确定时先澄清。不要猜坐标、边界、属性或未提供的道路连接。

## 选择方法

- 两点相距多远：measure 的 distance；点离一条线多远：point_to_line。它们是地理距离，不是沿道路行驶距离。不要把经纬度差当米，也不要拿线的端点代替整条线。
- 线有多长：length；面有多大：area。折线长度包含各段，面面积来自真实轮廓，不能用端点距离或包围盒替代。结果单位分别为 m 和 m²；需要展示千米、平方千米时按 1000、1000000 换算，保留合理精度。
- 区域包含对象、对象相交或分离：relate。contains 是区域覆盖目标，默认包含边界；intersects 包括边界接触；disjoint 是没有交集。部分相交不等于完全位于区域内，相交也不表示道路连通。严格内部、仅接触边界等不同问题不能直接冒充已支持的关系。
- 区域内且符合属性的对象：filter。确定候选范围后再按真实字段与空间条件筛选。空间条件中的 target 是参照区域或对象；input 是待筛选集合。缺失字段与不匹配不是一回事，以工具报告的数据缺口为准。
- 最近的 N 个：先完成全部限定条件，再 nearest。本期参考对象和候选对象均须为点。按地理距离排序；同距按完整对象身份稳定排序，N 不因并列自动扩大。明确实际候选范围，不把局部范围的最近说成全部来源的最近。
- 需要点或线周围的范围几何：buffer，距离用 distanceM 的米数。后续用 resultRef 引用生成的 geometry。若只需判断某个点距线是否不超过阈值，可测距或按距离过滤，不必额外生成面。缓冲是近似范围，不能自行扩大阈值或承诺测绘级精度。
- 按类别计数：先获得符合条件的集合，再 summarize 指定实际属性字段。按完整对象身份去重；null 是单独类别，字段缺失要按错误处理。不能先统计全部候选，再把它描述成区域内数量。

## 组合步骤与引用

一次 spatial_analyze 执行一个操作。按实际依赖组织 Pi 的正常调用：例如“线周边某距离内的可用对象分类数量”，可先 buffer，再用范围结果 filter，并把筛选结果交给 summarize；需要最近若干对象时，在全部筛选完成后 nearest。等价的正确方法可以省略不必要步骤。

input 的 kind 为 source 时保留完整 systemId/objectType/objectId 身份和明确的来源/区域候选范围；kind 为 annotation 时使用固定 ref 与必要的图层或对象选择；kind 为 result 时使用宿主实际返回的 resultRef。引用筛选集合使用结果 items；引用缓冲面使用 geometry:true。不要从摘要抄坐标、编造结果引用，或把重新查询后的变化数据说成前一次快照。

对“刚才的范围”“继续统计”等续问，使用已知真实 resultRef；需要恢复内容时用 spatial_analyze 的 read 操作。读取固定结果不会刷新来源。用户要最新情况时重新查询、重新分析，并区分两次依据。

## 检查与解释

工具负责权限、类型组合、分页收集、版本、有效几何和规模限制；Skill 不授予权限。不能因为用户说“全部”就把当前页当全量，也不能扩大原先限定的区域。工具失败、缺失几何/属性、版本变化和超限都不是零命中。只在完整的实际候选范围内得到空集合时说明没有匹配对象。

遇到错误，先看错误标识和缺口：歧义用查询或澄清解决；来源变化需核实是否接受新快照；来源不可用或不支持的算法条件要明确说明，不靠改小范围或猜测数据制造成功。保留已成功的固定结果，不能把失败步骤包装成完整组合分析。

答复核对工具的数值、单位、对象集合、scope、completeness、provenance 和 limitations。说明与用户问题相关的范围及时间；多来源读取不保证同一瞬时。区分结果支持的事实和额外推断。距离采用球面近似，关系和缓冲有适用地域/几何限制，不承诺厘米级精度。成功时简明回答；地图入口由界面产生，无须手写 URL 或原始几何 JSON。

“最快到达”“道路可通行”“最适合派遣”需要路网或专业依据，本期不能据最近距离给出这些结论。必要时询问是否改为比较地理距离，不暗中替换问题。仅改名称、颜色等普通标绘请求走既有标绘工具，不额外执行空间分析。

## 保存分析结果

用户明确要求保存时，读取 map-annotations 方法并沿用已有草稿、图层和版本流程；已有足够固定依据时不重复读取。通过 annotation_from_analysis 的真实 resultRef 保存已展示几何，或选择结果中的具体对象；不手工重画，也不重算后替换原结果。原请求已要求保存就不再重复征求批准。

保存工具会重新检查权限和草稿版本，只有能无损表达的几何可保存。含孔或多面结果不能靠删除孔、取第一块或包围盒降级。保存失败保留分析事实，按标绘错误/回执规则处理；未知写入结果先核对原回执，不换标识重试。保存、发布和设为任务当前是不同动作，不自动发布或采用。
