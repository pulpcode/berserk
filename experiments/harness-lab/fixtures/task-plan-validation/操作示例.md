# 人员操作示例

这些文字供人员在当前任务会话中自行输入，不作为 Agent 系统提示或自动发送。

总体席在“西区补给方案”任务选择初稿作为附件，请求分派给筹划席完善补给方案，并核对确认卡。

筹划席签收交接后：

> 请结合本任务的相关信息和交接初稿，编制供审阅的补给方案。写清依据、约束、建议及待确认事项；保留初稿，另存为补给方案_v1.md。

筹划席查看文件后明确请求提交，并确认对应文件。总体席保留待验收状态。此时才运行 `send E4`。

总体席在新信息完成实际分析和投递后，退回第一稿，说明：

> 有新的道路信息，请核对变化并更新方案。

筹划席从退回工作进入原办理会话：

> 请核对新的道路信息，与第一稿比较并更新方案。保留原文件，另存为补给方案_v2.md，写明变化依据和仍待确认的事项。

筹划席审阅后提交第二稿，总体席自行审阅验收。每个席位自行决定是否将外部信息标记处理。模型漏读、未关联、未建议投递或错误判断均保留，人工补充另作记录。
