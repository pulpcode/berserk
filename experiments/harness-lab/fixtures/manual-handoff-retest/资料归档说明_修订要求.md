# 资料归档说明修订要求

本次只修订随附初稿，不查询外部制度。材料与示例均为虚构测试内容。

1. 保留初稿开头的测试声明。
2. 统一文件名规则为“日期_资料名称_版本.扩展名”，日期使用 YYYY-MM-DD。例如：2026-10-10_活动纪要_v1.md。
3. 归档登记必须包含资料名称、整理人、归档日期、版本、存放位置。
4. 交接双方逐项核对文件和登记信息，留下书面核对结果。缺少文件时，登记缺失内容、补齐负责人和约定完成日期，不得以口头通知代替核对。
5. 增加一条虚构填写示例：资料名称“活动纪要”、整理人“张明”、归档日期“2026-10-10”、版本“v1”、存放位置“活动资料/2026-10-10”。
6. 文末用三条要点说明主要修改；排版自行决定，无需另行确认章节形式。

交付：保留初稿，不覆盖；另存为“资料归档说明_修订稿.md”。筹划席完成后向总体席提交该文件，由总体席人员审阅验收。
