# 消防救援符号素材

本目录只接受随产品审查的本地 SVG，不接受用户上传、远程图片地址或动态 SVG。

- 标准依据：应急管理部发布的 XF/T 3013—2020。`provenance.json` 逐项记录标准条目、原 PDF 页码和转换方式。
- 12 个条目直接保留原文矢量路径（移除页面水印）；8 个原文位图条目按已审阅样张转写为几何 SVG。转写保持外框比例、专用标记和朝向，没有以通用车辆插画替换。
- 冲锋舟与救援舰船是本项目应用扩展，沿用已审阅的俯视轮廓，不能标为标准原图。
- 战斗员沿用标准中的编号示例 1；它是符号样式，不代表已绑定人员编号。真实人员名称由对象名称提供。
- 原图车辆与船艇朝东；直升机尾部朝南。实际方位由共享目录 `intrinsicHeading` 和可选的真北方位 `heading` 换算，省略方向时保留原图朝向。
- 所有素材使用 128 × 128 画布，保留图形宽高比例；地图以 pixelRatio 4 注册，基准显示尺寸为 32 CSS px，用户允许选择 20–64 px。白色外衬仅提高底图对比，不表示业务状态。
- 加载失败使用中性问号并报告失败条目，不替代成另一种车辆。标准主体颜色不随草稿或业务状态改变。
